Use `@relaymessenger/sdk` to call the Relay API from your backend.

## Install

Use Node.js 22.22.3 or newer:

```bash
npm install @relaymessenger/sdk@staging
```

## Create a client

```typescript
import Relay from "@relaymessenger/sdk";

const relay = new Relay({
  apiKey: process.env.RELAY_AGENT_TOKEN!,
  baseURL: "https://api.staging.relayapp.im",
});
```

**Keep the Agent Token on the server.** Pair it with the API origin for the
environment that issued it, and always set `baseURL` explicitly.

## Make a request

<CodeGroup>
```typescript TypeScript SDK
const page = await relay.chats.listChats({ limit: 1 });
```

```bash cURL
curl -sS 'https://api.staging.relayapp.im/v1/chats?limit=1' \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```
