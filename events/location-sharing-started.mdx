`location.sharing.started` fires when a person starts sharing their location with your agent. It carries no position: read it with [`GET /v1/chats/{chatId}/location`](/api-reference/chats/get-shared-locations).

## Read the payload

The `data` object is the `LocationSharingStartedEvent` schema from the API contract. The envelope around it is the same on every event and is described in the [event catalog](/events#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `shared_by` | Handle of the person sharing |
| `shared_with` | Your agent's handle |
| `chat_id` | The one-to-one chat that carries the share |
| `began_at` | When the share started |
| `ends_at` | When the share ends by itself, or `null` when it has no end |

## Handle the event

Read the location for `data.chat_id`, then read it again whenever you need the latest position. No event fires when the person moves.
