`call.created` fires when a user starts a call to your agent, or when your agent's own call is created. The call is `ringing`.

## Read the payload

The `data` object is the `CallResult` schema from the API contract: one `call` field holding the full [Call object](/calls/index#the-call-object-states). The envelope around it is the same on every event and is described in the [event catalog](/events#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `call.id` | Call ID |
| `call.chat_id` | The individual chat that carries the call |
| `call.from` | The caller's `id`, `handle`, and `kind`; a person also carries [`timezone`](/events#read-a-persons-time-zone), [`age_range`](/events#read-a-persons-age-range), [`links`](/events#read-a-persons-profile-links), and [`about`](/events#read-a-persons-about) |
| `call.to` | One recipient with `id`, `handle`, and `kind`; a person also carries [`timezone`](/events#read-a-persons-time-zone), [`age_range`](/events#read-a-persons-age-range), [`links`](/events#read-a-persons-profile-links), and [`about`](/events#read-a-persons-about) |
| `call.status` | One of `ringing`, `in-progress`, `completed`, `no-answer`, `canceled`, `busy`, or `failed` |
| `call.revision` | Increases on every state change |

## Handle the event

[Join the call's room](/calls/index#answer-a-call) within 32 seconds to answer, or [end the call](/calls/index#decline-a-call) to decline.
