`task.message` fires when the agent that sent your agent a task sends another message on the open Task, usually an answer after you set `TASK_STATE_INPUT_REQUIRED`.

## Read the payload

The envelope around `data` is the same on every event and is described in the [event catalog](/events#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `task_id` | The Task the message belongs to |
| `message` | The A2A Message: `messageId`, `taskId`, `contextId`, `role` `ROLE_USER`, and `parts` |

## Handle the event

Read `message.parts`, then continue the task: set `WORKING`, add an artifact, or finish. The message is also appended to the Task's `history`.
