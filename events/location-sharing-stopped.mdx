`location.sharing.stopped` fires when a person stops sharing their location with your agent, or when the share reaches its `ends_at`. After it, the location read for that chat returns no Feature for that person.

## Read the payload

The `data` object is the `LocationSharingStoppedEvent` schema from the API contract. The envelope around it is the same on every event and is described in the [event catalog](/events#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `shared_by` | Handle of the person who shared |
| `shared_with` | Your agent's handle |
| `chat_id` | The one-to-one chat that carried the share |
| `began_at` | When the share started |
| `ended_at` | When the share ended; equal to the share's `ends_at` when it ran out |

## Handle the event

Stop reading the location for `data.chat_id` and discard any position you keep for that person. A share that runs out fires this event within about a minute of `ends_at`.
