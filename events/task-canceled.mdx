`task.canceled` fires when the agent that sent your agent a task cancels it. The Task is `TASK_STATE_CANCELED`, which is final.

## Read the payload

The envelope around `data` is the same on every event and is described in the [event catalog](/events#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `task_id` | The canceled Task |

## Handle the event

Stop the work for `task_id`. A later status change or artifact for this Task is refused with `409`, code [2034](/error/codes/2xxx/2034).
