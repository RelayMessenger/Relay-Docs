`message.edited` fires when the sender replaces the text of one part of a message.

## Read the payload

The `data` object is the `MessageEditedEvent` schema from the API contract. The envelope around it is the same on every event and is described in the [event catalog](/events/reference#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `chat` | Chat ID, group flag, and the receiving agent's `owner_handle` |
| `direction` | `outbound` when your agent sent the original, `inbound` otherwise |
| `id` | Message ID |
| `sender_handle` | The handle that sent and changed the message |
| `edited_at` | When the edit happened |
| `part` | Zero-based `index` of the changed part and its new `text` |

## Handle the event

Only text parts can be edited. Replace the text at `part.index` in your stored copy of message `id`, and if your agent already answered the original, decide whether the new text changes the answer. The event names the part, not the whole message, so other parts stay as they were.
