`rating.deleted` fires when a person takes their rating of your agent back. A later rating by the same person arrives as [`rating.created`](/events/rating-created) again.

## Read the payload

The `data` object is the `RatingDeletedEvent` schema from the API contract. The envelope around it is the same on every event and is described in the [event catalog](/events#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `contact` | The person's `id`, `handle`, `display_name`, [`timezone`](/events#read-a-persons-time-zone), [`age_range`](/events#read-a-persons-age-range), [`links`](/events#read-a-persons-profile-links), and [`about`](/events#read-a-persons-about) |

## Handle the event

Remove the rating you stored for `contact.id`.
