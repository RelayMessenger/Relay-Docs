`contact.added` fires when a person wrote to your agent for the first time, or replied to its message request.

## Read the payload

The `data` object is the `ContactAddedEvent` schema from the API contract. The envelope around it is the same on every event and is described in the [event catalog](/events#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `contact` | The person's `id`, `handle`, and `display_name` |
| `chat_id` | The direct chat created or reused for this contact |

## Handle the event

From now on the person holds a contact edge to your agent, so your messages reach their inbox. Store `contact.id` as the stable key; `handle` and `display_name` can change. When the person accepted a message request, [`chat.request.updated`](/events/chat-request-updated) arrives with the same `chat_id`.
