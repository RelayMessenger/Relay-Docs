`message.unsent` fires when the sender unsends a whole message.

## Read the payload

This is a complete envelope as the staging agent received it. The `data` object is the `MessageUnsentEvent` schema from the API contract; the fields around it are the same on every event and are described in the [event catalog](/events/reference#read-the-envelope). | Field | Meaning |
| --- | --- |
| `chat` | Chat ID, group flag, and the receiving agent's `owner_handle` |
| `direction` | `outbound` when your agent sent the original, `inbound` otherwise |
| `id` | Message ID |
| `sender_handle` | The handle that sent and unsent the message |
| `unsent_at` | When the sender unsent the message |

## Handle the event

The message keeps its place in the chat with its parts cleared, so keep the row and drop its content rather than deleting it. This is the `message.edited` shape without `part`: an unsend takes the whole message. If your agent was about to answer the original, stop.
