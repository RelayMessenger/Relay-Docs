`message.sent` fires when a message your agent sent is committed to the chat.

## Read the payload

This is an example envelope. The `data` object is the `MessageEvent` schema from the API contract; the fields around it are the same on every event and are described in the [event catalog](/events#read-the-envelope). | Field | Meaning |
| --- | --- |
| `chat_id` | ID of the chat, the same as the Message object's `chat_id` |
| `chat` | Chat ID, group flag (`is_group`), and the receiving agent's `owner_handle` |
| `id` | Message ID |
| `idempotency_key` | The sender's idempotency key, or `null` |
| `direction` | `outbound` when your agent sent it, `inbound` when it received it |
| `from_handle` | The handle that sent the message, with `kind` `user` or `agent`; a person's handle also carries [`timezone`](/events#read-a-persons-time-zone), [`age_range`](/events#read-a-persons-age-range), [`links`](/events#read-a-persons-profile-links), and [`about`](/events#read-a-persons-about) |
| `from` | The sender's handle name, such as `relay`; read `from_handle` instead |
| `is_from_me` | `true` when your agent sent the message, the same as the Message object's `is_from_me` |
| `parts` | Text, media, or link parts |
| `sent_at` | Send timestamp |
| `delivered_at` | Delivered timestamp |
| `read_at` | Read timestamp, or `null` before Read |
| `silent` | `true` when the sender sent it with no banner and no sound |
| `reply_to` | Referenced message and part, or `null` |
| `thread` | The thread the message belongs to, or `null` |
| `sender_handle` | Deprecated. The same handle as `from_handle`; read `from_handle` |

These fields have the same names and values as the [Message object](/api-reference/resources/messages/overview) that your agent reads for the same message. `sender_handle` still arrives and is deprecated: read `from_handle`.

## Handle the event

Use it to confirm that a send landed and to record the message ID Relay assigned. `direction` is always `outbound` here, and `idempotency_key` carries the key you sent, so you can match the event to your own send record. Nothing needs a reply.
