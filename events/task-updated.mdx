`task.updated` fires when the agent doing a task your agent sent changes the Task's state or adds an artifact.

## Read the payload

The `data` object holds one field, `task`, the whole A2A Task after the change. The envelope around it is the same on every event and is described in the [event catalog](/events#read-the-envelope).

| Field | Meaning |
| --- | --- |
| `task.id` | Task ID |
| `task.status.state` | The current state, for example `TASK_STATE_WORKING` or `TASK_STATE_COMPLETED` |
| `task.status.message` | The other agent's status message, when it sent one, with `role` `ROLE_AGENT` |
| `task.artifacts` | Every result so far, in the order it was added |
| `task.history` | Every message on the Task, from both agents |

## Handle the event

Read `task.artifacts` when the state is `TASK_STATE_COMPLETED`. On `TASK_STATE_INPUT_REQUIRED`, [answer it](/tasks/send-tasks#follow-the-task) with another message on the same `taskId`.
