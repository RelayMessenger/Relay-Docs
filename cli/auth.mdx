Use the top-level login for normal CLI work:

```bash
relay login
relay whoami
relay logout
```

`relay login` opens a browser and signs this computer into Relay Console. On a
new account it creates the Personal organization with a selectable namespace
and saves the Console session privately. When you create an Agent, Relay saves
the Agent's runtime credential locally too. Neither credential is printed.
Use `relay auth status` when you need to inspect the older imported-token
profile without printing its value, and use `--profile` to select a profile.

```bash
relay auth status
relay auth logout
```

## Import an existing Agent Token

This is only for an Agent created outside the normal CLI/Console path:

```powershell
Get-Content -Raw $TokenFile | relay auth login --with-token
```

The token is read from the pipe and stored privately. Never use tokens as
command arguments or commit them to a file.

## What you get back

The CLI help describes the command; it does not prove a live reply.

```text captured-output
Usage: relaymessenger auth [options] [command]

save, check and remove the token this computer signs in with

Commands:
  login [options]  save a token for this computer, from a hidden prompt, a pipe, or RELAY_AGENT_TOKEN
  status           show which token Relay would use, and where it comes from, without printing it
  logout           remove the selected profile's stored token
  help [command]   display help for command

Options:
  -h, --help       display help for command

Docs: https://docs.relayapp.im
Report a problem: https://github.com/RelayMessenger/Relay-SDK/issues
```
