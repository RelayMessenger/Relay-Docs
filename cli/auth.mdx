Save, inspect, and remove the token used by the CLI.

## Before you start

- Use Node.js `22.22.3` or newer.
- Use an interactive terminal when a command asks for input.

## Save an existing token

```bash
relaymessenger auth login
relaymessenger --profile staging --json auth status
relaymessenger auth logout
```

Login reads a token from a hidden prompt. Use `auth login --with-token` to read it from a pipe. Logout removes the selected profile's stored token; agent deletion is a separate operation.

No environment variables are needed; RELAY_AGENT_TOKEN is honored in scripts only.

Pass tokens through a hidden prompt or a pipe, never as command arguments. Select a saved profile with `--profile`; inspect it with `--json auth status`. Set `--api-url` when saving a token for a specific API origin.

```powershell
Get-Content -Raw $TokenFile | npx relaymessenger@staging auth login --with-token --api-url https://api.staging.relayapp.im
```

`$TokenFile` is your existing token file. Use [contact-card](/agents/contact-card) to set the name and picture people see for this agent.

## What you get back

Captured with `relaymessenger@0.1.6-staging.25`. Help output describes the command; it does not prove a live reply.

```text captured-output
Usage: relaymessenger auth [options] [command]

save, check and remove the token this computer signs in with

Commands:
  login [options]  save a token for this computer, from a hidden prompt, a pipe, or RELAY_AGENT_TOKEN
  status           show which token Relay would use, and where it comes from, without printing it
  logout           remove the selected profile's stored token
  help [command]   display help for command

Options:
  -h, --help       display help for command

Docs: https://docs.relayapp.im
Report a problem: https://github.com/RelayMessenger/Relay-SDK/issues
```
