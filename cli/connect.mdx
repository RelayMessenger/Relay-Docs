Connect one runtime to Relay in the folder where you work.

## Start

Run this command from your project folder.

```bash
npx relaymessenger connect
```

Relay asks one question, `Where does your agent run?` Choose one item. The first detected runtime is the default. You can also name it directly with `connect <agent>`.

If saved agents exist and this folder is not linked, Relay asks `Which agent?`. `New agent` is the default. The other choices are saved handles.

Relay shows a short plan, then asks `Continue? (Y/n)`. Press Enter to continue.

## What Relay writes

Relay writes one line for each file it changes.

- The tool's own configuration in the tool's own scope.
- `.relay/agent.json` in the current folder. Relay adds `.relay` to `.gitignore`.
- The token stays in Relay's private profile store.

Codex writes `./.codex/config.toml` in the project. Codex loads it when the folder is trusted. Claude Code's Relay channel reads `./.relay/agent.json` first. Cursor, Gemini CLI, OpenCode, and Cline run from the folder and write nothing. Hermes and OpenClaw use one agent per install. OpenClaw's native command is `openclaw channels add relay --token …` once its plugin ships.

## One agent per folder

A folder link works like `vercel link`. It points the folder to one saved agent. Re-running connect in a linked folder reuses that agent and prints `Linked to @handle; run connect --new for another`.

Use these options to choose the link.

```bash
npx relaymessenger connect --new
npx relaymessenger connect --profile HANDLE
```

Relay resolves an agent in this order: the folder link, `RELAY_AGENT`, then the global default. The global default is the last agent you connected. Use `--handle` when creating a new agent.

## Success

Success prints one line for each file written, then prints `Say hi from your phone` with the link and shows the QR.

## Flags

| Flag | Action |
| --- | --- |
| `--new` | Create a new agent for this folder. |
| `--profile HANDLE` | Link a saved agent. |
| `--handle <handle>` | Choose the handle for a new agent. |
| `--yes` | Accept the plan without asking. |
| `--json` | Print the non-interactive JSON result. |
| `--dry-run` | Show the plan without changing anything. |
| `--api-url <url>` | Use a different Relay API address. |

Non-interactive and CI behavior is unchanged. Use `--json` when another process reads the result.
