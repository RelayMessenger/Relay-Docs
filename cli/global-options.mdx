Select a profile and control CLI input and output.

## Before you start

- Use Node.js `22.22.3` or newer.
- Use an interactive terminal when a command asks for input.

## Choose output and input settings

```bash
relaymessenger --json agents list
relaymessenger --no-input auth status
relaymessenger --help
```

`--profile <name>` selects a saved profile. `--quiet` prints errors only. `--verbose` writes each request to stderr. `--agent <auto|yes|no>` controls coding-agent detection. Use `--install-skills` to install Relay guidance.

No environment variables are needed; RELAY_AGENT_TOKEN is honored in scripts only.

## What you get back

Captured with `relaymessenger@0.1.6-staging.6`. Help output describes the command; it does not prove a live reply.

```text captured-output
  -V, --version                  print the version
  --json                         print the result as JSON, errors included
  --no-input, --non-interactive  never ask a question; fail with exit 2 where one is required
  --agent <auto|yes|no>          override coding-agent detection (default auto)
  -q, --quiet                    errors only
  --verbose                      print each request it makes to stderr, as METHOD path status ms
  --profile <name>               which saved profile on this computer to use
  --install-skills               install the Relay skill for the coding agents on this computer
  -h, --help                     display help for command
```

## When it fails

Use the [exit-code table](/cli/index#when-it-fails) to distinguish input, missing resources, and authentication failures. `--no-input` and `--non-interactive` fail with exit 2 if a question needs an answer.
