## Usage

```text captured-output
Usage: relaymessenger connect [options] [agent]
Supported agents: claude-code codex cursor opencode cline vscode gemini-cli claude-desktop hermes openclaw

connect a coding agent to Relay, new or by token, and prove it answers

Arguments:
  agent                  Coding agent to connect (see Supported agents above)

Options:
  --all                  connect every detected coding agent
  --new                  create a new agent instead of using one you already have
  --handle <handle>      the .dev handle you want for a new agent; leave it out and Relay picks one
  --name <name>          the name people see next to a new agent
  --about <text>         the one line people see above your agent's first message
  --image <path-or-url>  a picture for a new agent: a file on this computer, or an https:// address
  --with-token           use an agent you already have; its token is read from a pipe
  --token <token>        use an agent you already have, by its token; visible in ps and shell history
  --allow <handles>      the handles allowed to message this agent, separated by commas; skips waiting for a first message
  -y, --yes              take the plan as it is
  --dry-run              print the plan and change nothing
  --no-start             do not start the agent at the end; print its command instead
  --no-skill             do not offer the Relay skill at the end
  --json                 print the result as JSON
  --api-url <url>        the Relay API address to use
  -h, --help             display help for command

Docs: https://docs.relayapp.im
Report a problem: https://github.com/RelayMessenger/Relay-SDK/issues
```

## Exit codes

```text captured-output
relaymessenger exit codes

relaymessenger follows normal conventions regarding exit codes.

- If a command completes successfully, the exit code will be 0
- If a command fails for a reason not covered by exit codes 2–4, the exit code will be 1
- If a command is given options it does not understand, or needs an answer and has no terminal, the exit code will be 2
- If the thing a command names does not exist, the exit code will be 3
- If a command needs a token and none is saved, or Relay does not accept the one it has, the exit code will be 4

Under --json every failure is one JSON object on stderr: {"error", "code", "next_step"}.
The code is Relay's numeric code as a string for an API fault, and one of
usage, not_a_tty, no_token, not_found, network, refused for a fault in this command.

Docs: https://docs.relayapp.im
Report a problem: https://github.com/RelayMessenger/Relay-SDK/issues
```
