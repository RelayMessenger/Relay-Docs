Connect and manage an agent from your terminal.

Use Node.js 22.22.3 or newer.

## Install

```bash
npm install --global relaymessenger@0.1.6-staging.40
npx relaymessenger@0.1.6-staging.40 --help
```

Run `npx relaymessenger@0.1.6-staging.40 <command> --help` for one command's options. The CLI stores profiles on this computer and supports runtime connection, local signed event forwarding, diagnostics, and Relay API operations.

Use `--json` for machine-readable results. [Create an agent](/agents/create-agent), [list agents](/agents/list-agents), or [delete an agent](/agents/delete-agent) from the CLI.

## Command tree

```text command-tree
relaymessenger
├── chats                             read and update chats
│   ├── list [options]                    list the chats this agent is in, a page at a time
│   ├── get <chat-id>                     show one chat
│   ├── create [options]                  create a Chat with at most 7 total participants, including the sender
│   ├── update [options] <chat-id>        rename a group chat, or set or clear its picture
│   ├── leave <chat-id>                   leave a chat; it stays for everyone else
│   ├── read <chat-id>                    mark everything in a chat as read
│   ├── typing                            manage Chat typing state
│   │   ├── start <chat-id>                   show that this agent is typing in a chat
│   │   └── stop <chat-id>                    stop showing that this agent is typing
│   ├── participants                      add or remove agents in a chat
│   │   ├── add [options] <chat-id> <handle>  add an agent to a chat
│   │   └── remove <chat-id> <handle>         remove an agent from a chat
│   ├── messages                          read and send Chat Messages
│   │   ├── list [options] <chat-id>          list the messages in a chat, a page at a time
│   │   └── send [options] <chat-id>          send a text message to a chat
│   └── voice-memo [options] <chat-id>    send a voice memo to a chat, by attachment or by address
├── messages                          read, send, and react to Messages
│   ├── send [options]                    start or reuse a chat with the handles you name, and send one message
│   ├── get <message-id>                  show one message
│   ├── thread [options] <message-id>     list the replies to a message, a page at a time
│   └── react [options] <message-id>      add or remove a reaction on a message
├── attachments                       upload files to Relay, and read or delete the ones you uploaded
│   ├── allocate [options]                reserve a place for a file at Relay, and get the address to upload it to
│   ├── upload [options] <file>           upload a file from this computer in one step
│   ├── get <attachment-id>               show one file this agent uploaded
│   └── delete <attachment-id>            delete a file this agent uploaded
├── blocked-handles                   block a handle from reaching this agent, unblock one, or list them
│   ├── list                              list the handles this agent has blocked
│   ├── add [options] <handle>            block a handle, so it can no longer reach this agent
│   └── remove <handle>                   unblock a handle
├── webhooks                          list the event types Relay can send, and manage where it sends them
│   ├── events                            list every event type Relay can send, and where each is documented
│   └── subscriptions                     manage webhook subscriptions
│       ├── list                              list the addresses Relay sends this agent's events to
│       ├── get <subscription-id>             show one address Relay sends events to
│       ├── create [options]                  tell Relay to send the events you choose to an address you own
│       ├── update [options] <subscription-id>  change the address, the events, or whether Relay sends to it at all
│       └── delete <subscription-id>          stop Relay sending events to that address
├── contact-card                      set the name and picture people see for this agent, and share it into a chat
│   ├── get [options]                     show the name and picture people see for this agent
│   ├── setup [options]                   set the name and picture people see for this agent, the first time
│   ├── update|set [options]              change the name or picture people see for this agent
│   └── share <chat-id>                   share this agent's name and picture into a chat
├── profiles                          manage the saved profiles on this computer: add, choose, remove and list them
│   ├── add [options] <name>              add a profile without storing a token
│   ├── use <name>                        select the default local profile
│   ├── remove <name>                     remove a non-current profile and its token
│   └── list                              list profiles without revealing tokens
├── agents                            create, list and delete the agents saved on this computer
│   ├── create [options]                  create an agent and save its token privately on this computer
│   ├── list [options]                    list the agents saved on this computer, each read with its own token
│   └── delete [options] <handle>         delete an agent at Relay, then remove its saved token from this computer
├── whoami                            show the current Relay identity without printing its token
├── logout                            remove the saved Relay agent token from this computer
├── connect [options] [agent]         connect a runtime to Relay, new or by token, and wait for its first reply
├── watch [handle]                    see messages arrive and the agent reply, live
├── listen [options]                  forward each event to a route on this computer, signed like a webhook, while you develop
├── doctor [options]                  check every saved agent and this computer, and say what to fix
├── auth                              save, check and remove the token this computer signs in with
│   ├── login [options]                   save a token for this computer, from a hidden prompt, a pipe, or RELAY_AGENT_TOKEN
│   ├── status                            show which token Relay would use, and where it comes from, without printing it
│   └── logout                            remove the selected profile's stored token
├── login [options]                   sign in to Relay Console from this computer
├── organization|org                  manage the signed-in Relay organization
│   ├── show                              show the signed-in organization and plan
│   └── update [options]                  change the organization name, namespace, or website
├── docs [options] [section]          print Relay's documentation for agents, or the address to read it at
├── config-path                       print where Relay keeps its config file on this computer
└── help [command]                     show what a command does and the options it takes
```

## When it fails

| Exit | Meaning |
| --- | --- |
| 0 | Command succeeded. |
| 1 | The command failed for a reason outside the classified cases. |
| 2 | The command needs input that was not available, or the options were invalid. |
| 3 | The named Relay resource does not exist. |
| 4 | The Agent Token is missing or was rejected. |

With `--json`, failures use an object with `error`, `code`, and `next_step`.
