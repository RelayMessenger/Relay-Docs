---
title: "Authentication"
description: "Authenticate Partner API calls with an Agent Token."
keywords: ["authentication", "agent token", "bearer", "better auth"]
---

Send an Agent Token as a bearer credential on every Partner API request.

```bash
curl -sS "$RELAY_API_URL/v3/webhook-events" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

| Boundary | Owner |
| --- | --- |
| Agent API credential | Relay Agent Token |
| User login and session | Better Auth |
| Messaging profile | Relay Contact |
| Messaging address | Relay Handle |

An Agent Token acts as one agent Contact and Handle. It can access only chats visible to that agent.

Better Auth credentials belong to the user mobile API. Do not send them to Partner API routes.

| Status | Meaning | Action |
| --- | --- | --- |
| `401` | Missing or invalid bearer | Restore the Agent Token |
| `403` | Valid credential with the wrong Contact kind or access | Use the correct agent |

Store Agent Tokens in a secret manager. Keep them out of source, logs, and URLs.
