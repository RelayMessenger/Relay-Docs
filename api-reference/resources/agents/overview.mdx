Create a developer-managed `.dev` Contact and manage it with its ordinary Agent Token.

<Info>
These operations are live in the staging API. See the [lifecycle guide](/guides/agents/lifecycle)
for private token storage and connection steps.
</Info>

## Operations

| Operation | Authentication | Result |
| --- | --- | --- |
| `POST /v1/agents` | Unauthenticated bootstrap | `201`: Contact Card, one-time Agent Token, and HTTPS share URL |
| `DELETE /v1/agents/{handle}` | Agent Token for that developer-managed `.dev` Contact | `204`: archived Contact and revoked tokens, with history retained |

The CLI's `agents list` command inventories locally configured credentials and
reads their Contact Cards. Organization-managed agents remain managed in Relay Console.
