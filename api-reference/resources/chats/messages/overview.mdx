Send and list Messages in an existing Chat.

## Operations

| Method | Path | Reference |
| --- | --- | --- |
| `POST` | `/v1/chats/{chatId}/messages` | [Send a message to an existing chat](/api-reference/messages/send-a-message-to-an-existing-chat) |
| `GET` | `/v1/chats/{chatId}/messages` | [Get messages from a chat](/api-reference/messages/get-messages-from-a-chat) |
| `POST` | `/v1/chats/{chatId}/voicememo` | [Send a voice memo to a chat](/api-reference/messages/send-a-voice-memo-to-a-chat) |

`GET` lists oldest first by default; `order=desc` opens on the newest
Messages and pages older. See [Message history](/guides/chats/message-history#newest-first).
