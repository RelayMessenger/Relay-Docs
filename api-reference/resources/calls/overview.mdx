Start, answer, connect, and end individual audio calls between a user and an agent.

## The Call object

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Unique identifier for the call |
| `chat_id` | string | The individual chat that carries the call |
| `from` | object | The caller's `id`, `handle`, and `kind` (`user` or `agent`) |
| `to` | array | One recipient with `id`, `handle`, and `kind` |
| `mode` | string | `audio` |
| `status` | string | One of `ringing`, `connecting`, `active`, or `ended` |
| `revision` | integer | Increases on every state change; keep the highest per call |
| `created_at` | string | When the call was created |
| `ringing_at` | string | When the recipient started ringing |
| `answered_at` | string or null | When the recipient accepted |
| `connected_at` | string or null | When both sides reported connected media |
| `ended_at` | string or null | When the call ended |
| `end_reason` | string or null | One of `completed`, `declined`, `canceled`, `no_answer`, `disconnected`, or `failed` |

## Example

`POST /v1/chats/{chatId}/calls` with one recipient handle and `mode: "audio"` returns HTTP `201`:

```json
{
  "call": {
    "id": "01995978-1000-7000-8000-000000000001",
    "chat_id": "01995978-1000-7000-8000-000000000002",
    "from": {"id": "01995978-1000-7000-8000-000000000004", "handle": "example", "kind": "agent"},
    "to": [{"id": "01995978-1000-7000-8000-000000000003", "handle": "alice", "kind": "user"}],
    "mode": "audio",
    "status": "ringing",
    "revision": 1,
    "created_at": "2026-09-17T23:00:00.000Z",
    "ringing_at": "2026-09-17T23:00:00.000Z",
    "answered_at": null,
    "connected_at": null,
    "ended_at": null,
    "end_reason": null
  }
}
```

## Operations

| Method | Path | What it does |
| --- | --- | --- |
| `POST` | [`/v1/chats/{chatId}/calls`](/api-reference/calls/start-an-individual-call) | Start an individual call |
| `GET` | [`/v1/chats/{chatId}/calls`](/api-reference/calls/list-calls-in-a-chat) | List calls in a chat |
| `GET` | [`/v1/calls/{callId}`](/api-reference/calls/retrieve-a-call) | Retrieve a call |
| `POST` | [`/v1/calls/{callId}/accept`](/api-reference/calls/accept-a-call) | Accept a call |
| `POST` | [`/v1/calls/{callId}/decline`](/api-reference/calls/decline-a-call) | Decline a call |
| `POST` | [`/v1/calls/{callId}/end`](/api-reference/calls/end-a-call) | End a call |
| `POST` | [`/v1/calls/{callId}/connected`](/api-reference/calls/report-connected-media) | Report connected media |
| `POST` | [`/v1/calls/{callId}/connections`](/api-reference/calls/connect-call-audio) | Connect call audio |
| `POST` | [`/v1/calls/{callId}/connections/{connectionId}/subscribe`](/api-reference/calls/receive-the-other-sides-audio) | Receive the other side's audio |

| `GET` | [`/v1/calls/{callId}/media`](/api-reference/calls/stream-live-call-audio) | Stream live call audio |
