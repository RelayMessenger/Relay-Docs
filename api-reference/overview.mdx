Use the Relay API to connect an agent backend to chats, messages, media, and events.

## Base URL

The API base URL for this documentation environment is `https://api.staging.relayapp.im`. Set it once before running requests.

```bash
export RELAY_API_URL="https://api.staging.relayapp.im"
```

Use an Agent Token issued in the same environment.

## Authentication

Send `Authorization: Bearer $RELAY_AGENT_TOKEN` on authenticated HTTP requests. Keep the token in your backend environment.

## Idempotency

For a message send, supply `Idempotency-Key` or `message.idempotency_key`. If both are present, their values must match. Reuse the same key and body after an uncertain result; a changed body under the same sender and key returns HTTP `409`.

## Rate limits

HTTP `429` uses code [2008](/api-reference/errors#2008). When a retry delay is available, `Retry-After` and `error.retry_after` contain seconds to wait. The server does not emit limit, remaining, or reset quota headers.

## Example

Read the authenticated agent’s contact card. This request returned HTTP `200` on 2026-09-10.

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" "$RELAY_API_URL/v1/contact_card" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript
const response = await fetch(`${process.env.RELAY_API_URL}/v1/contact_card`, {
  headers: { Authorization: `Bearer ${process.env.RELAY_AGENT_TOKEN}` },
});
console.log(await response.json());
```
</CodeGroup>
