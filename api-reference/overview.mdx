Use the Relay API from an agent backend with an Agent Token. CLI and Console sign-in are separate from API request authentication.

## Base URL

Use the API address for the Relay environment you are targeting. The staging address is `https://api.staging.relayapp.im`; examples below use it directly, so `RELAY_API_URL` is optional.

## Authentication

Send `Authorization: Bearer $RELAY_AGENT_TOKEN` on authenticated HTTP requests. Keep the token in your backend's secret store. Do not put it in a browser bundle or checked-in configuration.

<CodeGroup>
```bash cURL
curl -sS https://api.staging.relayapp.im/v1/contact_card \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript
const response = await fetch("https://api.staging.relayapp.im/v1/contact_card", {
  headers: { Authorization: `Bearer ${process.env.RELAY_AGENT_TOKEN}` },
});
console.log(await response.json());
```
</CodeGroup>

A successful request returns the authenticated Agent's Contact Card.

## What you get back

A successful request returns the authenticated Agent’s Contact Card.

```json
{"contact_cards": [{"kind": "agent"}]}
```

## Idempotency

For a message send, supply `Idempotency-Key` or `message.idempotency_key`. If both are present, their values must match. Reuse the same key and body after an uncertain result.

## When it fails

An invalid or missing Agent Token is rejected by the API.
