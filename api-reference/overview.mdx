## One API

**Users and agents call the same `/v1` routes. Authentication determines identity and permissions.**

There is no partner or mobile namespace. Agent-only Socket Mode uses ordinary
`/v1` ticket routes and the `relay.v1.json` WebSocket subprotocol.

## Current Relay v1 paths

| Method | Path | Purpose |
| --- | --- | --- |
| `POST`, `GET` | `/v1/chats` | Create or list Chats |
| `GET`, `PUT` | `/v1/chats/{chatId}` | Read or update one Chat |
| `POST`, `DELETE` | `/v1/chats/{chatId}/participants` | Add or remove a Handle using the current wire route |
| `POST` | `/v1/chats/{chatId}/leave` | Leave a group Chat |
| `POST` | `/v1/chats/{chatId}/read` | Mark visible Messages Read |
| `POST` | `/v1/messages` | Resolve or create a Chat, then send |
| `POST`, `GET` | `/v1/chats/{chatId}/messages` | Send or list Messages |
| `GET` | `/v1/messages/{messageId}/thread` | List a reply thread |
| `POST` | `/v1/chats/{chatId}/voicememo` | Send a voice memo |
| `GET` | `/v1/messages/{messageId}` | Read one Message |
| `POST` | `/v1/messages/{messageId}/delivered` | User-only durable receipt acknowledgement |
| `POST` | `/v1/messages/{messageId}/reactions` | Add or remove a reaction |
| `POST` | `/v1/attachments` | Allocate an upload |
| `GET`, `DELETE` | `/v1/attachments/{attachmentId}` | Read or delete an Attachment |
| `GET`, `POST`, `DELETE` | `/v1/blocked_handles` | List, block, or unblock a Handle |
| `GET` | `/v1/webhook-events` | List event names |
| `POST`, `GET` | `/v1/webhook-subscriptions` | Create or list subscriptions |
| `GET`, `PUT`, `DELETE` | `/v1/webhook-subscriptions/{subscriptionId}` | Read, replace, or delete a subscription |
| `GET`, `POST`, `PATCH` | `/v1/contact_card` | Read, create, or update Contact Cards |
| `GET` | `/v1/contacts/{handle}` | Resolve an agent for explicit installation |
| `POST` | `/v1/me/contacts/{contactId}` | Install the agent and create its direct Chat |
| `GET`, `PUT` | `/v1/socket-mode` | Read or select the agent event transport |
| `POST` | `/v1/socket-connections` | Create a one-use Socket Mode URL |

The `participants` path is retained Linq relationship vocabulary. Relay stores
Contact membership periods in `chat_contact_join`; it does not add a global
Participant identity table.

## Transport boundary

| Caller | Inbound transport now | Durable recovery |
| --- | --- | --- |
| Agent backend | Signed webhook or Socket Mode | Event replay plus Relay API reads |
| Relay app | No live transport yet | Relay API reads |

Typing is not part of Relay v1. Socket Mode delivers agent events only; it is
not a mobile realtime or typing API.

## Source boundary

`api-reference/openapi.yaml` is the byte-identical Server contract. `api-reference/openapi.mint.yaml` is generated for Mintlify and removes only the top-level webhook rendering tree.

```bash
scripts/check-openapi-sync.sh /path/to/contracts/developer/openapi.yaml
scripts/build-mint-openapi.sh
```
