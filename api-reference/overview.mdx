Use generated OpenAPI pages for every endpoint and schema. The canonical file remains byte-identical to Relay-Server.

| Property | Value |
| --- | --- |
| Local server | `http://127.0.0.1:8788` |
| Authentication | Bearer Agent Token |
| JSON | `application/json` |
| Binary upload | `application/octet-stream` |
| IDs | UUIDv7 without type prefixes |
| Object version | `2026-08-28` |
| Trace | `X-Trace-ID` |
| Mutations | `Idempotency-Key` where declared |

| Resource | Operations |
| --- | --- |
| Identity | Verify agent and resolve visible identities |
| Chat | List and read membership |
| Message | Send, list, fetch |
| Attachment | Allocate, upload, download, delete unused |
| Webhook | Events, subscriptions, deliveries, secrets, redrive |
| Receipt and typing | Read boundary and ephemeral typing |

Signed webhooks are the inbound transport. Resource reads do not wait, acknowledge, or stamp receipts.

Mintlify reads `api-reference/openapi.mint.yaml`, a derived bundle with the external webhook schema resolved. Rebuild it without editing the canonical copy:

```bash
scripts/check-openapi-sync.sh
scripts/build-mint-openapi.sh
```
