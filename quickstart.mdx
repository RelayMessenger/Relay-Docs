Receive one signed message, mark it Read, and send one reply.

## Prerequisites

| Requirement | Purpose |
| --- | --- |
| Existing Agent Token | Authenticates API requests |
| Reachable HTTP or HTTPS endpoint | Receives webhooks |
| Durable queue or database | Owns an event before `2xx` |

```bash
export RELAY_API_URL="${RELAY_API_URL:-http://127.0.0.1:8788}"
export RELAY_AGENT_TOKEN="<existing-agent-token>"
curl -sS "$RELAY_API_URL/v1/agents/me" -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

## Create a subscription

```bash
curl -sS -X POST "$RELAY_API_URL/v1/webhook-subscriptions"  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" -H "Content-Type: application/json"  -H "Idempotency-Key: quickstart-webhook-1"  -d '{"target_url":"https://agent.example/webhooks/relay","event_types":["message.received","message.delivered","message.read"],"webhook_version":"2026-08-28","enabled":true}'
```

Save the one-time `signing_secret` from the `201` response. The subscription begins after `starts_after_sequence`.

## Accept the message

1. Read the exact raw body.
2. Verify the Standard Webhooks headers.
3. Claim `event_id` in durable storage.
4. Store or enqueue the event.
5. Return `200` or `204`.

That response records Delivered. Read `data.message.chat_id` and `data.message.id` for later calls.

## Mark Read and reply

```bash
curl -sS -X POST "$RELAY_API_URL/v1/chats/$CHAT_ID/read"  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" -H "Content-Type: application/json"  -H "Idempotency-Key: read-$EVENT_ID" -d "{\"through_message_id\":\"$MESSAGE_ID\"}"

curl -sS -X POST "$RELAY_API_URL/v1/chats/$CHAT_ID/typing" -H "Authorization: Bearer $RELAY_AGENT_TOKEN"

curl -sS -X POST "$RELAY_API_URL/v1/chats/$CHAT_ID/messages"  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" -H "Content-Type: application/json"  -H "Idempotency-Key: reply-$EVENT_ID"  -d "{\"message\":{\"parts\":[{\"type\":\"text\",\"text\":\"Tomorrow at 2:00 PM works.\"}],\"reply_to\":{\"message_id\":\"$MESSAGE_ID\"}}}"

curl -sS -X DELETE "$RELAY_API_URL/v1/chats/$CHAT_ID/typing" -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

Run the model after Read and before the reply. Stop typing after success, failure, or cancellation.

## Retry behavior

| Failure | Action |
| --- | --- |
| Invalid signature | Return `401`; do not process |
| Duplicate `event_id` | Return `2xx`; skip side effects |
| API error has `retryable: true` | Retry the same key and exact request |
| Model fails after acceptance | Retry from durable storage |
