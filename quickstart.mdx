Receive one user message and send one agent reply.

## Prerequisites

| Requirement | Purpose |
| --- | --- |
| Agent Token | Authenticates Partner API calls |
| HTTPS endpoint | Receives agent events |
| Durable storage | Saves an event before acknowledgement |

```bash
export RELAY_API_URL="https://api.relayapp.im/api/partner"
export RELAY_AGENT_TOKEN="<agent-token>"

curl -sS "$RELAY_API_URL/v3/webhook-events" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

## Create a subscription

```bash
curl -sS -X POST "$RELAY_API_URL/v3/webhook-subscriptions" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "target_url": "https://agent.example/webhooks/relay",
    "subscribed_events": ["message.received"]
  }'
```

Save `signing_secret` from the `201` response. Relay shows it once.

## Accept a message

<Steps>
<Step title="Read the raw body">
Keep the exact request bytes for signature verification.
</Step>
<Step title="Verify the signature">
Verify `webhook-id`, `webhook-timestamp`, and `webhook-signature`.
</Step>
<Step title="Save the event">
Deduplicate with `event_id`, then commit the event or enqueue it durably.
</Step>
<Step title="Return success">
Return `200` or `204` within 10 seconds. This records Delivered for the agent recipient.
</Step>
</Steps>

Read `data.chat.id` and `data.id` from the `message.received` envelope.

## Mark Read and reply

```bash
curl -sS -X POST "$RELAY_API_URL/v3/chats/$CHAT_ID/read" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"

curl -sS -X POST "$RELAY_API_URL/v3/chats/$CHAT_ID/typing" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"

curl -sS -X POST "$RELAY_API_URL/v3/chats/$CHAT_ID/messages" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: reply-$EVENT_ID" \
  --data-binary @- <<JSON
{
  "message": {
    "parts": [{"type":"text","value":"Tomorrow at 2:00 PM works."}],
    "reply_to": {"message_id":"$MESSAGE_ID","part_index":0}
  }
}
JSON

curl -sS -X DELETE "$RELAY_API_URL/v3/chats/$CHAT_ID/typing" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

## Failure handling

| Failure | Action |
| --- | --- |
| Invalid signature | Return `401` and stop |
| Duplicate `event_id` | Return `2xx` without repeating side effects |
| Model failure | Retry from your saved event |
| Uncertain send response | Reuse the same idempotency key and request |
