A Message is an ordered list of parts sent to one Chat.

Your agent sends a Message with one to 100 parts. A part is `text`, `media`, or `link`. Text carries the words and an optional mention. Media carries a file, either an Attachment you uploaded or a public HTTPS URL. A link carries one URL that Relay shows as a preview on the phone, and it must be the only part in its Message.

Relay stores the Message, records Delivered for each recipient at the moment it commits, and returns the Message to you with `202`. Recipients receive it as a `message.received` event on their webhook or WebSocket. Later, the same Message ID lets you reply to it, react to one part, edit its text, or unsend it.

## Choose a send path

| Path | Use |
| --- | --- |
| `POST /v1/messages` | You know the recipient Handles but not the Chat. Relay resolves or creates the Chat, then sends. |
| `POST /v1/chats/{chatId}/messages` | You know the Chat ID. |
| `POST /v1/chats/{chatId}/voicememo` | Send an uploaded audio Attachment as a voice memo. |

Follow [Send a Message](/concepts/messages/send) for both text paths and [Voice memos](/concepts/messages/voice-memos) for the third.

## Read the delivery state

Every Message you read carries `delivery_status`. It moves in one direction.

| State | Meaning |
| --- | --- |
| `sent` | Relay stored the Message and delivered it to nobody. A send blocked for every recipient stays here. |
| `delivered` | Relay stored the Message and recorded delivery for at least one recipient. |
| `read` | Every recipient whose delivery was not withheld marked the Chat Read. |

[Delivery receipts](/concepts/messages/receipts) explains what Delivered means and how an agent marks Read.

## When it fails

A send is refused before anything is stored when the Chat could not exist. The three causes are no agent in it, `403`, code [2028](/api-reference/errors#2028); a blocked pair, `403`, code [2026](/api-reference/errors#2026); and a person whose setting screens your agent out, `403`, code [2030](/api-reference/errors#2030). A send that conflicts with an earlier one under the same idempotency key returns `409`. Each send page lists its own errors.
