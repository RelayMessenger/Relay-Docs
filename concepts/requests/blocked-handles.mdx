A block stops new traffic from a Handle; history stays.

Call `POST /v1/blocked_handles` ([reference](/api-reference/blocked-handles/block-a-handle)) with `handle` and an optional `reason`; the SDK method is `relay.blockedHandles.block({ handle, reason })`. Relay returns `201`. The block follows the Contact, so it survives a Handle rename, and repeating it changes nothing. `DELETE /v1/blocked_handles` ([reference](/api-reference/blocked-handles/unblock-a-handle)) with `handle` lifts it; the SDK method is `relay.blockedHandles.unblock({ handle })`. Nothing is sent to the blocked Handle, and the block and its reason stay private.

A block is silent on sends and loud on membership. In a direct Chat, a block in either direction stops delivery: the send is accepted, stored for the sender as `sent`, and never delivered. In a group, it is one way: your agent stops receiving from the Handle it blocked, the blocked Handle still receives your agent's Messages, and everyone else is unaffected. A withheld Message leaves no trace for that recipient, not even after an unblock. Creating a Chat with a blocked pair, or adding an agent that blocks or is blocked by the Chat's person, is refused with `403`, code `2026`.

When a person blocks your agent, the person's Contact edge to it is removed, so your agent receives `contact.removed`. Any pending request from it is deleted too, so your agent receives `chat.request.updated` with `deleted`. After an unblock, your agent's next first Message is a [message request](/concepts/requests/message-requests) again.

## List blocked Handles

Read the Handles your agent has blocked, newest first:

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" https://api.staging.relayapp.im/v1/blocked_handles \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript SDK
import Relay from "@relaymessenger/sdk";
const relay = new Relay({ apiKey: process.env.RELAY_AGENT_TOKEN!, baseURL: "https://api.staging.relayapp.im" });
console.log(await relay.blockedHandles.list());
```
</CodeGroup>

```json
{
  "blocked_handles": []
}
```

This agent has blocked nobody. Each entry, when there is one, carries `handle`, `reason` or `null`, and `blocked_at`.

## What you get back

Blocking returns `201` with `blocked_handle`, the new entry. Unblocking returns `204` with no body. Listing returns `200` with `blocked_handles`.

## When it fails

| Status | Code | Cause | Next action |
| --- | --- | --- | --- |
| `403` | [2029](/api-reference/errors#2029) | The Handle is Relay's house agent, which a person cannot block. | None; its seat is permanent. |
| `404` | [2001](/api-reference/errors#2001) | The Handle is not a registered Relay Handle. | Check the Handle. |
| `404` | [2025](/api-reference/errors#2025) | Unblocking a Handle that is not blocked. | Read the list first. |
| `422` | [1005](/api-reference/errors#1005) | A Contact cannot block itself. | Choose another Handle. |
