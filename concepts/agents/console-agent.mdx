An organization agent lives under your organization's namespace: the handle `forecast` becomes `forecast.yourorg`. You create it in Relay Console, copy its token once, and give the token to your backend. For a `.dev` agent that belongs to you alone, use [Create an agent](/concepts/agents/create-agent) instead.

## Before you start

- A [Relay Console](https://console.staging.relayapp.im) account with permission to create agents in your organization.
- Private server-side storage for the Agent Token.

## Create the agent

Open **Create agent** in Relay Console and fill in the identity fields:

| Field | What to enter |
| --- | --- |
| Name | The name people see beside the agent on their phone. |
| Handle | The part before your organization's namespace: 3 to 32 lowercase letters, numbers, or underscores, starting with a letter. |
| About | One optional line people see above the agent's first message. |

Press **Create agent**. To set the picture, follow [Profile photos](/concepts/identity/profile-photos).

## Choose a connection and save the token

<Steps>
  <Step title="Choose your connection">
    Select **WebSocket** or **Webhook**. Follow the
    [WebSocket](/events/websocket) or [Webhooks](/events/webhooks) guide for the
    connection you choose.
  </Step>
  <Step title="Copy the Agent Token">
    In **Connect your backend**, choose **Manually**, then **Copy token**.
    Store the token in private server-side storage before you close the dialog.
    Console shows the full token once.
  </Step>
  <Step title="Connect your backend">
    Use the saved token with the matching API origin,
    `https://api.staging.relayapp.im` for the Console linked above.
    Send the agent a message from your phone and confirm the reply arrives.
  </Step>
</Steps>

## When it fails

| Outcome | Next action |
| --- | --- |
| Creation result is uncertain | Check your organization's agent list before you submit another create. |
| Agent created, picture upload failed | Keep the agent and retry the picture from its **Settings** page. |
| Token was not saved | Open the agent's **Settings**, find **agent token**, and choose **Rotate token**. The old token stops working the moment the new one exists, so update your backend at once. |
| Backend connection failed | Keep the agent and token; follow the connection guide's own failure section. |
