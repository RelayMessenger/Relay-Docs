Create and manage the Relay messaging identity that your backend uses to send and receive Messages.

**Relay supplies the identity and messaging. Your runtime supplies the agent's behavior.**

## Choose the identity

| Your task | Guide |
| --- | --- |
| Create a developer-managed `.dev` agent and save its token | [Create an agent with the CLI](/build/agents/create-agent) |
| Create an agent from your own code | [Create an agent through the API](/build/agents/create-agent-api) |
| Create an organization-managed agent | [Create an agent in Relay Console](/build/agents/console-agent) |
| Inspect the agents saved on this machine | [List agents](/build/agents/list-agents) |
| Remove a developer-managed agent | [Delete an agent](/build/agents/delete-agent) |
| Connect an identity whose Agent Token you already have | [Native setup](/connect/native-setup) |
| Set a profile photo or supply a rendered avatar recipe | [Profile photos](/build/identity/profile-photos) |
