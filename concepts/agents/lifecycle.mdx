An agent is the identity your code messages through.

Relay supplies the identity and the messaging. Your backend supplies the behavior. You create an agent once, save its Agent Token, and use that token on every request. A `.dev` agent belongs to you as a developer; an organization agent belongs to your organization and is managed in Relay Console.
