Use the same messaging surface from your backend. Set `RELAY_AGENT_TOKEN` in your environment, then install the SDK if you want the TypeScript version.

```bash
npm install @relaymessenger/sdk@staging
```

```typescript
import Relay from "@relaymessenger/sdk";

const relay = new Relay({
  apiKey: process.env.RELAY_AGENT_TOKEN!,
  baseURL: "https://api.staging.relayapp.im",
});
```

### Find a chat

List one chat belonging to your agent.

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" \
  "https://api.staging.relayapp.im/v1/chats?limit=1" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript SDK
const page = await relay.chats.listChats({ limit: 1 });
console.log(page);
```
</CodeGroup>

### Send the first message

Replace `RECIPIENT_HANDLE` with the person you want to message. This call resolves an existing chat or creates one. A new chat can arrive as a message request.

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" \
  "https://api.staging.relayapp.im/v1/messages" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"to":["RECIPIENT_HANDLE"],"message":{"parts":[{"type":"text","value":"Hello from my agent."}]}}'
```

```typescript TypeScript SDK
const sent = await relay.messages.create({
  to: ["RECIPIENT_HANDLE"],
  message: { parts: [{ type: "text", value: "Hello from my agent." }] },
});
console.log(sent);
```
</CodeGroup>

(unverified: sending to a recipient was not performed because no test recipient was provisioned for this run 2026-09-11)

**What you see** on success is the message with `chat_id` and `created_new_chat`. Store the chat ID for follow-ups. No successful send response is asserted here.

### Send a follow-up

Set `CHAT_ID` to the returned chat ID. Use a fresh idempotency key for each logical message, and reuse that key when retrying the same message.

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" \
  "https://api.staging.relayapp.im/v1/chats/$CHAT_ID/messages" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"message":{"parts":[{"type":"text","value":"The report is ready."}]}}' \
  -H "Idempotency-Key: message-018f"
```

```typescript TypeScript SDK
const followUp = await relay.chats.messages.send(process.env.CHAT_ID!, {
  message: {
    parts: [{ type: "text", value: "The report is ready." }],
    idempotency_key: "message-018f",
  },
});
console.log(followUp);
```
</CodeGroup>

(unverified: follow-up send and duplicate-key retry were not executed to avoid changing the existing chat 2026-09-11)

**What you see** on success is the sent message. [Sending messages](/concepts/messages/send) covers keys and retries.

### Read history

Read one message from the captured chat. Replace this chat ID with yours. The default order is oldest first.

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" \
  "https://api.staging.relayapp.im/v1/chats/01a08e5a-13cd-707f-ad0b-29eec3010341/messages?limit=1" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript SDK
const history = await relay.chats.messages.list(
  "01a08e5a-13cd-707f-ad0b-29eec3010341", { limit: 1 },
);
console.log(history);
```
</CodeGroup>

**What you see** is a page of messages. The cURL request returned HTTP 200 on 2026-09-11.
