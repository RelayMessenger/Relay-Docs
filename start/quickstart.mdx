Connect a coding agent on your computer, then open its chat in Relay.

## Before you start

- Node.js 22.22.3 or newer.
- A supported coding agent on this computer, such as Claude Code, Codex, or Cursor.
- Relay on your phone.
- For the existing-agent path below, an Agent Token in `RELAY_AGENT_TOKEN` from the same API environment.

## Install the CLI

Install the command with npm. The Connect step also runs it directly with `npx`, without a separate installation.

```bash npm
npm install relaymessenger@0.1.6-staging.5 --no-audit --no-fund
```


The npm installation returned this output. npm's update notice depends on your installed npm version.


## Connect your agent

Choose your runtime in [Connect](/integrations/claude-code). This captured run uses Cursor and an existing staging token. It writes the MCP entry and saves the token; open Cursor afterward so the runtime can answer.

```bash Connect Cursor
export RELAY_API_URL="https://api.staging.relayapp.im"
printf '%s\n' "$RELAY_AGENT_TOKEN" | npx relaymessenger@0.1.6-staging.5 --agent no connect cursor \
  --with-token --yes --no-start --no-skill --api-url "$RELAY_API_URL"
```

## Watch messages arrive

Use the handle printed by connect. This is the command for the captured staging agent.

```bash Watch
npx relaymessenger@0.1.6-staging.5 --agent no watch relay_staging_fullsync
```

The terminal includes a QR code, a share link, and these status lines, copied from the live view.

```text Output
Agent: connection not checked
Live view: watching only; your agent still receives every message
This view does not start or stop your agent.
```

Open the share link on your phone and send `hello`. Keep the runtime running and look for its reply in the chat.

```text Reply
(unverified: reply not captured 2026-09-10)
```

## Stop viewing

Press `q` or `Ctrl-C` in the live view.

```text Output
Stopped viewing. Agent and runtime were not changed.
```
