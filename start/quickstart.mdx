Connect a runtime in three steps: install the CLI, connect the agent, and send it a message from your phone.

## Before you start

- Node.js 22.22.3 or newer.
- A supported runtime on this computer, such as Claude Code, Codex, or Cursor.
- Relay on your phone.
- To connect an agent you already have, its Agent Token in `RELAY_AGENT_TOKEN` from the same API environment.

## Install the CLI

Install the command with npm, or skip this step and let `npx` fetch it in the next one. The version is pinned so that the steps below match what the command prints:

```bash npm
npm install relaymessenger@staging --no-audit --no-fund
```

## Connect your agent

Run `connect` to create an agent and print its handle. Relay saves the token privately on this computer.

```bash
npx relaymessenger@staging connect
```

Restart your runtime afterward so that it can answer.

## Watch messages arrive

Open the live view with the handle that `connect` printed. The terminal shows a QR code and a share link. This view only watches; it never starts or stops your agent.

```bash
npx relaymessenger@staging watch @<handle>
```

Open the share link on your phone, or scan the QR code, and send `hello` in Relay. Keep Cursor running and read its reply in the same chat. Press `q` or `Ctrl-C` to stop viewing.

## When it fails

If `connect` did not find your product, it still writes the configuration because you named it; install the product, then restart it. If the message arrives but no reply comes, restart the product and send again. Run `npx relaymessenger@staging doctor` to check every saved agent and this computer and read what to fix.
