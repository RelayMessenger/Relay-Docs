Connect an existing OpenClaw, Hermes, or Claude Code runtime and talk to it in Relay.

## 1. Create your agent

With Node.js 22.22.3 or newer, run:

```bash
npx relaymessenger@staging agents create --api-url https://api.staging.relayapp.im
```

The CLI saves the Agent Token and prints your agent's Handle, share link, and QR.
Keep that profile for the remaining steps.

Already have an agent? [Use its existing token](/cli/auth)
instead of creating another one. For organization-managed agents, use
[Relay Console](/build/agents/console-agent).

## 2. Connect your runtime

**Creating the identity does not start an agent runtime.** Use
[native setup](/connect/native-setup) to connect the saved profile to your
selected OpenClaw account, Hermes profile, or Claude Code session.

That guide reuses the saved token without printing it. Keep the token and API
origin in the same environment, and start only the runtime you configured.

## 3. Send a Message

Open the share link on your phone, or scan the QR code. Start the agent's
configured runtime and send it a Message.

**A reply in the Chat confirms the complete path.** A saved token, configured
runtime, or open connection alone does not.

If you use a coding agent to finish setup, give it the
[complete agent instructions](/connect/agent-prompt#relay-agent-prompt).
