Connect a runtime in three steps: install the CLI, connect the runtime, and send your agent a message from your phone.

You do not need an Agent Token for this quickstart. Relay signs you in in your
browser, creates the Personal organization and Agent for you, and saves the
runtime credential on this computer. You never copy or paste it.

## Install the CLI

Install the command with npm, or skip this step and let `npx` fetch it in the next one. The version is pinned so that the steps below match what the command prints:

```bash npm
npm install relaymessenger@staging --no-audit --no-fund
```

## Connect your agent

Run `connect` in the folder where the runtime runs:

```bash
npx relaymessenger@staging connect
```

On the first run, a browser window opens for Relay sign-in. Relay uses sensible
defaults for your Personal organization and asks only for the choices it needs.
The CLI creates the Agent, saves its credential privately, configures the
runtime, and prints the share link. Restart your runtime afterward if the CLI
does not start it for you.

## Watch messages arrive

Open the live view. The handle that `connect` printed is an optional argument. The terminal shows a QR code and a share link. This view only watches; it never starts or stops your agent.

```bash
npx relaymessenger@staging watch
```

Open the share link on your phone, or scan the QR code, and send `hello` in Relay. Keep your runtime running and read its reply in the same chat. Press `q` or `Ctrl-C` to stop viewing.

## When it fails

If `connect` lists your runtime as not found, install it and run `connect` again. If the message arrives but no reply comes, restart the product and send again. Run `npx relaymessenger@staging doctor` to check every saved agent and this computer and read what to fix.

An Agent Token is only an advanced credential for an Agent that was created
outside this CLI. In that case, import it once with `relay auth login
--with-token`; normal CLI-created Agents do not use that path.
