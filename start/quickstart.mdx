Connect a runtime in three steps: install the CLI, connect the agent, and send it a message from your phone.

## Before you start

- Node.js 22.22.3 or newer.
- A supported runtime on this computer, such as Claude Code, Codex, or Cursor.
- Relay on your phone.
- To connect an agent you already have, its Agent Token in `RELAY_AGENT_TOKEN` from the same API environment.

## Install the CLI

Install the command with npm, or skip this step and let `npx` fetch it in the next one. The version is pinned so that the steps below match what the command prints:

```bash npm
npm install relaymessenger@0.1.6-staging.5 --no-audit --no-fund
```

## Connect your agent

Run `connect` with the id of your product. This example connects Cursor to an agent you already have, reading its token from a pipe so that it never lands in your shell history. Relay adds itself to Cursor's configuration and saves the token privately on this computer.

```bash Connect Cursor
export RELAY_API_URL="https://api.staging.relayapp.im"
printf '%s\n' "$RELAY_AGENT_TOKEN" | npx relaymessenger@0.1.6-staging.5 --agent no connect cursor \
  --with-token --yes --no-start --no-skill --api-url "$RELAY_API_URL"
```

To create a new agent instead, leave out `--with-token` and Relay picks a handle. For another product, use its id from [Connect](/integrations/claude-code) in place of `cursor`. Restart Cursor afterward so that it can answer.

## Watch messages arrive

Open the live view with the handle that `connect` printed. The terminal shows a QR code and a share link. This view only watches; it never starts or stops your agent.

```bash Watch
npx relaymessenger@0.1.6-staging.5 --agent no watch relay_staging_fullsync
```

Open the share link on your phone, or scan the QR code, and send `hello` in Relay. Keep Cursor running and read its reply in the same chat. Press `q` or `Ctrl-C` to stop viewing.

## When it fails

If `connect` did not find your product, it still writes the configuration because you named it; install the product, then restart it. If the message arrives but no reply comes, restart the product and send again. Run `npx relaymessenger@0.1.6-staging.5 doctor` to check every saved agent and this computer and read what to fix.
