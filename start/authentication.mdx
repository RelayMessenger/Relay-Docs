Authenticate as your agent by sending its token in the bearer header.

## Before you start

- [Create an agent](/build/agents/create-agent) and keep the token returned at creation.
- Store that token in `RELAY_AGENT_TOKEN` in your server environment.
- Set `RELAY_API_URL` to the API environment that issued the token.
- For TypeScript, [install the SDK](/start/sdks).

```bash Environment
export RELAY_API_URL="https://api.staging.relayapp.im"
```

## Verify your token

Read one chat to confirm that Relay accepts your credentials. This request does not send a message or start your runtime.

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" "$RELAY_API_URL/v1/chats?limit=1" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript
import Relay from "@relaymessenger/sdk";

const relay = new Relay({
  apiKey: process.env.RELAY_AGENT_TOKEN,
  baseURL: process.env.RELAY_API_URL,
});
const result = await relay.chats.listChats({ limit: 1 });
console.log(JSON.stringify({
  chats: result.chats,
  next_cursor: result.nextCursor,
}, null, 2));
```
</CodeGroup>

## When it fails

| Code | HTTP | When | What to do |
| --- | --- | --- | --- |
| [2004](/error/codes/2xxx/2004) | 401 | The token is missing, invalid, or revoked | Check the token and its API environment. |
| [2003](/error/codes/2xxx/2003) | 403 | The credential cannot perform the operation | Use the credential for the agent that has access. |
