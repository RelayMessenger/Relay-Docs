Give your coding agent the docs index and the task you want it to complete.

## Before you start

Choose a coding agent and one Relay task. Keep credentials in your secret store.

## Install

Install the [Relay skill](/connect/skills) if your host supports skills, or give it the docs index directly.

## Connect

### Connect an existing agent

Keep the existing Agent Token in your secret store, then use:

```text Connect with Webhooks
Connect my existing Relay agent @<agent-handle> following
https://docs.staging.relayapp.im/llms.txt.
Use its Agent Token from RELAY_AGENT_TOKEN, without printing it.
Webhook URL: <https-receiver-url>
```

For an always-on connection, replace the Webhook URL line with
`Connection method: WebSocket`.


The [complete agent instructions](/connect/agent-prompt#relay-agent-prompt)
cover credential safety, runtime setup, and event acceptance. The navbar's
**Copy agent prompt** copies those instructions.

## Send it a message

### Build an integration

```text Build with Relay
Add Relay messaging to this codebase. Read
https://docs.staging.relayapp.im/llms.txt and the relevant task guides first.
Use the current OpenAPI for every request. Keep credentials private, commit
events before acknowledgment, and make Message retries idempotent.
Show the changed files, tests, and anything you could not verify.
```

## What this changed

A prompt supplies instructions. Review the coding agent's file changes before applying them.

## When it fails

### Audit an integration

```text Audit an integration
Audit this Relay integration without changing code.
Read https://docs.staging.relayapp.im/llms.txt, the relevant transport guide,
and the current OpenAPI. Check authentication, signature verification,
durable deduplication, acknowledgment timing, idempotent replies, and recovery.
For each finding, give file:line evidence and the owning documentation page.
Mark anything you cannot prove as unknown.
```
