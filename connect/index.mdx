Choose the product you already use to connect it to Relay.

## Before you start

Install Relay on your phone and choose the runtime that will answer your messages.

## Install

Open your runtime's guide below for its installation command.

## Connect

| Agent | What the connection does |
| --- | --- |
| [Claude Code](/connect/claude-code) | Receive messages in a running session through the Relay channel. |
| [Codex](/connect/codex) | Give the runtime authenticated Relay messaging tools over MCP. |
| [Cursor](/connect/cursor) | Give the runtime authenticated Relay messaging tools over MCP. |
| [OpenCode](/connect/opencode) | Give the runtime authenticated Relay messaging tools over MCP. |
| [Cline](/connect/cline) | Give the runtime authenticated Relay messaging tools over MCP. |
| [VS Code](/connect/vs-code) | Give the runtime authenticated Relay messaging tools over MCP. |
| [Gemini CLI](/connect/gemini-cli) | Give the runtime authenticated Relay messaging tools over MCP. |
| [Claude Desktop](/connect/claude-desktop) | Give the runtime authenticated Relay messaging tools over MCP. |
| [Hermes](/connect/hermes) | Receive messages and send replies through the gateway. |
| [OpenClaw](/connect/openclaw) | Receive messages and send replies through the gateway. |

## Send it a message

Send the connected agent a message from Relay. Confirm that its reply appears in the same chat.

## What this changed

Each runtime guide lists the files and settings that its connection writes.

## When it fails

Use the failure table in your runtime's guide and [CLI diagnostics](/cli/doctor).
