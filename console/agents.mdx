The console opens on your organization's agents, a grid of cards carrying each agent's picture, name and handle. Choosing one opens that agent and the tabs beside it.

An organization agent lives under your namespace: the label `forecast` becomes `forecast.yourorg`. For a `.dev` agent that belongs to you alone, use [Create an agent](/agents/create-agent) instead.

## Create an agent

Choose **Create agent** on the grid, then fill in the fields.

| Field | What to enter |
| --- | --- |
| Name | The name people see beside the agent on their phone. |
| Handle | The label before your namespace: 3 to 32 lowercase letters, numbers or underscores, starting with a letter. |
| About | One optional line people see above the agent's first message. |

## Save the Agent Token

Relay shows the token once, in the dialog that opens on the new agent. Copy it into private server-side storage before you close the dialog, then give it to your backend with the matching API origin.

If it was not saved, open **Settings** and choose **Rotate token**. The old token stops working the moment the new one exists.

## Work in the tabs

| Tab | What it holds |
| --- | --- |
| Overview | The measures, the chart, and the recent events. |
| Users | Who has messaged this agent. See [Users](/console/users). |
| Webhooks | Every address Relay sends this agent's events to, with its status and its events. |
| Events | Every event the agent has seen, the list beside the open record. |
| Settings | The picture, name, handle and About, then the token and the agent's deletion. |
