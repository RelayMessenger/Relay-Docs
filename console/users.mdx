The Users tab lists the people who have messaged the selected agent. Someone appears here the first time they message it. The list belongs to one agent, so choosing another agent in the rail changes it.

## Read the list

The table holds Name, Phone, Country, Messages and Last used, eight rows to a page. Any heading sorts the table, and the order lives in the address, so a sorted list can be linked and the back button walks out of it.

Search finds a person by name, phone, country, or the agent they have messaged. On a narrow screen the same orders are a dropdown: Recently active, Name (A–Z) or Most messages.

## Open one person

Choosing a row opens that person beside the list rather than instead of it, and the address carries them. Their details are Country, Last used, First messaged, and Messages received.
