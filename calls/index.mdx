## What a call is

A person calls your agent from the Relay app. Relay sends your agent `call.created`, and your agent answers by joining the call's room. Relay carries the audio over WebRTC. Your backend runs the agent.

Your agent registers nothing for calls. `call.created` arrives on the webhook or WebSocket your agent already uses for messages.

## Answer a call

When `call.created` arrives with `status: "ringing"`, join the room for `call.id` within 32 seconds. Joining is the answer: the call becomes `in-progress`. A call nobody joins ends `no-answer`.

The TypeScript SDK joins the room and runs the WebRTC connection for you. Install the SDK with the WebRTC packages it lists as optional peer dependencies:

```bash
npm install @relaymessenger/sdk@staging werift @evan/opus rtp-packet
```

```typescript
import Relay from "@relaymessenger/sdk";
import { RelayCallTransport } from "@relaymessenger/sdk/calls";

const relay = new Relay({ apiKey: process.env.RELAY_AGENT_TOKEN!, baseURL: "https://api.staging.relayapp.im" });

// In your call.created handler:
const transport = new RelayCallTransport({ relay, callId: event.data.call.id });

transport.on("audio", ({ samples, sampleRate, channelCount }) => {
  // Interleaved signed PCM16 from the person, 48 kHz stereo by default.
});

await transport.connect();
await transport.writeAudio({ samples, sampleRate: 48_000, channelCount: 1 });
```

`writeAudio()` queues your agent's speech. Audio written before the person can hear it waits, in order, so your agent's first words are not cut off. `clearAudio()` drops what is still queued.

## Decline a call

To decline a ringing call, end it with `POST /v1/calls/{callId}/end`. A call your agent ends while it rings becomes `no-answer`.

<CodeGroup>
```typescript TypeScript SDK
await relay.calls.end(callId);
```

```bash cURL
curl -sS -X POST "https://api.staging.relayapp.im/v1/calls/$CALL_ID/end" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{}'
```
</CodeGroup>

## The call room

The room is a WebSocket at `GET /v1/calls/{callId}/room`, opened with your Agent Token. It carries only signaling: JSON frames with WebRTC session descriptions. Audio travels over WebRTC, never through this socket.

1. Send `{"type":"join"}` when the socket opens. Relay answers with `iceServers` and then `roomState`.
2. Send an `offer` that publishes one track named `audio`. Relay answers with `answer`.
3. Send `connected` when your peer connection is connected.
4. Relay sends an `offer` for the person's `audio` track. Reply with `answer`.

The [room reference](/api-reference/calls/join-a-call-room) lists every frame. Use the SDK unless you run your own WebRTC stack.

## End a call

Call `transport.close()` and end the call with `POST /v1/calls/{callId}/end`, or send `{"type":"end"}` in the room. An answered call becomes `completed`.

## The call in the chat

Relay writes one system message into the chat with `is_system_message: true` and `system_event.type: "call"`. The marker exists from the moment the call is placed; `call.status` carries its state. The event's `actor` is the caller, its `subject` is the callee, and its [`call` object](/api-reference/resources/messages/overview#system-events) carries its current state.

`parts[0].value` is a plain sentence such as "Atlas called you" or "Atlas called you with no answer". The Relay app shows it as a call bubble on the caller's side. Agents receive it like any other system message and should not reply to it.

## The Call object states

`status` uses Twilio's call status words. `ringing` and `in-progress` are live. The other five are terminal and set `ended_at`.

| Status | Meaning |
| --- | --- |
| `ringing` | Relay is waiting for the person or agent being called to join the room. |
| `in-progress` | The person or agent being called joined the room within 32 seconds. |
| `completed` | An answered call ended. |
| `no-answer` | Nobody joined within 32 seconds, or the recipient declined. |
| `canceled` | The caller ended the call while it was ringing. |
| `busy` | The person was already on another call. An agent is never busy. |
| `failed` | Relay could not connect or keep the call. |
