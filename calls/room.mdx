`GET /v1/calls/{callId}/room` upgrades to the WebSocket that carries a Call's signalling: state, accept and end, mute, and the audio grant.

## Endpoint

Send `Upgrade: websocket` with the same `Authorization: Bearer` header as every REST route; an agent sends its Agent Token. `Sec-WebSocket-Protocol` is not used.

```http Upgrade
GET /v1/calls/01995978-1000-7000-8000-000000000001/room HTTP/1.1
Host: api.staging.relayapp.im
Upgrade: websocket
Connection: Upgrade
Authorization: Bearer $RELAY_AGENT_TOKEN
Sec-WebSocket-Version: 13
Sec-WebSocket-Key: <client-generated-key>
```

One socket per participant per Call. A second upgrade from the same Contact replaces the first, which closes `1000 "Replaced"`.

| Status | Meaning |
| --- | --- |
| `101` | Connected |
| `401` | Bad token |
| `404` | Unknown Call, or you are not a participant |
| `410` | The Call already ended |

Errors before the upgrade use the same JSON `error` body as REST.

## Client frames

Every frame is one JSON text object; `type` discriminates.

| Frame | Sender | Effect |
| --- | --- | --- |
| `join` | either | Attach. Reply: one `roomState`. Idempotent. |
| `offer` | user | Publish the microphone. Carries `session_description` (`{type:"offer", sdp}`) and `tracks` (`[{mid, name:"microphone"}]`). Allowed in `ringing`, `connecting`, `active`. Reply: `answer`. A second `offer` closes `4400`. Agents publish over the [audio socket](/calls/media) instead. |
| `answer` | either | Completes a pull the room started with its `offer`. Carries `session_description` (`{type:"answer", sdp}`). |
| `userUpdate` | either | Carries `muted` (boolean). Reply: `roomState` to everyone. |
| `accept` | callee | `ringing` → `connecting`. |
| `decline` | callee | `ringing` → `ended` with `declined`. |
| `end` | either | `ringing` → `ended` with `canceled` from the caller; otherwise `ended` with `completed`. |
| `connected` | either | "My remote track is playing." The second side's `connected` → `active`. |
| `heartbeat` | either | Answered with `{"type":"heartbeat"}` by the runtime, never by code. Send it every 15 seconds. |

```json Mute
{"type":"userUpdate","muted":true}
```

## Server frames

| Frame | When | Fields |
| --- | --- | --- |
| `roomState` | Once on `join`, then after every change, to every socket | `call` (the [Call object](/api-reference/resources/calls/overview), unchanged), `participants`, and `media` on the agent's socket only |
| `answer` | After the user's publish `offer` | `session_description` (`{type:"answer", sdp}`) |
| `offer` | The room started pulling the other side's track into your session | `session_description` (`{type:"offer", sdp}`), `track` (`"agent-voice"`). Reply with `answer`. |
| `ended` | Terminal; the socket closes `1000 "Call ended"` right after | `reason`: `completed`, `declined`, `canceled`, `no_answer`, `disconnected`, or `failed` |
| `error` | A rejected frame or a failed media setup | `code`: `invalid_frame`, `not_allowed`, or `media_unavailable`; `message`. `invalid_frame` is followed by close `4400`. |

Each `participants` entry carries `contact_id`, `kind` (`user` or `agent`), `attached`, `track` (`microphone`, `agent-voice`, or `null`), `muted`, and `connected`. `media` carries `url`, `token`, `expires_at`, and `audio_format`. The same `roomState` may arrive twice; treat it as idempotent.

```json roomState
{
  "type": "roomState",
  "call": {"id": "01995978-1000-7000-8000-000000000001", "status": "ringing", "revision": 1},
  "participants": [
    {"contact_id": "01995978-1000-7000-8000-000000000003", "kind": "user", "attached": true, "track": "microphone", "muted": false, "connected": false},
    {"contact_id": "01995978-1000-7000-8000-000000000004", "kind": "agent", "attached": true, "track": null, "muted": false, "connected": false}
  ],
  "media": {
    "url": "wss://api.staging.relayapp.im/v1/calls/01995978-1000-7000-8000-000000000001/media",
    "token": "<media-grant>",
    "expires_at": "2026-09-17T23:01:02.000Z",
    "audio_format": {"encoding": "pcm_s16le", "sample_rate": 48000, "channels": 2}
  }
}
```

The `call` above is shortened; on the wire it carries every field of the Call object.

## Ordering guarantees

1. `join` → `roomState` before anything else on that socket.
2. A user's `offer` is accepted while ringing; its `answer` comes back before accept.
3. After `accept`: `roomState` with `status: "connecting"` to both sides. When the agent's audio path is live, the room sends the user `offer` with `track: "agent-voice"` and marks the agent participant `track: "agent-voice"`.
4. `connected` from the second side → `roomState` with `status: "active"` and `connected_at` set.
5. Any terminal transition → `ended` on every socket, then close.
6. Every status transition is written to the Call record and emitted as `call.created`, `call.updated`, or `call.ended` in the same step; the record and the socket never disagree.

The ringing lease is 60 seconds (`no_answer`) and the connecting lease is 30 seconds (`failed`).

## Close codes

| Code | Reason | When |
| --- | --- | --- |
| `1000` | `Call ended` | After the `ended` frame |
| `1000` | `Replaced` | A newer socket from the same Contact attached |
| `4400` | | After `error` with `invalid_frame`, or a second `offer` |
