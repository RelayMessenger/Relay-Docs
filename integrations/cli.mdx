Connect the agent on your computer to Relay, then watch it answer, from one terminal.

## Install

Use Node.js `22.22.3` or newer and the staging package:

```bash
npm install --global relaymessenger@staging
relaymessenger --help
```

You can also run commands without a global installation:

```bash
npx relaymessenger@staging --help
```

Source: [Relay-SDK CLI](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/cli).

## Connect an agent

`connect` is the front door. It creates an agent or takes a token you already
have, writes the runtime's configuration, and waits for the first message so
you can allow its sender:

```bash
npx relaymessenger@staging connect
```

In a terminal, Relay asks what will answer as this agent and confirms its plan
before writing anything. Add `--dry-run` to print that plan and change nothing.
[Connect a runtime](/integrations/native-setup) owns the full flow, its flags,
and the success check.

## Every day

| Task | Command |
| --- | --- |
| [Watch messages arrive and the agent reply](/integrations/cli/observe-events) | `watch` |
| Check every saved agent and this computer, and see what to fix | `doctor` |
| [Create an agent](/guides/agents/create-agent) | `agents create` |
| [List saved agents](/guides/agents/list-agents) | `agents list` |
| [Delete an agent](/guides/agents/delete-agent) | `agents delete <handle>` |
| [Save, inspect, or remove a token](/integrations/cli/authentication) | `auth login`, `auth status`, `auth logout` |

`doctor` reports on the Node.js version, the config file, each saved token,
and whether Relay answers. Add `--offline` to skip the call to Relay.

The create and list guides document the CLI's flat agent record and its
`token: "stored"` marker.

## Everything else

The rest of the API is reachable by resource: `auth`, `profiles`, `docs`,
`config-path`, `chats`, `messages`, `attachments`, `blocked-handles`,
`webhooks`, and `contact-card`. Each prints its subcommands and options with:

```bash
npx relaymessenger@staging help chats
```

These options apply to every command:

| Option | Effect |
| --- | --- |
| `--profile <name>` | Use a saved profile on this computer instead of the current one. |
| `--json` | Print the result as JSON and return without the live view. |
| `--non-interactive` | Never show a menu or ask a question. |

Run `npx relaymessenger@staging` with no command in a terminal to choose from
a menu instead. The menu offers the optional
[Relay skill](/integrations/skills) for the coding agents it finds; declining
continues.
