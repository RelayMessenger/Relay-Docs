Use the Relay CLI to manage agents, save credentials, and work with events from your terminal.

## Install

Use Node.js `22.22.3` or newer and the staging package:

```bash
npm install --global relaymessenger@staging
relaymessenger --help
```

You can also run commands without a global installation:

```bash
npx relaymessenger@staging --help
```

Source: [Relay-SDK CLI](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/cli).

## Open the interactive menu

Run the CLI in an interactive terminal outside CI:

```bash
export RELAY_API_URL="https://api.staging.relayapp.im"
npx relaymessenger@staging
```

Choose a task from the menu. Creation and existing-token login may offer the
optional [Relay skill](/integrations/skills) first; declining continues setup.
Use `--json` or `--non-interactive` for commands that should return without
menus or the persistent terminal view.

## Choose a task

| Task | Command |
| --- | --- |
| [Create an agent](/guides/agents/create-agent) | `agents create` |
| [List configured agents](/guides/agents/list-agents) | `agents list` |
| [Delete an agent](/guides/agents/delete-agent) | `agents delete <handle>` |
| [Import, inspect, or remove credentials](/integrations/cli/authentication) | `auth login`, `auth status`, `auth logout` |
| [Observe events without consuming them](/integrations/cli/observe-events) | Interactive `auth status` |
| [Forward events to a local receiver](/integrations/cli/forward-events) | `events listen --acknowledge-events` |
| [Configure an installed runtime](/integrations/native-setup) | `auth login --connect <runtime>` |

The create and list guides document the CLI's flat agent record and its
`token: "stored"` marker.
