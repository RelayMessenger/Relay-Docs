Pick the integration that matches where your agent already runs. Your agent
stays there, and Relay carries the messages, media, approval requests, and
receipts between it and the person texting it.

Four of them run the agent on your own computer and install through the same
CLI. The rest connect a server or a host runtime you operate.

## Supported integrations

- [Claude Code](/integrations/claude-code) - drive Claude Code on your computer over ACP, or push messages into an open Claude session (bundled adapter, plus a research-preview channel plugin).
- [Codex](/integrations/codex) - drive Codex on your computer over ACP, or add Relay tools to normal Codex runs (bundled adapter, plus optional MCP and hooks).
- [Hermes Agent](/integrations/hermes) - bridge the `hermes acp` command you already have installed (external binary, you own installation and upgrades).
- [OpenClaw](/integrations/openclaw) - install Relay as a native OpenClaw channel inside your gateway (bundled plugin).
- [Vercel AI SDK](/integrations/vercel-ai-sdk) - verify signed webhooks and pipe `streamText` output into one message from your own server (published package).
- [Your own runtime](/integrations/channel-plugin) - the contract for giving a host runtime you maintain its own Relay channel (a reference contract you implement).

The four local engines share one install path:

```bash
npm install -g @relaymessenger/cli
relaymessenger pair
```

See [the CLI](/integrations/cli) for what pairing creates, what Relay never
receives, and the approval guarantees all four share.

## What every integration guarantees

- Approval cards are owner-only. A non-owner message is dropped before its content is interpreted.
- Approvals are denied rather than shown when the exact operation does not fit in the security preview. Claude Code hits this most often, because its permission preview is truncated.
- Agent and tool turns are at-most-once. A crash cannot silently repeat a deploy, deletion, command, or external send.
- Relay never receives your engine provider keys, SSH keys, or full parent process environment.
- Claude and Codex adapters are pinned at exact versions inside `relaymessenger`, launched directly with Node, with no shell and no mutable `npx latest` lookup. Hermes is the exception: you install and upgrade it yourself.
- OpenClaw is direct conversations only today. Reactions and receipts do not start agent turns there.
- Running more than one integration at once is fine, as long as each has its own agent and token.
- `relaymessenger doctor` is the first step for any local-engine problem. It checks pairing, token permissions, API reachability, saved state, and each adapter entrypoint.
