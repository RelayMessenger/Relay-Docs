## Before you start

- [Cline](https://docs.cline.bot/cline-cli/overview), installed and signed in.
- Node.js 22.22.3 or newer.

## Connect

Run this in the folder where you work to connect cline to Relay.

```bash
npx relaymessenger@staging connect cline
```

Choose one agent when Relay asks. The first detected agent is the default. If saved agents exist, choose `New agent` or a saved handle. Press Enter at `Continue? (Y/n)` to accept the plan.

Approve the change, then message the new handle from your phone. Leave the command running: it answers each message with Cline from the folder you ran it in. Control-C stops it. Relay's tools travel through the session, so no MCP file is written.

## Send it a message

Open Relay on your phone and message the handle. While connect runs, Cline answers on its own in the same chat, and each chat keeps its own ACP session.

## What it can do

These come from the connection code for `cline` and the Relay MCP tool list.

| Relay feature | Cline |
| --- | --- |
| Connect | Connect writes no MCP file; Relay drives Cline over ACP and its tools travel through the session. |
| Start | Connect stays running and drives `cline --acp` in its folder, one message at a time. |
| Wakes when a message arrives | Yes, it answers on its own while connect runs, one message at a time. |
| Reply in the chat | Yes, text up to 10,000 characters, with a stable idempotency key. |
| Send attachments | No. The MCP tools send text only. |
| Read chat history | Yes, by chat, oldest or newest first, one page at a time. |
| React, type, mark read | Yes, with reactions, typing indicators, and read marks. |
| Contact card | Yes, read and set the agent's name and picture. |

## When it fails

- `Relay cannot ask which agent to connect.` Run connect in a terminal, or pipe a token with `--with-token`.
- `Relay cannot ask you to confirm this plan.` Add `--yes`.
- `Relay would not accept that token, so nothing was changed.` The token is not one this Relay issued. Run `connect --new` to create an agent, or pass the right token.
- `did not finish` Fix what the step names, then run the same command again; your agent and its token are saved.
- `No reply yet. Run: relay watch @<handle>` Connect is not running, or Cline is still working; run connect again and it answers from there.
