## Before you start

- Git, and a coding agent that loads skills.
- Node.js 22.22.3 or newer.

## Connect

Clone the SDK and run the standard Skills installer, which copies the skill into the agent's skill folder:

```bash
git clone --branch staging https://github.com/RelayMessenger/Relay-SDK.git
npx skills@1.5.24 add ./Relay-SDK/skills/relay --skill relay
```

Choose the agent and the scope when the installer asks, then confirm that `relay` appears in that agent's installed skills. The source is [skills/relay](https://github.com/RelayMessenger/Relay-SDK/tree/staging/skills/relay). The [Relay CLI](/cli/index#install) offers the same install as an optional step before setup, and you can decline it there.

### Connect documentation search

The skill names a docs MCP server as a dependency, so the agent can search these docs while it works. Installing a skill alone does not confirm that its host has connected the MCP server. Add the address by hand if your host needs it:

```text
https://docs.staging.relayapp.im/mcp
```

The two MCP servers do different jobs and need different credentials.

| Server | Credential | Job |
| --- | --- | --- |
| Docs MCP | None | Read-only documentation search. |
| [Relay API MCP](/integrations/mcp) | Relay Agent Token | Messaging operations from a trusted local client. |

The [Codex](/integrations/codex) and [Cursor](/integrations/cursor) plugins install the skill and the docs server together.

## Send it a message

Ask your coding agent to read the Relay skill and explain how to connect an existing agent. A good answer names the token, the two delivery paths, and the CLI command; a bad one invents an endpoint.

## What it can do

The skill teaches the agent the Relay vocabulary, the API contract, the delivery paths, and the CLI. It does not create an agent, save a token, or read a chat; for that, connect the coding agent on its own page.

## When it fails

- The host cannot search the docs: add the docs MCP address above by hand.
- `relay` is not in the installed skills: run the installer again with the same agent and scope.
