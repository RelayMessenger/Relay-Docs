Install the Relay skill so your coding agent knows how Relay works before it writes code.

## Before you start

You need Git and a coding agent that loads skills. The skill is a folder of instructions in the SDK. The standard Skills installer copies it into the agent's skill folder, in the project or globally, and the agent reads it when a task mentions Relay. Clone the SDK and run the installer:

```bash
git clone --branch staging https://github.com/RelayMessenger/Relay-SDK.git
npx skills@1.5.24 add ./Relay-SDK/skills/relay --skill relay
```

Choose the agent and the scope when the installer asks, then confirm that `relay` appears in that agent's installed skills. The source is [skills/relay](https://github.com/RelayMessenger/Relay-SDK/tree/staging/skills/relay). The [Relay CLI](/cli/index#install) offers the same install as an optional step before setup; you can decline it there and run this later.

## Connect

### Connect documentation search

The skill names a docs MCP server as a dependency, so the agent can search these docs while it works. Installing a skill alone does not confirm that its host has connected the MCP server. If your host needs MCP servers added by hand, add this address:

```text
https://docs.staging.relayapp.im/mcp
```

The two MCP servers do different jobs and need different credentials.

| Server | Credential | Job |
| --- | --- | --- |
| Docs MCP | None | Read-only documentation search. |
| [Relay API MCP](/integrations/mcp) | Relay Agent Token | Messaging operations from a trusted local client. |

The [Codex](/integrations/codex) and [Cursor](/integrations/cursor) plugins install the skill and the docs server together.

## Send it a message

Ask your coding agent to read the Relay skill and explain how to connect an existing agent. A good answer names the token, the two delivery paths, and the CLI command; a bad one invents an endpoint.

## What it can do

The skill teaches the agent the Relay vocabulary, the API contract, the delivery paths, and the CLI. It does not create an agent, save a token, or read a chat. For that, connect the coding agent on its own page.

## When it fails

If the host cannot search the docs, add the docs MCP address above by hand. If `relay` is not in the installed skills, run the installer again and choose the same agent and scope.
