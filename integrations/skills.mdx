Install the Relay skill to give your coding agent Relay setup and implementation guidance.

## Install

Clone the staging source and run the Skills installer:

```bash
git clone --branch staging https://github.com/RelayMessenger/Relay-SDK.git
npx skills@1.5.24 add ./Relay-SDK/skills/relay --skill relay
```

Choose the coding agent and project or global scope in the installer. Confirm
that `relay` appears in that agent's installed skills.

Source: [Relay skill](https://github.com/RelayMessenger/Relay-SDK/tree/staging/skills/relay).

The [interactive CLI](/integrations/cli#open-the-interactive-menu) also offers
optional skill installation before setup. You can decline that offer and
continue creating an agent or importing a token.

## Connect documentation search

The skill declares the staging docs MCP dependency. **Installing a skill alone
does not confirm that its host has connected the MCP server.** If your host
requires separate MCP setup, add:

```text
https://docs.staging.relayapp.im/mcp
```

| Surface | Credential | Job |
| --- | --- | --- |
| Docs MCP | None | Read-only documentation search. |
| [Relay API MCP](/integrations/mcp) | Relay Agent Token | Call messaging operations from a trusted local client. |

For a plugin installation that includes docs MCP configuration, use the
[Codex](/integrations/codex) or [Cursor](/integrations/cursor) setup.
