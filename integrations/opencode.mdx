Connect OpenCode to Relay and talk to it from your phone.

## Before you start

[Install OpenCode](https://opencode.ai/docs/) and sign in to it. Install Node.js 22.22.3 or newer; the Relay CLI runs with `npx`. Set `RELAY_API_URL` to `https://api.staging.relayapp.im` so Relay talks to the API your agent lives on. You do not need an agent yet: the command below creates one and saves its token on this computer. If you already have an Agent Token, pipe it in with `--with-token`.

## Connect

Run this in a terminal. Relay finds OpenCode and creates an agent with a `.dev` handle. Then it prints what it will change before it changes anything: Relay adds one `mcp.relay` entry to `~/.config/opencode/opencode.json` and keeps every other entry. It asks `Continue?` and does the work. It ends with `Relay is ready for OpenCode.` and the handle to message from your phone:

```bash
npx relaymessenger@staging connect opencode
```

The last lines tell you what to do next. `Say anything to @<handle> from your phone.` is the invitation. `Later: relay watch <handle> · relay doctor` names the two commands that show the chat in the terminal and check the setup. Connect then waits for the agent's first reply and prints it as `Answered from your phone: …`.

## Send it a message

Open Relay on your phone and send a message to the handle connect printed. OpenCode does not wake up on its own: the Relay MCP server gives it tools, and it uses them when you ask. In OpenCode, say `Read my Relay messages and answer them.` It lists the chat, reads your message, and sends its answer. The answer appears in the same chat on your phone, and in the terminal while connect is waiting. Start it: `opencode`; connect offers to start it for you.

## What it can do

The table says what the Relay CLI and the Relay MCP server give OpenCode. It comes from the connection code for `opencode` and the tool list of `@relaymessenger/mcp`; anything not listed is not there.

| Relay feature | OpenCode |
| --- | --- |
| Connect | Relay adds one `mcp.relay` entry to `~/.config/opencode/opencode.json` and keeps every other entry. |
| Start | `opencode`; connect offers to start it for you. |
| Wakes when a message arrives | No. It reads the chat when you ask it to. |
| Reply in the chat | Yes, text up to 10,000 characters, with a stable idempotency key. |
| Send attachments | No. The MCP tools send text only. |
| Read chat history | Yes, by chat, oldest or newest first, one page at a time. |
| React, type, mark read | Yes, with reactions, typing indicators, and read marks. |
| Contact card | Yes, read and set the agent's name and picture. |

## When it fails

Every failure prints one line, and nothing else changes. `Relay cannot ask which agent to connect.` means you ran connect without a terminal and without a token; pipe one in with `--with-token`, or run it in a terminal. `Relay cannot ask you to confirm this plan.` means the same for the plan; add `--yes`. `Relay would not accept that token, so nothing was changed.` means the token and `RELAY_API_URL` come from different environments. `OpenCode was not found on this computer; you named it, so Relay will try anyway` is a notice, not an error: install OpenCode and run connect again. If a step stops with `did not finish`, your agent and its token are saved; fix what it said and run the same command again. `No reply yet. Run: relay watch @<handle>` means OpenCode has not read the chat: `Read my Relay messages and answer them.`
