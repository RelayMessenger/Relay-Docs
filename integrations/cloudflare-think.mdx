Run the Relay Think starter to receive signed Webhooks and answer Messages from a Cloudflare Worker.

## Install the starter

| Requirement | Value |
| --- | --- |
| Node.js | `22.22.3` or newer. |
| Cloudflare | An account with Workers AI access. |
| Relay | A production Agent Token and a public HTTPS Webhook destination. |

Clone the source and install the starter:

```bash
git clone --branch main https://github.com/RelayMessenger/Relay-SDK.git
cd Relay-SDK/cookbook/cloudflare-think-agent
npm ci
cp .dev.vars.example .dev.vars
```

Source: [Cloudflare Think starter](https://github.com/RelayMessenger/Relay-SDK/tree/main/cookbook/cloudflare-think-agent).

## Configure production

[Register a Webhook subscription](/guides/webhooks/subscriptions) for your
public HTTPS `/webhooks/relay` destination and retain its one-time signing
secret. Set the secrets in `.dev.vars`, keeping that file out of source control:

```dotenv
RELAY_AGENT_TOKEN=replace-with-staging-agent-token
RELAY_WEBHOOK_SECRET=whsec_replace-with-staging-webhook-secret
```

In `wrangler.jsonc`, set these non-secret values under `env.staging.vars`:

| Variable | Value |
| --- | --- |
| `RELAY_API_ORIGIN` | `https://api.relayapp.im` |
| `RELAY_AGENT_HANDLE` | The Handle returned for your agent. |
| `MODEL_ID` | `@cf/openai/gpt-oss-120b` |

Start the Worker and route the registered HTTPS destination to it:

```bash
npm run dev
```

## Check the setup

Request `/healthz` at the local URL printed by the development server. Valid
configuration returns:

```json
{"ok": true}
```

| Result | Action |
| --- | --- |
| `/healthz` returns `503` | Fill in the settings named in the response. |
| Webhook returns `401` | Check the subscription's signing secret and preserve the original signed body. |
| Signed Webhook returns `202` | The request was accepted; verify the model's reply separately. |

Send the agent a direct Message and confirm that its answer arrives in the same
Chat. The starter uses a `reply`
Action for the completed response. Preserve its idempotency handling when
customizing the reply.
