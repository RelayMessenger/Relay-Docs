Open a saved agent's identity, QR, and live event view in an interactive terminal.

**This view watches only; your runtime remains the consumer.**

## Open the view

Use the [CLI](/integrations/cli#install) with a saved profile from
[connecting an agent](/integrations/native-setup),
[agent creation](/guides/agents/create-agent), or
[saving a token](/integrations/cli/authentication).

`watch`: see messages arrive and the agent reply, live.
Name the agent to watch:

```bash
npx relaymessenger@staging watch brave_golden_cangoo.dev
```

`handle`: the agent to watch; leave it out for the profile Relay would use.
`--profile <name>`: which saved profile on this computer to use. The agent needs zero saved Webhook subscriptions for the view's
connection. Interactive `connect`, creation, and login also open this view
after they succeed. The view needs a terminal: a script, a pipe, or `--json`
returns without it.

## Read and control the view

| Control or line | Meaning |
| --- | --- |
| `q`, Ctrl-C, or Ctrl-D | Leave the view and restore the terminal. The identity, saved credential, and runtime remain unchanged. |
| `c` | Redraw the QR from the public share URL. |
| `?` | Show view help. |
| `Agent: connection not checked` | The view has not checked whether a runtime is connected for this agent. |
| `Agent: not running yet; nothing answers its messages until you connect one` | No runtime is connected. Messages sent to the agent get no reply until you connect one. |
| `Agent: running` | A connected runtime answers for the agent. |
| `Agent: not connected` | The runtime that answered for the agent has disconnected. |
| `Live view: connecting` | The view is opening its watch connection. |
| `Live view: watching only; your agent still receives every message` | The server confirmed the read-only connection. Your runtime stays the consumer. |
| `Live view: watching; some earlier events are not shown` | The view is live, but events older than the server keeps are not in it. This view is not full history. |
| `Live view: disconnected` | The watch connection closed. The saved identity is unchanged. |
| `Live view: unavailable` | The view could not open a watch connection. The CLI keeps the saved identity and does not open a consuming fallback. |

The view also prints `This view does not start or stop your agent.` when a
runtime is attached, and `?` shows `This view only watches. It does not answer
messages or change anything.`

The view uses `/v1/websocket?observe=true` and requires `observational: true`
in the ready frame. It sends neither event ACKs nor `full_sync_complete`, so it
never advances the runtime's durable checkpoint. The wire shape is in
[Observe WebSocket events](/guides/websocket/observe-events).

Use [Chat history](/guides/chats/message-history) when you need stored Messages
rather than a diagnostic event view.
