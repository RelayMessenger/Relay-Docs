## Usage

```text
Usage: relaymessenger [options] [command]

Relay: give the agent on your computer a phone number.

Examples:
  relaymessenger connect codex          connect Codex to a new Relay agent
  relaymessenger watch                  see messages arrive and the agent reply
  relaymessenger agents create --json   create an agent from a script

Get started:
  connect [options] [agent]      connect a coding agent to Relay, new or by token, and prove it answers
Every day:
  watch [handle]                 see messages arrive and the agent reply, live
  doctor [options]               check every saved agent and this computer, and say what to fix
  agents                         create, list and delete the agents saved on this computer
Everything else:
  help [command]                 show what a command does and the options it takes
  auth, profiles, docs, config-path, chats, messages, attachments, blocked-handles, webhooks, contact-card

Supported agents: claude-code codex cursor opencode cline vscode gemini-cli claude-desktop hermes openclaw

Options:
  -V, --version                  print the version
  --json                         print the result as JSON, errors included
  --no-input, --non-interactive  never ask a question; fail with exit 2 where one is required
  --agent <auto|yes|no>          override coding-agent detection (default auto)
  -q, --quiet                    errors only
  --verbose                      print each request it makes to stderr, as METHOD path status ms
  --profile <name>               which saved profile on this computer to use
  --install-skills               install the Relay skill for the coding agents on this computer
  -h, --help                     display help for command

No environment variables are needed. RELAY_AGENT_TOKEN is honored in scripts only.
Docs: https://docs.relayapp.im
Report a problem: https://github.com/RelayMessenger/Relay-SDK/issues
```

## Exit codes

```text
relaymessenger exit codes

relaymessenger follows normal conventions regarding exit codes.

- If a command completes successfully, the exit code will be 0
- If a command fails for any reason, the exit code will be 1
- If a command is given options it does not understand, or needs an answer and has no terminal, the exit code will be 2
- If the thing a command names does not exist, the exit code will be 3
- If a command needs a token and none is saved, or Relay does not accept the one it has, the exit code will be 4

Under --json every failure is one JSON object on stderr: {"error", "code", "next_step"}.
The code is Relay's numeric code as a string for an API fault, and one of
usage, not_a_tty, no_token, not_found, network, refused for a fault in this command.

Docs: https://docs.relayapp.im
Report a problem: https://github.com/RelayMessenger/Relay-SDK/issues
```
