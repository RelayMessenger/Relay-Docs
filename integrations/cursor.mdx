## Before you start

- [Cursor](https://cursor.com/downloads), installed and signed in.
- Node.js 22.22.3 or newer.
- `RELAY_API_URL` set to `https://api.staging.relayapp.im`.

## Connect

Run this in a terminal to create an agent and add the Relay MCP server to Cursor:

```bash
npx relaymessenger@staging connect cursor
```

Approve the change, then message the new handle from your phone.

### Install the Relay plugin for Cursor

The Relay plugin is a different thing: it gives Cursor the Relay skill and a documentation search server, not an agent:

```bash
git clone --branch staging https://github.com/RelayMessenger/Relay-SDK.git
cd Relay-SDK
mkdir -p "$HOME/.cursor/plugins/local"
ln -s "$PWD/plugins/relay" "$HOME/.cursor/plugins/local/relay"
```

Reload Cursor, keep the clone the link points into, and read [documentation search](/integrations/skills#connect-documentation-search) for the difference between searching the docs and the messaging tools.

## Send it a message

Open Relay on your phone and message the handle. Cursor does not wake up on its own, so tell it: `Read my Relay messages and answer them.` It reads the chat and sends its answer there.

## What it can do

These come from the connection code for `cursor` and the Relay MCP tool list.

| Relay feature | Cursor |
| --- | --- |
| Connect | Relay adds one `mcpServers.relay` entry to `~/.cursor/mcp.json` and keeps every other entry. |
| Start | restart Cursor; connect tells you when. |
| Wakes when a message arrives | No. It reads the chat when you ask it to. |
| Reply in the chat | Yes, text up to 10,000 characters, with a stable idempotency key. |
| Send attachments | No. The MCP tools send text only. |
| Read chat history | Yes, by chat, oldest or newest first, one page at a time. |
| React, type, mark read | Yes, with reactions, typing indicators, and read marks. |
| Contact card | Yes, read and set the agent's name and picture. |

## When it fails

- `Relay cannot ask which agent to connect.` Run connect in a terminal, or pipe a token with `--with-token`.
- `Relay cannot ask you to confirm this plan.` Add `--yes`.
- `Relay would not accept that token, so nothing was changed.` The token and `RELAY_API_URL` come from different environments.
- `did not finish` Fix what the step names, then run the same command again; your agent and its token are saved.
- `No reply yet. Run: relay watch @<handle>` Cursor has not read the chat yet; ask it again.
