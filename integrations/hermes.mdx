## Before you start

- [Hermes Agent](https://github.com/NousResearch/hermes-agent#installation) on Python 3.11 through 3.13, run once. Requires Hermes 0.19.0 or newer, tested through 0.21.3; newer minor versions log a warning and run, and versions below 0.19.0 are refused.
- Node.js 22.22.3 or newer.
- An existing Agent Token needs zero saved webhook subscriptions.

## Connect

Run this in the folder where you work to connect hermes to Relay.

```bash
npx relaymessenger@staging connect hermes
```

In an unlinked folder, this creates a new agent by default. If the folder is already linked, it uses that agent. Use `--handle` or `--name` to customize the new agent.

start the gateway with `hermes gateway run`, then message the handle.

### Install the plugin yourself

To keep the CLI away, install the [Git-hosted plugin](https://github.com/RelayMessenger/Relay-Hermes) with Hermes's own command in the active profile:

```bash
hermes plugins install RelayMessenger/Relay-Hermes --enable
```

Then set the token, the API address, and an absolute `RELAY_STATE_DIR` in the active profile, plus the optional `RELAY_ALLOWED_CONTACTS`.

### Do it by hand

```bash
hermes plugins install RelayMessenger/Relay-Hermes --enable
```

## Send it a message

Open Relay on your phone and message the handle. Hermes wakes up on its own and answers in the same chat. Keep the gateway running; it catches up later.

## What it can do

From the connection code for `hermes` and the plugin's adapter.

| Relay feature | Hermes |
| --- | --- |
| Connect | The Relay-Hermes plugin, with its config in `~/.hermes/.env`. |
| Start | `hermes gateway run`; connect offers to start it for you. |
| Wakes when a message arrives | Yes, over the WebSocket. |
| Reply in the chat | Yes, text with a stable idempotency key; it quotes the message only when answering one that did not start the turn. |
| Send attachments | Yes. Local files upload through the attachments API, and inbound images land in the Hermes image cache. |
| Read chat history | No. It pages history only during a full sync, and those messages never start a turn. |
| Reactions, edits, typing | Yes, with reactions and typing indicators while Hermes works on a reply; typing stops when the reply is sent. Hermes can add and remove reactions, and people's reactions reach its reaction handler. Editing and unsending messages are not supported. |
| Tool approvals | Yes. Reply /approve, /approve session, /approve always or /deny when Hermes asks; other slash commands run as on Telegram. |
| Buttons | Yes; see [Buttons](/interactions/buttons). A tap comes back as a message whose text is the label. |
| Link preview | Yes; a URL alone on its own line in the answer goes out as its own link message, drawn as a card; see [Rich link previews](/messages/rich-link-previews). |

Slash commands work the way they do on Telegram: Hermes runs them, and Hermes's own `allow_admin_from` setting for the `relayapp` platform decides who may. When Hermes needs approval to run a tool, reply `/approve`, `/approve session`, `/approve always` or `/deny`.

## When it fails

- Startup fails naming the state folder: it belongs to another token; give this agent its own `RELAY_STATE_DIR`.
- `No reply yet. Run: relay watch @<handle>` The gateway is not running, or a configured `RELAY_ALLOWED_CONTACTS` list excludes this sender.

Use the [CLI guide](/cli/index) for prompt, token, and restart errors.
