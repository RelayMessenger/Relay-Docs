## Before you start

- [Codex](https://github.com/openai/codex#quickstart), installed and signed in.
- Node.js 22.22.3 or newer.
- `RELAY_API_URL` set to `https://api.staging.relayapp.im`.

## Connect

Run this in a terminal to create an agent, add the Relay MCP server to Codex, and answer messages with Codex:

```bash
npx relaymessenger@staging connect codex
```

Approve the change, then scan the QR with Relay on your phone to add the agent, and send it a message. Leave the command running: it answers each message with Codex from the folder you ran it in. Control-C stops it.

### Install the Relay plugin for Codex

The Relay plugin is a different thing: it gives Codex the Relay skill and a documentation search server, not an agent:

```bash
git clone --branch staging https://github.com/RelayMessenger/Relay-SDK.git
cd Relay-SDK
codex plugin marketplace add "$PWD"
codex plugin add relay@relay-plugin-marketplace
```

Start a new Codex session, then read [documentation search](/integrations/skills#connect-documentation-search) for the difference between searching the docs and the messaging tools.

## Send it a message

Open Relay on your phone and message the handle. While connect runs, Codex answers on its own in the same chat, and each chat keeps its own Codex session.

## What it can do

These come from the connection code for `codex` and the Relay MCP tool list.

| Relay feature | Codex |
| --- | --- |
| Connect | Codex's own `codex mcp add` writes the Relay MCP server into `~/.codex/config.toml`. |
| Start | Connect stays running and runs `codex exec` in its folder for each message. |
| Wakes when a message arrives | Yes, while connect runs, one message at a time. |
| Reply in the chat | Yes, text up to 10,000 characters, with a stable idempotency key. |
| Send attachments | No. The MCP tools send text only. |
| Read chat history | Yes, by chat, oldest or newest first, one page at a time. |
| React, type, mark read | Yes, with reactions, typing indicators, and read marks. |
| Contact card | Yes, read and set the agent's name and picture. |

## When it fails

- `Relay cannot ask which agent to connect.` Run connect in a terminal, or pipe a token with `--with-token`.
- `Relay cannot ask you to confirm this plan.` Add `--yes`.
- `Relay would not accept that token, so nothing was changed.` The token and `RELAY_API_URL` come from different environments.
- `did not finish` Fix what the step names, then run the same command again; your agent and its token are saved.
- `No reply yet. Run: relay watch @<handle>` Connect is not running, or Codex is still working; run connect again and it answers from there.
