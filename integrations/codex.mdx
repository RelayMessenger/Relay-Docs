Install the Relay plugin to add Relay guidance and documentation search to Codex.

## Install locally

Use Codex CLI `0.152.0` with the Relay plugin:

```bash
npm install --global @openai/codex@0.152.0
git clone --branch staging https://github.com/RelayMessenger/Relay-SDK.git
cd Relay-SDK
codex plugin marketplace add "$PWD"
codex plugin add relay@relay-plugin-marketplace
```

Start a new Codex session after installation. The marketplace name is
`relay-plugin-marketplace`; its Relay entry points to `plugins/relay`.

Source: [Relay plugin](https://github.com/RelayMessenger/Relay-SDK/tree/staging/plugins/relay)
and [Codex marketplace](https://github.com/RelayMessenger/Relay-SDK/blob/staging/.agents/plugins/marketplace.json).

## Confirm the installation

Confirm that the Relay skill is available in the new session and that the
`relayDocs` MCP server is configured. Ask Codex to use the Relay skill for your
next Relay integration task.

For the distinction between documentation search and authenticated messaging
tools, see [documentation search](/integrations/skills#connect-documentation-search).
