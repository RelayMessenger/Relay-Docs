Codex keeps running on your computer. Relay carries the messages, the file-change
approvals, and the final reply.

<Steps>
  <Step title="Pair this computer">
    ```bash
    npm install -g @relaymessenger/cli
    relaymessenger pair
    ```

    See [the CLI](/integrations/cli) for what pairing creates and what it never sends.
  </Step>

  <Step title="Choose a path">
    Use the headless bridge for a standalone conversation, or the project-scoped
    integration to get Relay tools inside the Codex runs you already do.
  </Step>
</Steps>

<Tabs>
  <Tab title="Headless ACP bridge">
    ```bash
    relaymessenger start --engine codex --dir ~/code/my-project
    ```

    The exact bundled `@agentclientprotocol/codex-acp` adapter drives Codex's
    app-server protocol. Relay preserves streamed text, per-conversation session
    bindings, cancellation, and permission options.

    For file-change approvals, the bridge combines Codex's earlier tool-call diff
    with the later permission request, so the phone sees the exact old and new
    text.

    <Warning>
    If an operation cannot be represented in full, Relay denies it rather than
    offering a blind Allow.
    </Warning>
  </Tab>

  <Tab title="Project-scoped integration">
    ```bash
    cd ~/code/my-project
    relaymessenger install-codex
    ```

    This merges into your existing configuration without clobbering it:

    | File | What is added |
    | --- | --- |
    | `~/.codex/config.toml` | `[mcp_servers.relay]` and a completion `notify` command |
    | `~/.codex/hooks.json` | A `PermissionRequest` hook |
    | `~/.relaymessenger/codex-notify.json` | A local opt-in for this project root |

    Other projects stay suppressed until you opt them in separately. Codex may
    ask you to trust a newly installed hook handler.

    <Info>
    MCP sends require a caller-stable `send_id`, so a retry with an unknown
    outcome can reuse the same Relay idempotency key without posting twice.
    </Info>
  </Tab>
</Tabs>

## Feature reference

<AccordionGroup>
  <Accordion title="Adapter pinning">
    The exact bundled `@agentclientprotocol/codex-acp` adapter drives Codex's
    app-server protocol, launched directly with Node. There is no shell and no
    mutable `npx latest` lookup.
  </Accordion>

  <Accordion title="Streaming and sessions">
    Relay preserves streamed text, per-conversation session bindings, and
    cancellation across the bridge.
  </Accordion>

  <Accordion title="File-change approvals carry the real diff">
    The bridge combines Codex's earlier tool-call diff with the later permission
    request, so the phone sees the exact old and new text rather than a summary.
    If the operation cannot be represented in full, Relay denies instead of
    offering a blind Allow.
  </Accordion>

  <Accordion title="Idempotent MCP sends">
    MCP sends require a caller-stable `send_id`, so a retry with an unknown
    outcome reuses the same Relay idempotency key and cannot post twice.
  </Accordion>

  <Accordion title="Per-project opt-in">
    `install-codex` records the project root in
    `~/.relaymessenger/codex-notify.json`. Other projects stay suppressed until
    you opt them in separately, so installing once does not start notifying for
    every repository on the machine.
  </Accordion>

  <Accordion title="Non-destructive config merge">
    The installer adds `[mcp_servers.relay]` and a `notify` command to
    `~/.codex/config.toml`, and a `PermissionRequest` hook to
    `~/.codex/hooks.json`, without clobbering the rest of your configuration.
  </Accordion>
</AccordionGroup>

## Troubleshooting

Start with `relaymessenger doctor`, then
[integration troubleshooting](/integrations/troubleshooting) for symptoms shared
with every other integration. These are specific to this one.

<AccordionGroup>
  <Accordion title="Codex asks you to trust a hook handler">
    Expected after `install-codex`. Codex prompts before running a newly
    installed `PermissionRequest` hook. Accept it once at the keyboard.
  </Accordion>

  <Accordion title="Nothing arrives for a project">
    That project root is not opted in. `install-codex` opts in only the
    directory you ran it from; run it again from the project you want.
  </Accordion>

  <Accordion title="An approval shows Deny only">
    The operation could not be represented in full, so Relay withheld Allow
    rather than offering a blind approval. Approve at the keyboard.
  </Accordion>
</AccordionGroup>
