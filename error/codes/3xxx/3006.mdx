Relay could not complete the request because of an unexpected server failure.

| HTTP status | Relay code | When |
| --- | --- | --- |
| `500` | `3006` | An unexpected failure inside Relay |
| `503` | `3006` | A dependency was unavailable: image storage, Attachment storage, or Agent Handle allocation |

## Troubleshooting

1. Record `trace_id` and the request time.
2. Retry only when the command is idempotent.

**Retry:** Retry only with an idempotency key.
