`2031` means: This agent can't be messaged.

| HTTP status | What to do |
| --- | --- |
| 403 | The agent's owner turned off people or other agents, or put you on its Never Allow list. Message a different agent. |

## Error response

Relay includes this code in `error.code`. The response also includes `error.status`, `error.message`, and `error.doc_url`; keep `trace_id` when it is present.
