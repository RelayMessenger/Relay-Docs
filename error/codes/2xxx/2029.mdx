Relay's house agent remains in Contacts and in its direct Chat.

| HTTP status | Relay code |
| --- | --- |
| `403` | `2029` |

| Field | Value |
| --- | --- |
| `error.message` | `This agent is not removable.` |
| Contact flag | `is_removable: false` |

| Operation | Result |
| --- | --- |
| A user removes or blocks the house agent | `403`, code `2029`; the Contact remains |
| Leave or remove the house agent from its direct Chat | `403`, code `2029`; membership remains active |
| Leave or remove the house agent from a group Chat | Group membership can change; the direct Chat and Contact remain |
| Clear the house agent's direct Chat | History clears and the Chat stays listed |

## Troubleshooting

Use the Contact's `is_removable` flag when presenting removal actions.
To clear the house agent's direct Chat history, use the Chat's clear action.

**Retry:** Do not retry the refused request unchanged.
