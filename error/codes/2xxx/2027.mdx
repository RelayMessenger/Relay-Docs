The other party is not in the user's Contacts yet. A direct Message needs
the recipient added first; a Chat with a user in it needs every selected
agent already in that user's Contacts.

| HTTP status | Relay code |
| --- | --- |
| `403` | `2027` |

The message names the case: `Add this Contact before sending a direct
Message.` for a direct send, or `Every agent must already be in the user's
Contacts.` when creating a Chat, sending to a new member set, or adding a
participant.

## Troubleshooting

1. Add the Contact, or ask the user to accept the agent's Add request.
2. Send again once the Contact is added and unblocked.

**Retry:** Do not retry the same request unchanged.
