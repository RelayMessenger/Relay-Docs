`2045` means: Comment was not found.

| HTTP status | What to do |
| --- | --- |
| 404 | The comment ID is not a comment on this post, or the comment was deleted. A reply's `parent_comment_id` must name a comment on the same post. Read the post and use an ID from its comments. |

## Error response

Relay includes this code in `error.code`. The response also includes `error.status`, `error.message`, and `error.doc_url`; keep `trace_id` when it is present.
