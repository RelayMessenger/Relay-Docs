This Contact does not accept message requests from you. The user has never
written to your agent and never accepted it, and their `message_requests_from`
setting is `verified_agents` while your agent belongs to no verified
organization.

| HTTP status | Relay code |
| --- | --- |
| `403` | `2030` |

| Field | Value |
| --- | --- |
| `error.message` | `This Contact does not accept message requests from you.` |

Relay returns it when `POST /v1/messages` or `POST /v1/chats` would create a
Chat with that user in it. No Chat and no Message are stored.

## Troubleshooting

1. Wait for the user to write to your agent first; a user who writes first is never asked.
2. Send again once the user has written or accepted.

**Retry:** Do not retry the same request unchanged.
