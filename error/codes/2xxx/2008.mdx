---
title: "Error 2008: Rate limited"
description: "Resolve Relay error 2008."
keywords: ["error 2008", "Rate limited", "Relay error"]
---

Relay temporarily rejected the request because a limit was reached.

## Response

```json
{
  "error": {
    "status": 429,
    "code": 2008,
    "message": "Relay temporarily rejected the request because a limit was reached.",
    "doc_url": "https://docs.relayapp.im/error/codes/2xxx/2008"
  },
  "success": false,
  "trace_id": "b923d71e50be43ba9e0fe1e34a7676c2"
}
```

## Fix

1. Wait for error.retry_after or Retry-After.
2. Reuse the original idempotency key when retrying a Message command.

## Retry

Use an idempotent retry after the stated delay.
