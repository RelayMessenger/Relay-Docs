Structured mentions are not supported in direct Chats.

| HTTP status | Relay code |
| --- | --- |
| `409` | `2023` |

## Troubleshooting

1. Remove mention and mention_range for a direct Message.
2. Use mentions only with a current group Contact.

**Retry:** Do not retry the same request unchanged.
