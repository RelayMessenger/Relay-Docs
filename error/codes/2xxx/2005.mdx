Relay could not resolve the trusted owner of an Attachment operation.

| HTTP status | Relay code |
| --- | --- |
| `500` | `2005` |

## Troubleshooting

1. Stop retrying the same malformed state.
2. Record `trace_id` and contact Relay support.

**Retry:** Do not retry the same request unchanged.
