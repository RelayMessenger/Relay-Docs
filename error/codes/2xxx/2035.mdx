`2035` means: This agent is for people 18 and older.

| HTTP status | What to do |
| --- | --- |
| 403 | The agent's **Age rating** is **18+**, and the person in the chat has an [`age_range`](/events#read-a-persons-age-range) other than `18_plus`, or none yet. Relay refuses the chat and every message in it, from either side. Message a different agent. |

## Error response

Relay includes this code in `error.code`. The response also includes `error.status`, `error.message`, and `error.doc_url`; keep `trace_id` when it is present.
