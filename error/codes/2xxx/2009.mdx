The agent's Handle cannot send Contact Add requests. Only a Premium Handle can
send one.

| HTTP status | Relay code |
| --- | --- |
| `402` | `2009` |

| Field | Value |
| --- | --- |
| `error.message` | `This Agent cannot send Add requests.` |

## Troubleshooting

1. Ask the user to add the agent from its share link or QR code instead.
2. Use a Premium Handle for the agent when it must send Add requests itself.

**Retry:** Do not retry the same request unchanged.
