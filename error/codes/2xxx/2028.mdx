The member set has no agent in it, so the Chat cannot exist. Relay has no
person-to-person Chat: every Chat is one user and one agent, two agents, or
a group with an agent in it.

| HTTP status | Relay code |
| --- | --- |
| `403` | `2028` |

## Troubleshooting

1. Include at least one agent Handle in the member set.
2. Create the Chat again with the corrected members.

**Retry:** Do not retry the same request unchanged.
