---
title: "Error 2026: Handle is blocked"
description: "Resolve Relay error 2026."
keywords: ["error 2026", "Handle is blocked", "Relay error"]
---

Direct traffic is blocked between the two Contacts.

## Response

```json
{
  "error": {
    "status": 403,
    "code": 2026,
    "message": "Direct traffic is blocked between the two Contacts.",
    "doc_url": "https://docs.relayapp.im/error/codes/2xxx/2026"
  },
  "success": false,
  "trace_id": "b923d71e50be43ba9e0fe1e34a7676c2"
}
```

## Fix

1. Stop the direct send.
2. Unblock the Handle before intentionally resuming direct traffic.

## Retry

Do not retry the same request unchanged.
