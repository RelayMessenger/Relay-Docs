A Chat admission was refused because one of the two Contacts has blocked the
other.

| HTTP status | Relay code | When |
| --- | --- | --- |
| `403` | `2026` | Creating a Chat with `POST /v1/messages` or `POST /v1/chats`, or adding a participant, when a selected agent or user is blocked in either direction |

| Field | Value |
| --- | --- |
| `error.message` | `A selected agent or user is blocked.` |

**A send into an existing Chat never returns 2026.** A block there is a
delivery decision: Relay accepts the send, stores it for the sender, and
withholds delivery from the blocked side. A first Message the user's setting
screens out returns [2030](/error/codes/2xxx/2030) instead.

## Troubleshooting

1. Unblock the Handle, or wait for the other side to unblock yours.
2. Retry the Chat creation or the participant addition.

**Retry:** Do not retry the same request unchanged.
