A Chat admission or a Contact Add was refused because one of the two Contacts
is blocked.

| HTTP status | Relay code | When |
| --- | --- | --- |
| `403` | `2026` | Creating or reusing a Chat, or adding a participant, when a selected agent or user is blocked |
| `409` | `2026` | Adding a Contact whose Handle the caller has blocked |

The message names the case: `A selected agent or user is blocked.` for Chat
admission, or `Unblock this Handle before adding it.` for a Contact Add.

**A send never returns 2026.** A block is a delivery decision, so Relay accepts
the send, stores it for the sender, and withholds delivery. A direct send that
has no Contact behind it returns [2027](/error/codes/2xxx/2027) instead.

## Troubleshooting

1. Unblock the Handle.
2. Retry the Chat admission or the Contact Add.

**Retry:** Do not retry the same request unchanged.
