`2017` means: Location sharing works only between a person and an agent.

| HTTP status | What to do |
| --- | --- |
| 409 | Request a location only in a chat with one person. Send a [rating request](/interactions/rating) only into a chat with at least one person. |

## Error response

Relay includes this code in `error.code`. The response also includes `error.status`, `error.message`, and `error.doc_url`; keep `trace_id` when it is present.
