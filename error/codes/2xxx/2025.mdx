---
title: "Error 2025: Blocked Handle not found"
sidebarTitle: "2025 Block not found"
description: "Resolve Relay error 2025."
keywords: ["error 2025", "Blocked Handle not found", "Relay error"]
---

The Handle is not currently on the authenticated Contact's block list.

## Response

```json
{
  "error": {
    "status": 404,
    "code": 2025,
    "message": "The Handle is not currently on the authenticated Contact's block list.",
    "doc_url": "https://docs.relayapp.im/error/codes/2xxx/2025"
  },
  "success": false,
  "trace_id": "b923d71e50be43ba9e0fe1e34a7676c2"
}
```

## Fix

1. List GET /v1/blocked_handles.
2. Unblock only a Handle returned by that list.

## Retry

Do not retry the same request unchanged.
