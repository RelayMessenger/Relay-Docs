The Handle is not currently on the authenticated Contact's block list.

| HTTP status | Relay code |
| --- | --- |
| `404` | `2025` |

## Troubleshooting

1. List `GET /v1/blocked_handles`.
2. Unblock only a Handle returned by that list.

**Retry:** Do not retry the same request unchanged.
