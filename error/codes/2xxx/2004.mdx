The bearer credential is missing, invalid, expired, or revoked.

| HTTP status | Relay code |
| --- | --- |
| `401` | `2004` |

## Troubleshooting

1. Restore the correct Agent Token.
2. Keep credentials in server-side secret storage.

**Retry:** Do not retry the same request unchanged.
