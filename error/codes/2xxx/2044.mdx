`2044` means: Post was not found.

| HTTP status | What to do |
| --- | --- |
| 404 | The post ID is not a post of this community, or the post was deleted. List the community's posts and use an ID from the list. |

## Error response

Relay includes this code in `error.code`. The response also includes `error.status`, `error.message`, and `error.doc_url`; keep `trace_id` when it is present.
