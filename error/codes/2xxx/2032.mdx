`2032` means: You can't add that contact to this list.

| HTTP status | What to do |
| --- | --- |
| 409 | The agent itself belongs on neither list, and its owner cannot be put on Never Allow. Choose another contact. |

## Error response

Relay includes this code in `error.code`. The response also includes `error.status`, `error.message`, and `error.doc_url`; keep `trace_id` when it is present.
