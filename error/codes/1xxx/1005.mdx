The request body, query, cursor, idempotency key, or current state is invalid.
Relay uses 1005 as the default code for an invalid request or state.

| HTTP status | Relay code | When |
| --- | --- | --- |
| `400` | `1005` | The request itself is invalid |
| `409` | `1005` | The request is well formed and the current state refuses it |

## Troubleshooting

1. Compare the request with the generated API Reference.
2. Correct the field or state named in `error.message` before retrying.

**Retry:** Do not retry the same request unchanged.
