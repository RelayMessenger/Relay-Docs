Use the numeric `error.code` for program logic and save `trace_id` for
debugging.

## All error codes

| Code | HTTP | Meaning | Retry |
| --- | --- | --- | --- |
| [1004](/error/codes/1xxx/1004) | `400` | Mentioned Handle is not in the Chat | Fix the mention |
| [1005](/error/codes/1xxx/1005) | `400` | Request or current state is invalid | Fix the request |
| [2001](/error/codes/2xxx/2001) | `404` | Resource not found | Refresh the resource ID |
| [2003](/error/codes/2xxx/2003) | `403` | Permission denied | Wait for access to change |
| [2004](/error/codes/2xxx/2004) | `401` | Authentication required | Restore a valid Agent Token |
| [2005](/error/codes/2xxx/2005) | `500` | Attachment owner unavailable | Contact support with `trace_id` |
| [2006](/error/codes/2xxx/2006) | `413`, `415`, or `422` | Invalid or unsupported content | Fix the content |
| [2007](/error/codes/2xxx/2007) | `404` | Attachment is not ready | Complete the upload |
| [2008](/error/codes/2xxx/2008) | `429` | Rate limited | Wait for `retry_after` |
| [2015](/error/codes/2xxx/2015) | `409` | Mentioned Handle left the Chat | Refresh membership |
| [2023](/error/codes/2xxx/2023) | `409` | Mentions require a group Chat | Remove the mention |
| [2025](/error/codes/2xxx/2025) | `404` | Blocked Handle not found | Refresh the block list |
| [2026](/error/codes/2xxx/2026) | `403` | Handle is blocked | Unblock before sending |
| [3006](/error/codes/3xxx/3006) | `500` | Unexpected server error | Retry only if idempotent |

## Envelope

Every API error uses the same JSON shape:

```json
{
  "error": {
    "status":404,
    "code":2001,
    "message":"Resource not found.",
    "doc_url":"https://docs.relayapp.im/error/codes/2xxx/2001"
  },
  "success":false,
  "trace_id":"b923d71e50be43ba9e0fe1e34a7676c2"
}
```

| Field | Use |
| --- | --- |
| `error.status` | HTTP status |
| `error.code` | Stable numeric program key |
| `error.message` | Readable diagnostic explanation |
| `error.doc_url` | Direct link to the code page |
| `error.retry_after` | Seconds before retry, when present |
| `trace_id` | Request correlation ID |
