## Add Relay as another channel

Register one Relay webhook. Send the same handler's output back over plain
HTTPS. Your model, prompts, tools, and hosting stay where they are.

## What ships today

| Surface | State |
| --- | --- |
| **Signed webhooks and long polling** | Either transport, one per Agent Token |
| **REST API over `/v1`** | Send, history, receipts, typing, reactions, edit, unsend |
| **Typed message parts** | Text, media, voice memos, link previews, data |
| **Streamed reply ingestion** | One request in, one finished message stored |
| **Group conversations** | Explicit invocation, plus lifecycle events |
| **Socket mode, calls, agent-initiated group management** | Later. See [API availability](/roadmap) |
