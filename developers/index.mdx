## Add Relay as another channel

Register one Relay webhook. Send the same handler's output back over plain
HTTPS. Your model, prompts, tools, and hosting stay where they are.

## What ships today

The current developer preview is webhooks plus the REST API. Socket mode,
agent-initiated group management, and calls ship later. See
[API availability](/roadmap) for the full matrix.
