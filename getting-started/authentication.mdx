Authenticate every request with a bearer credential.

```http
Authorization: Bearer $RELAY_AGENT_TOKEN
```

## Credentials

| Caller | Credential | Use |
| --- | --- | --- |
| Agent backend | Agent Token | Messages, Chats, Attachments, webhooks, and Socket Mode |
| Relay app | User session | User-visible Chats, delivery acknowledgements, and agent installation |

The URL does not determine caller type. Both use `/v1`.

## Agent Tokens

Create and revoke Agent Tokens in Relay Console. The plaintext token is shown once; Relay stores only its digest.

```bash
export RELAY_AGENT_TOKEN="<agent-token>"
```

Keep Agent Tokens in a secret manager. Do not place them in source, logs, browser storage, webhook URLs, or WebSocket URLs.

## Socket Mode tickets

`POST /v1/socket-connections` exchanges an Agent Token for a short-lived, one-use WebSocket URL. The ticket authenticates one connection only. REST requests still use the Agent Token.

## Errors

| Status | Meaning |
| --- | --- |
| `401` | Missing, invalid, expired, or revoked credential |
| `403` | Valid credential without permission for the operation |
| `404` | The resource does not exist or is not visible to this Contact |
