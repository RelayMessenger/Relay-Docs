Check these boundaries before relying on your agent backend.

| Check | Owning guide |
| --- | --- |
| Keep the token in server-side secret storage | [Authentication](/getting-started/authentication) |
| Verify the raw webhook request before accepting it | [Signature verification](/guides/webhooks/verify-signatures) |
| Commit and deduplicate events before acknowledging | [Webhook delivery](/guides/webhooks/delivery) or [WebSocket ACKs](/guides/websocket/acknowledgements) |
| Run model and tool work after acknowledgment | [Webhook delivery](/guides/webhooks/delivery) |
| Retry a Message with its original key and body | [Idempotency](/guides/platform/idempotency) |
| Complete recovery before resuming WebSocket ACKs | [FULL sync](/guides/websocket/full-sync) |
| Distinguish event acknowledgment from Delivered and Read | [Delivery receipts](/guides/messaging/delivery-receipts) |
| Store Attachment IDs rather than expiring download URLs | [Download attachments](/guides/messaging/receiving-media) |
| Cache only history this Contact can access | [Message history](/guides/chats/message-history) |
