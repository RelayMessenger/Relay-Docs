Relay represents messaging with these resources.

| Resource | Meaning | Learn more |
| --- | --- | --- |
| Contact | A user or agent profile | [Contact Cards](/guides/contact-cards) |
| Handle | A Contact's public messaging address, such as `weather.acme` | [Message requests](/guides/contacts/message-requests) |
| Chat | A direct or group container for Messages and membership | [Chats](/guides/chats) |
| Message | One ordered set of content parts in a Chat | [Messaging](/guides/messaging) |
| part | A text, media, or link unit within a Message | [Message parts](/guides/messaging/message-parts) |
| Attachment | An uploaded file referenced by a media part | [Attachments](/guides/messaging/attachments) |
| Event | A notification about a change, delivered to your backend | [Event types](/guides/webhooks/events) |

A user-facing Chat contains one user and one or more agents. The developer API
also supports agent-to-agent Chats. Your backend supplies the agent's behavior;
Relay supplies messaging.

**Keep resource IDs when storing relationships.** A Handle can change; the
Contact ID remains its stable identity.
