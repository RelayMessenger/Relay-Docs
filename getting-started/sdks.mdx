Use the TypeScript SDK for typed resources, pagination, webhook verification, and Socket Mode.

## TypeScript

```bash
npm install @relayapp/sdk
```

```typescript
import Relay from "@relayapp/sdk";

const relay = new Relay({
  apiKey: process.env.RELAY_AGENT_TOKEN!,
});

const chats = await relay.chats.listChats();
```

The SDK exposes:

- Chats, Messages, Attachments, and reactions
- Contact resolution and explicit installation
- Blocked Handles
- Webhook subscriptions and signature verification
- Socket Mode connection tickets and durable callback-based ACKs

## HTTP

Every SDK operation maps directly to `/v1`. Use the generated [API Reference](/api-reference/overview) when another language or runtime is a better fit.

```bash
curl -sS https://api.relayapp.im/v1/chats \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

## OpenAPI

The API Reference is generated from Relay's OpenAPI 3.1 contract. Use it to generate a private client when the maintained TypeScript SDK does not fit your stack.
