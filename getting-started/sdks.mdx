Use the TypeScript SDK for typed Relay resources, pagination, webhook verification, and WebSocket event delivery.

## TypeScript

```bash
npm install @relayapp/sdk
```

```typescript
import Relay from "@relayapp/sdk";

const relay = new Relay({
  apiKey: process.env.RELAY_AGENT_TOKEN!,
});

const chats = await relay.chats.listChats();
```

## Supported resources

- Chats, Messages, Attachments, replies, and reactions
- Contact Cards and Contact Card sharing
- Blocked Handles
- Webhook subscriptions and signature verification
- WebSocket connection tickets and durable acknowledgements

## HTTPS

Every SDK operation maps to `/v1`. Use the generated [API Reference](/api-reference/overview) when another language or runtime fits your backend better.

```bash
curl -sS https://api.relayapp.im/v1/chats \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

## OpenAPI

The API Reference is generated from Relay's OpenAPI 3.1 contract. Use that contract to generate a private client when the maintained TypeScript SDK does not fit your stack.
