Every agent below is published source you can clone today, point at an Agent
Token, and text.

## Agents

Each project turns an agent you already run into a Relay Contact a person can
message. Every one is open source and runs on your own machine or account.

### Claude Code

Text your running Claude Code session and read its work back in the Chat, so a
repository stays reachable from your phone.

- **Stack:** Node.js, Claude Code, `relay-claude-channel@0.3.0-staging.4`
- **Features:** Sender allowlist, direct Messages and addressed group Messages,
  Chat marked Read when a turn starts, one reply per turn
- **Set up:** [Relay channel for Claude Code](/ecosystem/claude-code),
  [Relay-SDK `packages/claude-code`](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/claude-code)

### Hermes Agent

Message an always-on Hermes Agent and get its answer in the same Chat, with
staging and production agents kept in separate profiles.

- **Stack:** Python `3.11` through `3.13`, Hermes Agent, `relay-hermes@1.0.0rc1`
- **Features:** Contact allowlist, Chat marked Read when processing starts,
  restart-safe inbox, ordinary chat continues while operator slash commands are
  refused
- **Set up:** [Relay for Hermes](/ecosystem/hermes),
  [RelayMessenger/Relay-Hermes](https://github.com/RelayMessenger/Relay-Hermes)

### OpenClaw

Message a self-hosted OpenClaw gateway, and let one gateway answer as several
separate Relay Contacts.

- **Stack:** Node.js, OpenClaw `2026.8.1`,
  `@relaymessenger/openclaw-plugin@0.4.0-staging.3`
- **Features:** Multiple named accounts, direct Messages and mention-addressed
  group Messages, owner-only token file, repeat-safe replies
- **Set up:** [Relay for OpenClaw](/ecosystem/openclaw),
  [Relay-SDK `packages/openclaw`](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/openclaw)

## Recipes

These six recipes are building blocks, not agents. Each proves one Relay
behavior you can lift into a project of your own.

Source:
[Relay-SDK `cookbook`](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook)

| Example | Runtime | What it proves |
| --- | --- | --- |
| [Webhook receiver](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/webhook-receiver) | Server or serverless-friendly HTTPS handler | Exact-body verification, SQLite acceptance before `2xx`, replay deduplication, and idempotent replies |
| [WebSocket agent](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/websocket-agent) | Always-on Node.js process | Durable acceptance before SDK-managed ACK, replay deduplication, and complete REST-backed FULL sync |
| [Cloudflare Think agent](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/cloudflare-think-agent) | Cloudflare Worker | `@cloudflare/think@0.17.0`, Relay Chat SDK Webhook ingress, and Action-owned idempotent sends |
| [Send a Message](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/send-a-message) | Local Node.js command | Send one idempotent text Message to a Chat |
| [Send an image](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/send-an-image) | Local Node.js command | Allocate and upload one image, then send its stable Attachment identity |
| [Send a voice memo](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/send-a-voice-memo) | Local Node.js command | Allocate and upload audio, then send it through the voice memo operation |

Webhooks and WebSocket carry the same event envelope. A saved Webhook
subscription selects signed HTTP delivery. With zero subscriptions, the
always-on process connects to `/v1/websocket`.

## Package versions

The current recipes pin:

| Package | Version |
| --- | --- |
| `@relaymessenger/sdk` | `0.3.0-staging.8` |
| `@relaymessenger/chat-sdk-adapter` | `0.3.0-staging.6` |
| `@cloudflare/think` | `0.17.0` |
| `chat` | `4.39.0` |

The lockfile resolves the Chat SDK adapter to the published staging registry
artifact and verifies its integrity during installation.

## Run locally

Use Node.js `22.22.3` or newer:

```bash
git clone --branch staging https://github.com/RelayMessenger/Relay-SDK.git
cd Relay-SDK
npm ci
npm run validate:cookbook
```

The root validation command uses local mocks and dry builds. It contacts
neither Relay nor Cloudflare.
