Branch on HTTP status and the numeric error code.

```json
{
  "error": {
    "status": 422,
    "code": 2006,
    "message": "part_index does not exist.",
    "doc_url": "https://docs.relayapp.im/error/codes/2xxx/2006/"
  },
  "success": false,
  "trace_id": "b923d71e50be43ba9e0fe1e34a7676c2"
}
```

| Field | Use |
| --- | --- |
| `status` | HTTP status repeated in the body |
| `code` | Stable numeric branch |
| `message` | Short diagnosis |
| `doc_url` | Error reference |
| `retry_after` | Delay in seconds when present |
| `trace_id` | Support correlation |

## Common status handling

| Status | Action |
| --- | --- |
| `400` | Correct the JSON or request fields |
| `401` | Restore the bearer token |
| `403` | Use the correct agent or visible resource |
| `404` | Stop or reconcile the resource ID |
| `409` | Resolve a state or idempotency conflict |
| `413` | Reduce attachment size |
| `415` | Use a supported content type |
| `422` | Correct media, mention, reply, or reaction data |
| `429` | Wait for `retry_after` or `Retry-After` |
| `500`, `503` | Retry an idempotent request with the same key |

For an uncertain message send, keep the same sender, body, and idempotency key.
