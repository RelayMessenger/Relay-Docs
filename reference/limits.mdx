Keep each request inside these local contract limits.

## Messages

| Limit | Value |
| --- | --- |
| Parts per message | 1 to 100 |
| Text value | 1 to 10,000 characters |
| Link value | Up to 2,048 characters |
| Link composition | One link part by itself |
| Direct URL media parts | Up to 40 |
| Direct URL media size | 1 byte to 10 MiB each |
| Idempotency key | 1 to 255 characters |
| New chat recipients | 1 to 31 other Handles |
| Custom reaction | 1 to 32 characters |

## Attachments

| Limit | Value |
| --- | --- |
| Pre-upload size | 1 byte to 100 MiB |
| Filename | 1 to 255 characters |
| Upload URL lifetime | 15 minutes |
| Upload content type | Must equal allocation |
| Upload length | Header and actual bytes must equal allocation |

## Lists

| List | Default | Maximum |
| --- | ---: | ---: |
| Chats | 20 | 100 |
| Chat messages | 50 | 100 |
| Message thread | 50 | 100 |

`next_cursor` is opaque. Pass it unchanged to continue the same list.

## Webhooks

| Limit | Value |
| --- | --- |
| Response timeout | 10 seconds |
| Maximum attempts | 10 |
| Backoff jitter | Up to 10 percent |
| Largest retry delay | 10 minutes |
| Centered retry window | 24 minutes 52.5 seconds |
