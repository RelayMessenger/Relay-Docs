Keep requests within the declared contract.

| Message limit | Value |
| --- | --- |
| Parts | 1 to 100 |
| Text | 1 to 10,000 characters |
| Part index | 0 through 99 |
| Image alt text | Up to 1,000 characters |
| Link URL | HTTPS, up to 2,048 characters |
| Link fallback | 1 to 1,000 characters |
| Audio waveform | Up to 200 values |
| Reaction emoji | 1 to 32 characters |

| Request limit | Value |
| --- | --- |
| Attachment | 1 to 104,857,600 bytes |
| Filename | 1 to 255 characters |
| Upload window | 15 minutes |
| Idempotency key | 1 to 255 allowed characters |
| Page size | 1 to 100, default 50 |
| Cursor | Up to 2,048 characters |
| Chat projection | 2 to 32 participants |

| Webhook limit | Value |
| --- | --- |
| Event types | 13 |
| Response timeout | 10 seconds |
| Durable cycle | 24 attempts or 24 hours |
| Backoff | 5 seconds to 1 hour |
| Retry-After cap | 24 hours |
| Secret overlap | 0 to 604,800 seconds |
| Durable audit | 30 days locally |
| Typing | 90 seconds |

The contract publishes no fixed per-minute quota. Follow `Retry-After` on `429`.
