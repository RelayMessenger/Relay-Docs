Read every current webhook through the frozen `2026-02-03` envelope.

```json
{
  "api_version": "v1",
  "webhook_version": "2026-02-03",
  "event_type": "message.received",
  "event_id": "01993d50-4133-7178-8e16-7c1455c91d43",
  "created_at": "2026-08-28T20:00:00.000Z",
  "trace_id": "b923d71e50be43ba9e0fe1e34a7676c2",
  "agent_id": "01993d50-d2a8-7fe2-8b76-9eaf04816377",
  "data": {
    "chat": {
      "id": "01993d50-d2a8-7fe2-8b76-9eaf04816377",
      "is_group": false
    },
    "id": "01993d50-b4ce-71e6-8e65-35d325d95ddb",
    "direction": "inbound",
    "sender_handle": {
      "handle": "alice",
      "kind": "user"
    },
    "parts": [{"type":"text","value":"Hello"}],
    "sent_at": "2026-08-28T19:59:59.900Z",
    "delivered_at": null,
    "read_at": null
  }
}
```

## Envelope fields

| Field | Use |
| --- | --- |
| `event_id` | Durable deduplication key |
| `event_type` | Selects the data shape |
| `created_at` | Event creation time |
| `trace_id` | Request correlation |
| `webhook_version` | Payload version |
| `api_version` | Relay API envelope version; currently `v1` |
| `agent_id` | Contact identifier of the receiving agent |

## Event names

| Event | Fires when |
| --- | --- |
| `message.sent` | Agent Message commits |
| `message.received` | A Message for the agent commits |
| `message.delivered` | Recipient delivery advances |
| `message.read` | Recipient Read advances |
| `reaction.added` | Reaction add commits |
| `reaction.removed` | Reaction removal commits |
| `participant.added` | A Handle joins a group Chat |
| `participant.removed` | A Handle leaves a group Chat |
| `chat.created` | A visible Chat is created |
| `chat.group_name_updated` | Group name changes |
| `chat.group_icon_updated` | Group image changes |

The two `participant.*` values are Linq-compatible relationship event names.
Relay stores timestamped Contact membership periods in `chat_contact_join`.
There is no global Participant identity table.

Typing and `message.failed` are unsupported. The current API has no typing route
and emits no typing or failed-message event.

## Transport

The envelope is identical over signed webhooks and Socket Mode.

| Mode | Outer transport |
| --- | --- |
| Webhook | The envelope is the signed HTTP request body |
| Socket Mode | The envelope is the `event` field beside a durable `sequence` |

## Message event state

| Event | `sent_at` | `delivered_at` | `read_at` |
| --- | --- | --- | --- |
| `message.sent` | Set | `null` | `null` |
| `message.received` | Set | `null` | `null` |
| `message.delivered` | Set | Set | `null` |
| `message.read` | Set | Set | Set |
