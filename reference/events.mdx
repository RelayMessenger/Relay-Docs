Handle all events through one signed envelope.

```json
{
  "api_version": "v1",
  "webhook_version": "2026-08-28",
  "event_id": "0198f4bc-19a2-7342-b03b-319bcc083563",
  "event_type": "message.delivered",
  "sequence": "484",
  "created_at": "2026-08-28T14:05:00.100Z",
  "trace_id": "9f4d3b65f2e54a98a4558f8877ef9a10",
  "agent_id": "0198f49d-e5c7-78ba-a74f-7ff8186fc242",
  "data": {
    "object": "message_delivered_event_data",
    "object_version": "2026-08-28",
    "message_id": "0198f4ba-3c8e-7e73-9fe9-3d272d9d427e",
    "chat_id": "0198f4a1-27ca-76d2-99ad-59b5d3bb13b2",
    "chat_sequence": "49",
    "recipient": {
      "object": "identity",
      "object_version": "2026-08-28",
      "id": "0198f49e-1718-7559-a251-649968bf7a22",
      "kind": "human",
      "username": "advait",
      "phone_number": "+13135550142",
      "display_name": "Advait",
      "avatar_url": null,
      "created_at": "2026-08-28T12:00:00.000Z"
    },
    "delivered_at": "2026-08-28T14:05:20.000Z"
  }
}
```

| Field | Use |
| --- | --- |
| `event_id` | UUIDv7 deduplication key |
| `event_type` | Selects `data` shape |
| `sequence` | Orders durable agent events |
| `agent_id` | Recipient agent |
| `trace_id` | Correlation |
| `webhook_version` | Pinned contract |

| Event | Fires when |
| --- | --- |
| `message.received` | Another participant message is accepted |
| `message.sent` | Agent message is accepted |
| `message.delivered` | Recipient Delivered advances |
| `message.read` | Recipient Read advances |
| `reaction.added` | Reaction becomes present |
| `reaction.removed` | Reaction becomes absent |
| `chat.created` | Visible chat is created |
| `chat.title.updated` | Group title changes |
| `chat.avatar.updated` | Group avatar changes |
| `participant.added` | Participant joins |
| `participant.removed` | Participant leaves or is removed |
| `typing.started` | Typing starts or refreshes |
| `typing.stopped` | Typing stops |

All except typing are durable. Typing is ephemeral. Successful `message.received` delivery records Delivered; Read remains explicit.
