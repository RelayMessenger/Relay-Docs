Create an organization-managed agent in Relay Console and save its Agent Token for your backend.

For a developer-managed `.dev` identity, use [Create an agent with the CLI](/build/agents/create-agent).

## Before you start

- A [Relay Console](https://console.staging.relayapp.im) account with access to your organization and permission to create agents.
- Private server-side storage for the returned Agent Token.

## Create the agent

Open **Create agent** in Relay Console and fill in the identity fields:

| Field | What to enter |
| --- | --- |
| Name | The display name users see in Relay. |
| Handle | For the default organization Handle, enter the local part: 3 to 32 lowercase letters, numbers, or underscores, starting with a letter. Console appends your organization's namespace, so `forecast` becomes `forecast.yourorg`. |
| About | An optional description. |

Press **Create agent**. For avatar setup, follow [Profile photos](/build/identity/profile-photos).

## Choose a connection and save the token

<Steps>
  <Step title="Choose your connection">
    Select **WebSocket** or **Webhook** in the creation flow. Follow the
    [WebSocket](/build/events/websocket) or [Webhooks](/build/events/webhooks) guide for the
    connection you choose.
  </Step>
  <Step title="Copy the Agent Token">
    In **Connect your backend**, choose **Manually**, then **Copy token**.
    Store the token in private server-side storage before closing the dialog.
  </Step>
  <Step title="Connect your backend">
    Use the saved token with the matching API origin,
    `https://api.staging.relayapp.im` for the Console linked above.
    Continue with your selected connection guide and verify an incoming Message
    reaches your backend and receives a reply.
  </Step>
</Steps>

**The creation flow shows the full Agent Token once.** Keep it private when
configuring your backend.

## When it fails

### Recover from setup failures

| Outcome | Next action |
| --- | --- |
| Creation result is uncertain | Check your organization's agent list before submitting another create. |
| Agent created, avatar upload failed | Keep the identity and retry the avatar from the agent's **Settings** page. |
| Token was not saved | Open the agent's **Settings**, find **Agent token**, and choose **Rotate token** to receive a replacement. |
| Backend connection failed | Keep the identity and token; troubleshoot the selected connection. |

<Warning>
Rotating a token stops the previous token from working. Update your backend
with the replacement immediately and save it privately before closing its dialog.
</Warning>


| Code | HTTP | When | What to do |
| --- | --- | --- | --- |
| [2001](/api-reference/errors#2001) | 404 | Resource is unavailable | Check the ID and token scope. |
| [3006](/api-reference/errors#3006) | 500 | Server rejected the operation unexpectedly | Keep the request ID and check history before retrying the same send key. |
