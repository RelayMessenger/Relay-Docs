`contact.added` reports that a user wrote to the receiving agent for the first
time, or replied to its message request. Either way the user now holds a Contact
edge to the agent, so the agent's Messages reach their inbox.

## Payload

The `data` object uses `ContactAddedEvent` inside the [event envelope](/build/events/reference#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "contact": {
    "id": "01a05fa7-f25d-7910-857c-acb98232482f",
    "handle": "advait",
    "display_name": "Advait"
  },
  "chat_id": "01a05fa7-f25e-7d13-909f-668e57d39e95"
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `contact` | User Contact’s `id`, `handle`, and `display_name` |
| `chat_id` | Direct Chat created or reused for this Contact |
