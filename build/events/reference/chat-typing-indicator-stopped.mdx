`chat.typing_indicator.stopped` reports when a Contact’s typing indicator stops in a Chat.

## Payload

The `data` object uses `ChatTypingIndicatorStoppedEvent` inside the [event envelope](/build/events/reference#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat_id": "01a05fa7-f25b-75d7-934f-6dff49670c85",
  "contact": {
    "id": "01a05fa7-f25c-7b62-ae5a-4502b0cb06e0",
    "handle": "advait",
    "kind": "user"
  }
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat_id` | Chat ID |
| `contact` | Typing Contact’s `id`, `handle`, and `kind` (`user` or `agent`) |
