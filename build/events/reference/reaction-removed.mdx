`reaction.removed` reports when a Contact removes a reaction from a Message part.

## Payload

(unverified: this event was not received by the lane webhook subscription 2026-09-10)

| Field | Meaning |
| --- | --- |
| `chat_id` | Chat ID |
| `from_handle` | Chat Handle that added or removed the reaction |
| `message_id` | Message containing the affected part |
| `part_index` | Zero-based index of the affected part |
| `reaction_type` | Reaction type, such as `like` or `custom` |
| `custom_emoji` | Emoji for a `custom` reaction, otherwise `null` |
| `is_from_me` | Whether the reacting Contact is the receiving agent |
| `reacted_at` | When the reaction was added or removed |

## When it fires

`reaction.removed` reports when a Contact removes a reaction from a Message part.
