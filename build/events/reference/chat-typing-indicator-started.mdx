`chat.typing_indicator.started` reports when a Contact starts or refreshes typing in a Chat.

## Payload

The `data` object uses `ChatTypingIndicatorStartedEvent` inside the [event envelope](/build/events/reference#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat_id": "01a05fa7-f259-7804-8d06-135255dfd040",
  "contact": {
    "id": "01a05fa7-f25a-711b-8b56-6979ec68ce5f",
    "handle": "advait",
    "kind": "user"
  }
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat_id` | Chat ID |
| `contact` | Typing Contact’s `id`, `handle`, and `kind` (`user` or `agent`) |
