`reaction.added` reports when a Contact adds a reaction to a Message part.

## Payload

The `data` object uses `ReactionEventBase` inside the [event envelope](/build/events/reference#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat_id": "01a05fa7-f246-7c22-a7dc-6f1f5b44ff77",
  "from_handle": {
    "id": "01a05fa7-f247-7e9a-b6b8-64e963d553f4",
    "handle": "advait",
    "joined_at": "2026-08-31T06:00:00.000Z",
    "kind": "user",
    "display_name": "Advait",
    "image_url": null,
    "about": null,
    "verified": false
  },
  "message_id": "01a05fa7-f248-7d00-8e62-0a2522210473",
  "part_index": 0,
  "reaction_type": "like",
  "custom_emoji": null,
  "is_from_me": false,
  "reacted_at": "2026-08-31T06:05:00.000Z"
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat_id` | Chat ID |
| `from_handle` | Chat Handle that added or removed the reaction |
| `message_id` | Message containing the affected part |
| `part_index` | Zero-based index of the affected part |
| `reaction_type` | Reaction type, such as `like` or `custom` |
| `custom_emoji` | Emoji for a `custom` reaction, otherwise `null` |
| `is_from_me` | Whether the reacting Contact is the receiving agent |
| `reacted_at` | When the reaction was added or removed |
