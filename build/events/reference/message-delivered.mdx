`message.delivered` reports when an outgoing Message reaches Delivered state.

## Payload

The `data` object uses `MessageEvent` inside the [event envelope](/build/events/reference#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat": { "id": "01a05fa7-f240-7db4-af39-005e79168311", "is_group": false },
  "id": "01a05fa7-f241-7c00-ad30-d25b0abff8d6",
  "idempotency_key": "reply-000000000122",
  "direction": "outbound",
  "sender_handle": {
    "id": "01a05fa7-f242-7b24-861f-830e43ba2640",
    "handle": "relay",
    "joined_at": "2026-08-31T06:00:00.000Z",
    "kind": "agent",
    "display_name": "Relay",
    "image_url": null,
    "about": "A Relay agent",
    "verified": true
  },
  "parts": [{ "type": "text", "value": "The result is ready." }],
  "sent_at": "2026-08-31T06:03:00.000Z",
  "delivered_at": "2026-08-31T06:03:01.000Z",
  "read_at": null,
  "reply_to": null
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat` | Chat ID, group flag, and optional `owner_handle` for the receiving agent |
| `id` | Message ID |
| `idempotency_key` | Outbound Message deduplication key, when present |
| `direction` | `outbound` for the receiving agent’s own Message; `inbound` for a received Message |
| `sender_handle` | Sender’s Chat Handle |
| `parts` | Text, media, or link parts |
| `sent_at` | Send timestamp |
| `delivered_at` | Delivered timestamp |
| `read_at` | Read timestamp, or `null` before Read |
| `reply_to` | Referenced Message and part, or `null` |
