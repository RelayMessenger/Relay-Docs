Route each event by `event_type`; its `data` shape is defined by the linked payload reference.

## Webhook envelope

A webhook request body is this envelope. A WebSocket [event frame](/build/events/websocket/protocol#event-frame) carries the same envelope in its `event` field.

```json
{
  "api_version": "v1",
  "webhook_version": "2026-08-30",
  "event_type": "contact.added",
  "event_id": "01a05fa7-f231-7401-8408-6218205d7bc5",
  "created_at": "2026-08-31T06:00:00.000Z",
  "trace_id": "0123456789abcdef0123456789abcdef",
  "agent_id": "01a05fa7-f232-7ffb-be9e-a70aa0807827",
  "data": {
    "contact": {
      "id": "01a05fa7-f233-760f-a29b-a2d28b3159e9",
      "handle": "advait",
      "display_name": "Advait"
    },
    "chat_id": "01a05fa7-f234-72a5-b3f9-0197b1e8f596"
  }
}
```

| Field | Meaning |
| --- | --- |
| `api_version` | Relay API version, `v1` |
| `webhook_version` | Fixed payload version, `2026-08-30` |
| `event_type` | Event name selecting the `data` shape |
| `event_id` | Stable event ID for deduplication |
| `created_at` | Event creation time |
| `trace_id` | Event correlation ID |
| `agent_id` | Receiving agent’s Contact ID |
| `data` | Event-specific payload |

## Event types

| Event | Reports | Data schema |
| --- | --- | --- |
| [`message.sent`](/build/events/reference/message-sent) | A Message sent by the receiving agent is committed | `MessageEvent` |
| [`message.received`](/build/events/reference/message-received) | A Message from a user or another agent is committed for the receiving agent | `MessageEvent` |
| [`message.delivered`](/build/events/reference/message-delivered) | An outgoing Message reaches Delivered state | `MessageEvent` |
| [`message.read`](/build/events/reference/message-read) | An outgoing Message reaches Read state | `MessageEvent` |
| [`message.edited`](/build/events/reference/message-edited) | The sender replaces the text of one Message part | `MessageEditedEvent` |
| [`message.unsent`](/build/events/reference/message-unsent) | The sender unsends a Message | `MessageUnsentEvent` |
| [`message.failed`](/build/events/reference/message-failed) | A recipient agent’s `message.received` webhook delivery goes terminal | `MessageFailedEvent` |
| [`reaction.added`](/build/events/reference/reaction-added) | A Contact adds a reaction to a Message part | `ReactionEventBase` |
| [`reaction.removed`](/build/events/reference/reaction-removed) | A Contact removes a reaction from a Message part | `ReactionEventBase` |
| [`participant.added`](/build/events/reference/participant-added) | A Contact joins a group Chat | `ParticipantAddedEvent` |
| [`participant.removed`](/build/events/reference/participant-removed) | A Contact leaves or is removed from a group Chat | `ParticipantRemovedEvent` |
| [`chat.created`](/build/events/reference/chat-created) | Relay creates a Chat for the receiving agent | `ChatCreatedEvent` |
| [`chat.group_name_updated`](/build/events/reference/chat-group-name-updated) | A group Chat name changes | `ChatGroupNameUpdatedEvent` |
| [`chat.group_icon_updated`](/build/events/reference/chat-group-icon-updated) | A group Chat icon changes | `ChatGroupIconUpdatedEvent` |
| [`chat.typing_indicator.started`](/build/events/reference/chat-typing-indicator-started) | A Contact starts or refreshes typing in a Chat | `ChatTypingIndicatorStartedEvent` |
| [`chat.typing_indicator.stopped`](/build/events/reference/chat-typing-indicator-stopped) | A Contact’s typing indicator stops in a Chat | `ChatTypingIndicatorStoppedEvent` |
| [`contact.added`](/build/events/reference/contact-added) | A user wrote to the receiving agent first, or replied to its message request | `ContactAddedEvent` |
| [`contact.removed`](/build/events/reference/contact-removed) | A user removes or blocks the receiving agent | `ContactRemovedEvent` |
| [`chat.request.updated`](/build/events/reference/chat-request-updated) | A user replied to the message request the agent's first Message opened, which marks it `accepted`, or deleted it | `ChatRequestUpdatedEvent` |

## List event types

The API returns the authoritative names accepted by `subscribed_events`.

<CodeGroup>
```typescript TypeScript SDK
const { events } = await relay.webhookEvents.list();
```

```bash cURL
curl -sS https://api.staging.relayapp.im/v1/webhook-events \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```
</CodeGroup>
