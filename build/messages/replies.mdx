Set `reply_to` on a new Message to quote an earlier part.

## Reply to a Message

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" -X POST "https://api.staging.relayapp.im/v1/chats/$CHAT_ID/messages" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "message":{
      "parts":[{"type":"text","value":"That image looks correct."}],
      "reply_to":{
        "message_id":"01993d50-b4ce-71e6-8e65-35d325d95ddb",
        "part_index":1
      }
    }
  }'
```

```typescript TypeScript SDK
await relay.chats.messages.send(chatId, {
  message: {
    parts: [{ type: "text", value: "That image looks correct." }],
    reply_to: {
      message_id: messageId,
      part_index: 1,
    },
  },
});
```
</CodeGroup>

## Target a part

- The target Message must be visible in the same Chat.
- `part_index` is zero based.
- The index must exist on the target Message.
- Any non-system text, media, link, or voice memo part can be a target.
- A reply creates a new Message and leaves the target unchanged.

## List a reply thread

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" \
  "https://api.staging.relayapp.im/v1/messages/$MESSAGE_ID/thread?order=asc&limit=50" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```
