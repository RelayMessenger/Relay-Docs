Check these boundaries before relying on your agent backend.

| Check | Owning guide |
| --- | --- |
| Keep the token in server-side secret storage | [Authentication](/start/authentication) |
| Verify the raw webhook request before accepting it | [Signature verification](/build/events/verify-signatures) |
| Commit and deduplicate events before acknowledging | [Webhook delivery](/build/events/delivery) or [WebSocket ACKs](/build/events/websocket/acknowledgements) |
| Run model and tool work after acknowledgment | [Webhook delivery](/build/events/delivery) |
| Retry a Message with its original key and body | [Idempotency](/build/live/idempotency) |
| Complete recovery before resuming WebSocket ACKs | [FULL sync](/build/events/websocket/full-sync) |
| Distinguish event acknowledgment from Delivered and Read | [Delivery receipts](/build/messages/receipts) |
| Store Attachment IDs rather than expiring download URLs | [Download attachments](/build/messages/receiving-media) |
| Cache only history this Contact can access | [Message history](/build/chats/history) |
