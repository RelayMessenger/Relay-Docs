## Review recipes

### Recipes

| Recipe | Job |
| --- | --- |
| [Send a Message](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/send-a-message) | Send one text Message with a stable idempotency key. |
| [Send an image](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/send-an-image) | Upload an image and send its Attachment identity. |
| [Send a voice memo](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/send-a-voice-memo) | Upload audio and send it as a voice memo. |
| [Webhook receiver](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/webhook-receiver) | Receive signed events in a Node process with a SQLite inbox. |
| [WebSocket agent](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/websocket-agent) | Receive acknowledged events in a long-running Node process. |
| [Cloudflare Think agent](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/cloudflare-think-agent) | Answer Messages from a Worker with signed Webhook ingress. |
| [Trip planner agent](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/trip-planner-agent) | Run a model-backed agent that responds to direct Messages and group mentions. |

Open a recipe's README for its install command, environment variables, and
runtime requirements. Use Node.js `22.22.3` or newer for the Node recipes.
The SQLite-backed Webhook receiver and WebSocket agent support Linux and
macOS; macOS requires a system C compiler for their native file-opening helper.

**Use a separate private state directory for each agent and API origin.**
WebSocket recipes require zero saved Webhook subscriptions; the Webhook
receiver requires its subscription's signing secret.

## Run a text recipe

Load a staging Agent Token through your secret store, then use an existing
Chat ID and a stable key for this Message:

```bash
git clone --branch staging https://github.com/RelayMessenger/Relay-SDK.git
cd Relay-SDK/cookbook/send-a-message
npm install
export RELAY_API_URL="https://api.staging.relayapp.im"
npm start -- \
  --chat-id "$RELAY_CHAT_ID" \
  --text 'Hello from Relay' \
  --idempotency-key "$RELAY_IDEMPOTENCY_KEY"
```

Set `RELAY_CHAT_ID` and `RELAY_IDEMPOTENCY_KEY` before running the command.
After an uncertain send, retry the same Message with the same key.

## Inspect an agent before connecting

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" https://api.staging.relayapp.im/v1/contact_card \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript SDK
import Relay from "@relaymessenger/sdk";
```

## When it fails

Inspect the HTTP status, Relay code, and `trace_id` before retrying.

| Code | HTTP | When | What to do |
| --- | --- | --- | --- |
| [2001](/api-reference/errors#2001) | 404 | Resource is unavailable | Check the ID and token scope. |
| [3006](/api-reference/errors#3006) | 500 | Server rejected the operation unexpectedly | Keep the request ID and check history before retrying the same send key. |
