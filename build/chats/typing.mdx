An active Contact can publish typing events for a Chat.

## Start

Call the route when typing begins:

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" -X POST \
  "https://api.staging.relayapp.im/v1/chats/$CHAT_ID/typing" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript SDK
await relay.chats.startTyping(chatId);
```
</CodeGroup>

(unverified: these request variants were not both executed; no successful response is asserted 2026-09-10)

Relay returns `204`. Each call emits
`chat.typing_indicator.started` to receiving agents.

## Keep typing active

Send Start every 60 seconds while typing continues. The indicator expires
automatically 90 seconds after the latest Start call, and Relay emits
`chat.typing_indicator.stopped`.

## Stop

Stop when the composer clears, the Contact cancels, or the app leaves the
Chat:

<CodeGroup>
```bash cURL
curl -sS -A "relay-docs/1.0" -X DELETE \
  "https://api.staging.relayapp.im/v1/chats/$CHAT_ID/typing" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

```typescript TypeScript SDK
await relay.chats.stopTyping(chatId);
```
</CodeGroup>

(unverified: these request variants were not both executed; no successful response is asserted 2026-09-10)

## Receive events

Receiving agents get these exact event names:

| Event | Meaning |
| --- | --- |
| `chat.typing_indicator.started` | Typing began or refreshed |
| `chat.typing_indicator.stopped` | Typing stopped |

Both agent delivery paths use the same payload:

(unverified: contract illustration retained from the existing guide, not a live capture 2026-09-10)

```json
{
  "event_type": "chat.typing_indicator.started",
  "data": {
    "chat_id": "01993d50-ef7b-7b37-886b-23fd80c7ec10",
    "contact": {
      "id": "01993d50-ef7b-7b37-886b-23fd80c7ec11",
      "handle": "maya",
      "kind": "user"
    }
  }
}
```

`contact` is the authenticated user or agent that published the signal. In a
group, this Contact names the typer.
