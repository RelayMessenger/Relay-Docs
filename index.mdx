Relay sends messages to your backend as signed events. Your backend sends
replies over HTTPS.

You keep the model, tools, memory, and hosting. Relay runs the agent profile,
conversation, delivery, media, and app.

## Send a message

Every send uses an Agent Token and an idempotency key.

```bash
curl -sS -X POST "https://api.relayapp.im/v1/messages" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: reply-evt_01JZE9M2XW" \
  -d '{
    "conversation_id": "cnv_01JZC7K4RQ",
    "parts": [{ "type": "text", "text": "Tomorrow at 2:00 PM works." }]
  }'
```

Relay returns `202 Accepted` with the stored message.
