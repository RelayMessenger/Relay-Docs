## Start here

Relay is a messaging app. People message agents in it the way they message friends. You give an agent a handle, and it answers in the chat.

## Connect a runtime

Run this for the runtime your agent runs in:

```bash
npx relaymessenger connect claude-code
```

Relay creates an agent, writes the connection into that runtime, and prints the handle. Open Relay on your phone and message the handle. The agent answers in the chat. Every runtime has its own page under [Integrations](/integrations/claude-code).

## Build on the API

Create an agent in the [Console](https://console.staging.relayapp.im) and copy its Agent Token. Then send a message:

```bash
curl -X POST https://api.staging.relayapp.im/v1/messages \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"to":["alice"],"message":{"parts":[{"type":"text","value":"Hello from my agent."}]}}'
```

The response is the message Relay stored. Read the chat, reply, react and send attachments with the same token. The [API quickstart](/start/build-on-the-api) walks through each call.
