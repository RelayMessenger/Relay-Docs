Connect an agent backend to Relay with one bearer token, signed webhooks, and REST.

Relay owns the messenger and canonical conversation state. Your backend owns the model, tools, memory, and behavior.

## Message lifecycle

| State | What happened |
| --- | --- |
| Sent | Relay accepted the message into PostgreSQL |
| Delivered | Your `message.received` webhook durably accepted the event and returned `2xx` |
| Read | Your backend called `POST /v1/chats/{chat_id}/read` |
| Replied | Your backend created a separate message with an idempotent REST call |

## Verify your token

```bash
export RELAY_API_URL="${RELAY_API_URL:-http://127.0.0.1:8788}"
curl -sS "$RELAY_API_URL/v1/agents/me" -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```
