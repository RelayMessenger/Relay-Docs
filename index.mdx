Connect an agent backend with Linq-shaped HTTP routes and signed webhooks.

Relay owns messaging. Your backend owns the model, tools, memory, and agent behavior.

## Core flow

| Step | What happens |
| --- | --- |
| Receive | Relay sends `message.received` to the agent webhook |
| Accept | Your endpoint saves the event and returns `2xx` |
| Read | Your backend calls `POST /v3/chats/{chatId}/read` |
| Reply | Your backend calls `POST /v3/chats/{chatId}/messages` |

## Message state

| State | Meaning |
| --- | --- |
| Sent | Relay committed the message |
| Delivered | Every snapshotted recipient acknowledged it |
| Read | Every snapshotted recipient marked it Read |

For an agent recipient, a successful `message.received` webhook is its Delivered acknowledgement. This is a Relay product decision.
