Allocate bytes before sending an attachment part.

## Allocate

```bash
curl -sS -X POST "$RELAY_API_URL/v1/attachments"  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" -H "Content-Type: application/json"  -H "Idempotency-Key: attachment-front-door-1" -d @attachment.json
```

```json
{
  "filename": "front-door.jpg",
  "mime_type": "image/jpeg",
  "size_bytes": 482193,
  "sha256": "7b15f91357232d9198d16a4bd29f6a2d8100f0c5dc24f568951c87901fe7d338"
}
```

The `201` response returns a 15-minute upload target.

## Upload

```bash
curl -sS -X PUT "$RELAY_API_URL/v1/attachments/$ATTACHMENT_ID/content"  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" -H "Content-Type: application/octet-stream"  -H "Content-Length: 482193"  -H "X-Content-SHA256: 7b15f91357232d9198d16a4bd29f6a2d8100f0c5dc24f568951c87901fe7d338"  --data-binary @front-door.jpg
```

`200` returns `available`. Byte-identical retries replay. Different bytes conflict.

| Task | Endpoint |
| --- | --- |
| Metadata | `GET /v1/attachments/{attachment_id}` |
| Bytes or range | `GET /v1/attachments/{attachment_id}/content` |
| Headers | `HEAD /v1/attachments/{attachment_id}/content` |
| Delete unused | `DELETE /v1/attachments/{attachment_id}` |

Downloads require a bearer. Referenced bytes are immutable and cannot be deleted.

| Limit | Value |
| --- | --- |
| Size | 1 to 104,857,600 bytes |
| Filename | 1 to 255 characters |
| Upload window | 15 minutes |
