Allocate an attachment, upload exact bytes, then reference its ID.

## Allocate

```bash
curl -sS -X POST "$RELAY_API_URL/v1/attachments" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "front-door.jpg",
    "content_type": "image/jpeg",
    "size_bytes": 482193
  }'
```

The `200` response returns an opaque signed upload URL:

```json
{
  "attachment_id": "01993d50-c6ea-7439-82fc-f040f274d383",
  "upload_url": "https://api.relayapp.im/attachment-transfers/<signed-claim>",
  "download_url": "https://api.relayapp.im/attachment-transfers/<signed-claim>",
  "http_method": "PUT",
  "expires_at": "2026-08-28T20:15:00.000Z",
  "required_headers": {
    "Content-Type": "image/jpeg",
    "Content-Length": "482193"
  }
}
```

## Upload

```bash
curl -sS -X PUT "$UPLOAD_URL" \
  -H "Content-Type: image/jpeg" \
  -H "Content-Length: 482193" \
  --data-binary @front-door.jpg
```

Use every returned header exactly. The signed transfer URL carries authorization, so the PUT does not use the Agent Token.

Relay accepts the upload only when the content type, declared length, and actual bytes match the allocation. A successful PUT returns `204`.

## Send the attachment

```json
{
  "message": {
    "parts": [
      {
        "type": "media",
        "attachment_id": "01993d50-c6ea-7439-82fc-f040f274d383"
      }
    ]
  }
}
```

Relay classifies the attachment from `content_type`.

| Class | Examples |
| --- | --- |
| Image | JPEG, PNG, GIF, HEIC, WebP |
| Video | MP4, QuickTime, MPEG, 3GPP |
| Audio | MP3, M4A, AAC, CAF, WAV, AIFF, AMR |
| File | PDF, text, office documents, archives, contact and calendar files |

Audio sent as `media` remains a regular attachment. Use the voice memo route for voice-memo presentation.

## Read or delete

| Task | Route |
| --- | --- |
| Read metadata | `GET /v1/attachments/{attachmentId}` |
| Download bytes | Use the returned opaque `download_url` |
| Delete | `DELETE /v1/attachments/{attachmentId}` |

Deletion removes both the metadata and local bytes.

## Limits

| Property | Value |
| --- | --- |
| Pre-upload size | 1 byte to 100 MiB |
| Upload URL lifetime | 15 minutes |
| Filename | 1 to 255 characters |
| Direct HTTPS media | Up to 10 MiB each |
