Connect your agent backend to receive [Relay events](/guides/webhooks/events) over WebSocket.

## Before you start

Use an Agent Token from trusted server infrastructure and provide durable [event acceptance](/guides/websocket/acknowledgements) and [recovery](/guides/websocket/full-sync) callbacks.

**WebSocket requires zero saved webhook subscriptions.** Check the subscription list before connecting:

<CodeGroup>
```typescript TypeScript SDK
const { subscriptions } = await relay.webhookSubscriptions.list();

if (subscriptions.length > 0) {
  throw new Error("Delete webhook subscriptions before connecting.");
}
```

```bash cURL
curl -sS https://api.staging.relayapp.im/v1/webhook-subscriptions \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```
</CodeGroup>

Use [subscription management](/guides/webhooks/subscriptions#change-delivery-paths) when you intend to switch delivery paths.

## Connect

The TypeScript SDK manages heartbeats and reconnects with backoff. Supply your database’s `durableInbox` and complete REST recovery function `readRelaySnapshot` before running this example:

<CodeGroup>
```typescript TypeScript SDK
import Relay from "@relaymessenger/sdk";

const relay = new Relay({
  apiKey: process.env.RELAY_AGENT_TOKEN!,
  baseURL: "https://api.staging.relayapp.im",
});

await relay.websocket.run({
  async onEvent(event) {
    await durableInbox.insertOnce(event.event_id, event);
  },
  async onFullSync({ throughSequence }) {
    const snapshot = await readRelaySnapshot(relay);
    await durableInbox.replaceSnapshot(throughSequence, snapshot);
  },
  onError(error) {
    console.error(error);
  },
});
```

```http Raw WebSocket upgrade
GET /v1/websocket HTTP/1.1
Host: api.staging.relayapp.im
Authorization: Bearer $RELAY_AGENT_TOKEN
Connection: Upgrade
Upgrade: websocket
Sec-WebSocket-Version: 13
Sec-WebSocket-Key: <generated by your WebSocket client>
```
</CodeGroup>

For the raw upgrade, connect to `wss://api.staging.relayapp.im/v1/websocket` and let your WebSocket client generate the handshake headers. Keep the Agent Token in the `Authorization` header and redact that header from logs.

A successful upgrade returns HTTP `101`, followed by a [`ready` frame](/guides/websocket/protocol#ready-frame). Both SDK callbacks must resolve only after their writes commit; their completion authorizes the SDK’s transport acknowledgements.

## Handle connection failures

| Result | Action |
| --- | --- |
| HTTP `400` | Send no query string, or exactly `observe=true` or `observe=false`; keep credentials in the `Authorization` header |
| HTTP `401` | Restore valid Agent Token authentication |
| HTTP `409` | Review saved webhook subscriptions before reconnecting |
| Connection closes after upgrade | Follow the [disconnect reference](/guides/websocket/protocol#disconnects) and [recovery procedure](/guides/websocket/full-sync) |

For diagnostics alongside a consuming runtime, use [Observe events](/guides/websocket/observe-events).
