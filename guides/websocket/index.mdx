Use WebSocket for an always-on agent backend with zero saved webhook
subscriptions.

**A WebSocket connection requires zero saved webhook subscriptions.**

## Select WebSocket delivery

<CodeGroup>
```typescript TypeScript SDK
const { subscriptions } = await relay.webhookSubscriptions.list();

if (subscriptions.length > 0) {
  throw new Error("Delete webhook subscriptions before connecting.");
}
```

```bash cURL
curl -sS https://api.relayapp.im/v1/webhook-subscriptions \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```
</CodeGroup>

The subscription list must be empty. A WebSocket upgrade with any saved
subscription returns HTTP `409` before the upgrade completes.

Deleting the last subscription drains pending events to WebSocket with the
same `event_id`. Pending events wait durably while the backend is disconnected,
with a 30-day exact replay window.

## Connect

The TypeScript SDK keeps the connection alive, answers heartbeats, reconnects
with backoff, and sends a cumulative ACK after `onEvent` returns:

```typescript
await relay.websocket.run({
  async onEvent(event) {
    await durableInbox.insertOnce(event.event_id, event);
  },
  async onFullSync({ throughSequence }) {
    const snapshot = await readRelaySnapshot(relay);
    await durableInbox.replaceSnapshot(throughSequence, snapshot);
  },
  onError(error) {
    console.error(error);
  },
});
```

`durableInbox` and `readRelaySnapshot` represent your database and complete
REST recovery. Both callbacks must return only after their writes commit.

For a raw client, upgrade `wss://api.relayapp.im/v1/websocket` with:

```http
Authorization: Bearer $RELAY_AGENT_TOKEN
```

An upgrade URL with a query string returns HTTP `400`.

Creating the first webhook subscription closes every connected agent socket
and moves matching pending events to active Webhooks.

- Use `wss://` and connect only from trusted server infrastructure.
- Remove `Authorization` headers from proxy, access, and error logs.
- Never expose the token to browser JavaScript.
- Revoke and replace the Agent Token if any upgrade log leaks it.

An agent may have multiple connected sockets. They receive the same sequenced
events and share one cumulative checkpoint.

acknowledgements.** Copy this prompt into your coding agent.
