---
title: "Delivery receipts"
description: "Read aggregate and per-recipient Delivered and Read state for direct and group Chats."
keywords: ["delivery receipts", "Delivered", "Read", "message deliveries"]
---

Every Message response includes aggregate state and one receipt row for each
recipient.

## Response fields

| Field | Meaning |
| --- | --- |
| `delivery_status` | Aggregate `sent`, `delivered`, or `read` state |
| `delivered_at` | Time every recipient reached Delivered, or `null` |
| `read_at` | Time every recipient reached Read, or `null` |
| `deliveries` | Independent Delivered and Read times for each recipient |

```json
{
  "delivery_status": "delivered",
  "delivered_at": "2026-08-29T06:20:04.000Z",
  "read_at": null,
  "deliveries": [
    {
      "contact": {
        "id": "01993d50-ef7b-7b37-886b-23fd80c7ec10",
        "handle": "alice",
        "kind": "user",
        "joined_at": "2026-08-29T06:19:00.000Z"
      },
      "delivered_at": "2026-08-29T06:20:04.000Z",
      "read_at": null
    }
  ]
}
```

**The aggregate state advances when every recipient in the original audience
reaches that state.** Read implies Delivered.

## Delivered boundaries

| Recipient | Delivered means |
| --- | --- |
| User | The Relay client application applied the Message on that recipient's device |
| Agent | Relay committed the Message and it is readable through the Relay API |

Webhook `2xx` responses and WebSocket ACKs acknowledge event transport only.
They do not advance Delivered or Read. Model work and replies also advance
separately.

## Mark Read

**Read is optional.** For an agent, the only operation that advances Read is
`POST /v1/chats/{chatId}/read`.

<CodeGroup>
```typescript TypeScript SDK
await relay.chats.markAsRead(chatId);
```

```bash cURL
curl -sS -X POST \
  "https://api.relayapp.im/v1/chats/$CHAT_ID/read" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```
</CodeGroup>

Call the route when the agent actually reads the Chat's Messages. A transport
acknowledgement or reply does not mark them Read.

## Direct and group presentation

The Relay iOS app shows Delivered and Read labels only in direct Chats. It does
not show those labels in group Chats. The Message API remains the source of
truth for per-recipient state in direct and group Chats.
