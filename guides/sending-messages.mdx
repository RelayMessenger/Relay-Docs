Send one immutable message to an existing chat.

## Send text and media

```bash
curl -sS -X POST "$RELAY_API_URL/v1/chats/$CHAT_ID/messages" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: reply-$EVENT_ID" \
  -d '{
    "message": {
      "parts": [
        {"type":"text","value":"Here is the recording."},
        {"type":"media","attachment_id":"01993d50-c6ea-7439-82fc-f040f274d383"}
      ]
    }
  }'
```

`202` means Relay committed the message. It does not mean every recipient has acknowledged it.

## Part shapes

| Content | Request shape | Result |
| --- | --- | --- |
| Text | `{"type":"text","value":"Hello"}` | Text run |
| Mention | Text plus `mention` and `mention_range` | Mention attribute in the text run |
| Image | `media` with image bytes | Image attachment |
| Video | `media` with video bytes | Video attachment |
| Audio | `media` with audio bytes | Regular audio attachment |
| File | `media` with document bytes | File attachment |
| Link | `{"type":"link","value":"https://example.com"}` | URL balloon |

The `parts` array is an API projection from Apple `attributedBody`. Each array position becomes a zero-based `part_index`.

Use one `link` part by itself. Use a text part when the URL should remain plain text.

## Mention a Contact

```json
{
  "message": {
    "parts": [
      {
        "type": "text",
        "value": "Echo, can you check this?",
        "mention": "echo",
        "mention_range": [0, 4]
      }
    ]
  }
}
```

`mention` is the Contact's Handle. The range is `[start, end)` inside `value`.

## Reply to one part

```json
{
  "message": {
    "parts": [{"type":"text","value":"That image looks right."}],
    "reply_to": {
      "message_id": "01993d50-b4ce-71e6-8e65-35d325d95ddb",
      "part_index": 1
    }
  }
}
```

Omit `part_index` to use the first part. Relay rejects an index outside the target projection.

## Send a voice memo

Use the dedicated route to create voice-memo behavior instead of a regular audio attachment:

```bash
curl -sS -X POST "$RELAY_API_URL/v1/chats/$CHAT_ID/voicememo" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"attachment_id":"01993d50-c6ea-7439-82fc-f040f274d383"}'
```

You may send one HTTPS `voice_memo_url` instead. Relay stores the result as an attachment-backed message with the audio-message flag.

## Retry a send

| Retry | Result |
| --- | --- |
| Same sender and idempotency key | Returns the original message |
| Same key after an uncertain response | Prevents a duplicate message |
| New key | Creates another message |

Keep the same request body when reusing a key.
