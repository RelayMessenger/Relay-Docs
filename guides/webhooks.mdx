Create one subscription for the events your agent consumes.

## Create a subscription

```bash
curl -sS -X POST "$RELAY_API_URL/v3/webhook-subscriptions" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "target_url": "https://agent.example/webhooks/relay",
    "subscribed_events": [
      "message.received",
      "message.delivered",
      "message.read",
      "reaction.added",
      "reaction.removed"
    ]
  }'
```

The `201` response contains `signing_secret` once:

```json
{
  "id": "b2c3d4e5-f6a7-8901-bcde-f23456789012",
  "target_url": "https://agent.example/webhooks/relay",
  "signing_secret": "whsec_<base64-key>",
  "subscribed_events": ["message.received"],
  "phone_numbers": null,
  "is_active": true,
  "created_at": "2026-08-28T20:00:00.000Z",
  "updated_at": "2026-08-28T20:00:00.000Z"
}
```

## Verify the request

| Header | Use |
| --- | --- |
| `webhook-id` | Event deduplication key |
| `webhook-timestamp` | Unix seconds used in the signature |
| `webhook-signature` | Standard Webhooks `v1,<base64>` signature |
| `X-Webhook-Event` | Deprecated Linq-compatible event header |
| `X-Webhook-Subscription-ID` | Deprecated Linq-compatible subscription header |

Verify the exact raw body with Standard Webhooks. The signed bytes are:

```text
webhook-id.webhook-timestamp.raw-body
```

Strip `whsec_`, base64-decode the secret, then verify HMAC-SHA256 with constant-time comparison.

## Acknowledge safely

<Steps>
<Step title="Verify">
Reject an invalid signature or stale timestamp.
</Step>
<Step title="Deduplicate">
Claim `event_id` in durable storage.
</Step>
<Step title="Save">
Commit the event or enqueue the exact body.
</Step>
<Step title="Respond">
Return `200` or `204` within 10 seconds.
</Step>
<Step title="Process">
Mark Read, run the model, and send the reply after acknowledgement.
</Step>
</Steps>

A successful `message.received` response records Delivered for the agent recipient. Other event responses acknowledge webhook transport only.

## Manage subscriptions

| Task | Route |
| --- | --- |
| Discover event names | `GET /v3/webhook-events` |
| Create | `POST /v3/webhook-subscriptions` |
| List | `GET /v3/webhook-subscriptions` |
| Read | `GET /v3/webhook-subscriptions/{subscriptionId}` |
| Replace settings | `PUT /v3/webhook-subscriptions/{subscriptionId}` |
| Delete | `DELETE /v3/webhook-subscriptions/{subscriptionId}` |
