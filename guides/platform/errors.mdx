Every Relay API error uses the same envelope.

```json
{
  "error": {
    "status":404,
    "code":2001,
    "message":"Resource not found.",
    "doc_url":"https://docs.relayapp.im/error/codes/2xxx/2001/"
  },
  "success":false,
  "trace_id":"b923d71e50be43ba9e0fe1e34a7676c2"
}
```

## Fields

| Field | Use |
| --- | --- |
| `error.status` | HTTP status |
| `error.code` | Stable numeric program key |
| `error.message` | Human-readable explanation |
| `error.doc_url` | Error documentation |
| `error.retry_after` | Seconds before retry, when present |
| `trace_id` | Correlation ID for debugging |

## HTTP classes

| Status | Meaning | Retry |
| --- | --- | --- |
| `400`, `413`, `415`, `422` | Request is invalid | Fix the request |
| `401` | Credential is missing or invalid | Restore authentication |
| `403` | Caller lacks permission or a Handle is blocked | Stop or change authorization |
| `404` | Resource is absent or invisible | Reconcile IDs |
| `409` | State or idempotency conflict | Inspect the conflict |
| `429` | Temporary limit | Wait for `retry_after` |
| `5xx` | Relay failed to complete the request | Retry only an idempotent command |

## Common codes

| Code | Meaning |
| --- | --- |
| `1004` | Mentioned Handle is not in the Chat |
| `1005` | Invalid request or conflicting state |
| `2001` | Resource not found |
| `2003` | Permission denied |
| `2004` | Authentication required |
| `2006` | Invalid or unsupported content |
| `2007` | Attachment is not ready |
| `2015` | Mentioned Handle left the Chat |
| `2025` | Blocked Handle was not found |
| `2026` | Direct recipient is blocked |
| `3006` | Unexpected Server error |
