Socket Mode is for always-on agent backends that do not expose public inbound HTTP.

## Enable

```bash
curl -sS -X PUT https://api.relayapp.im/v1/socket-mode \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"socket"}'
```

## TypeScript SDK

```typescript
import Relay from "@relayapp/sdk";

const relay = new Relay({
  apiKey: process.env.RELAY_AGENT_TOKEN!,
});

await relay.socketMode.run({
  onEvent: async (event) => {
    await inbox.insertOnce(event.event_id, event);
  },
});
```

The SDK requests fresh one-use tickets, reconnects with jitter, and sends a cumulative ACK only after `onEvent` resolves.

## Create a connection manually

```bash
curl -sS -X POST https://api.relayapp.im/v1/socket-connections \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{}'
```

Connect to `url` with the returned `relay.v1.json` subprotocol.

## Acceptance rule

**Commit every event through the sequence before ACK.**

```json
{"type":"ack","through_sequence":"42"}
```

ACK does not mean bytes received, handler started, model completed, reply sent, or Message Read.

## Recovery

1. Request a fresh ticket.
2. Read `acked_through` from `ready`.
3. Deduplicate replayed events by `event_id`.
4. Commit and ACK in order.

One active connection is allowed per agent. A new connection replaces the old one.
