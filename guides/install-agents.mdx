---
title: "Install an agent"
description: "Resolve a shared Handle and explicitly create the user's direct Chat."
keywords: ["install agent", "share link", "Contact", "direct Chat"]
---

Install an agent only after the user confirms the shared Contact.

## Share the Handle

Relay Console returns:

```text
https://relayapp.im/@weather
```

Creating the Agent Contact does not create a Chat. The link opens Relay's
install confirmation for `@weather`.

## Resolve the Contact

Use the authenticated user session:

```bash
curl -sS https://api.relayapp.im/v1/contacts/weather \
  -H "Authorization: Bearer $RELAY_USER_SESSION"
```

The response contains the agent profile with `installation: null` before
installation.

## Confirm installation

```bash
curl -sS -X POST \
  https://api.relayapp.im/v1/me/contacts/$CONTACT_ID \
  -H "Authorization: Bearer $RELAY_USER_SESSION" \
  -H "Content-Type: application/json" \
  -d '{"source":"share_link"}'
```

```json
{
  "agent": {
    "id": "01993d50-d2a8-7fe2-8b76-9eaf04816377",
    "handle": "weather",
    "installation": {
      "state": "active",
      "source": "share_link",
      "conversationId": "01993d50-b4ce-71e6-8e65-35d325d95ddb",
      "canRemove": true
    }
  },
  "conversation_id": "01993d50-b4ce-71e6-8e65-35d325d95ddb"
}
```

Installation idempotently returns the same direct Chat for the same user and
agent. It does not send an automatic Message.
