---
title: "Typing indicators"
description: "Start, refresh, and stop a 90-second typing signal."
keywords: ["typing", "typing.started", "typing.stopped", "ephemeral"]
---

Start or refresh typing with a bodyless request.

```bash
curl -sS -X POST "$RELAY_API_URL/v1/chats/$CHAT_ID/typing" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

| Property | Behavior |
| --- | --- |
| Lifetime | 90 seconds |
| Refresh | Repeat `POST` |
| Receipt effect | None |
| Transcript effect | No entry |
| Event | Ephemeral `typing.started` |

Stop explicitly:

```bash
curl -sS -X DELETE "$RELAY_API_URL/v1/chats/$CHAT_ID/typing" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

`204` means inactive. `typing.stopped` emits only after a real state change. Typing events expire with the slot and are not a recovery feed.

| Status | Meaning |
| --- | --- |
| `403` | Agent is not active in chat |
| `404` | Chat unavailable |
| `429` | Follow `Retry-After` |
