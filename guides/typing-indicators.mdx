---
title: "Typing indicators"
description: "Start and stop an ephemeral typing signal."
keywords: ["typing", "typing indicator", "ephemeral"]
---

Start typing in a known chat.

```bash
curl -sS -X POST "$RELAY_API_URL/v3/chats/$CHAT_ID/typing" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

| Property | Behavior |
| --- | --- |
| Success | `204` |
| Lifetime | About 85 to 90 seconds |
| Persistence | Ephemeral |
| Delivery state | Unchanged |
| Transcript | No message row |

Refresh the signal with another `POST` while the model is working.

Stop typing after a reply, failure, or cancellation:

```bash
curl -sS -X DELETE "$RELAY_API_URL/v3/chats/$CHAT_ID/typing" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

The mobile WebSocket may carry typing frames. Durable messages still reconcile through HTTP.
