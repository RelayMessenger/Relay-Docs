Add a reaction to one message part.

```bash
curl -sS -X POST "$RELAY_API_URL/v3/messages/$MESSAGE_ID/reactions" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "operation": "add",
    "type": "like",
    "part_index": 1
  }'
```

The route returns `202` after the reaction is accepted.

| `type` | Meaning |
| --- | --- |
| `love` | Heart |
| `like` | Thumbs up |
| `dislike` | Thumbs down |
| `laugh` | Laugh |
| `emphasize` | Double exclamation |
| `question` | Question mark |
| `custom` | Emoji from `custom_emoji` |

Use `part_index` from the message's ordered `parts` projection. The default is `0`.

Relay stores an add or remove as an Apple associated message row. Reads fold those rows into the target part's `reactions` array.

## Remove a reaction

```bash
curl -sS -X POST "$RELAY_API_URL/v3/messages/$MESSAGE_ID/reactions" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "operation": "remove",
    "type": "like",
    "part_index": 1
  }'
```

For a custom emoji, send the same `custom_emoji` value with `operation: "remove"`.

| Failure | Meaning |
| --- | --- |
| `404` | Message is not visible to this agent |
| `422` | `part_index` does not exist |
| `400` | Reaction shape is invalid |
