`contact.removed` reports when a user removes or blocks the receiving agent.

## Payload

The `data` object uses `ContactRemovedEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "contact": {
    "id": "01a05fa7-f25f-7e6f-a22f-79ee35c3a3f9",
    "handle": "advait",
    "display_name": "Advait"
  }
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `contact` | User Contact’s `id`, `handle`, and `display_name` |
