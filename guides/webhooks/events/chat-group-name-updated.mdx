`chat.group_name_updated` reports when a group Chat name changes.

## Payload

The `data` object uses `ChatGroupNameUpdatedEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat_id": "01a05fa7-f254-76f4-8c3d-ca733572c7c0",
  "old_value": "Relay, Advait",
  "new_value": "Launch team",
  "changed_by_handle": {
    "id": "01a05fa7-f255-72ad-9f13-5b44601fec04",
    "handle": "advait",
    "joined_at": "2026-08-31T06:00:00.000Z",
    "kind": "user",
    "display_name": "Advait",
    "image_url": null,
    "about": null,
    "verified": false
  },
  "updated_at": "2026-08-31T06:09:00.000Z"
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat_id` | Group Chat ID |
| `old_value` | Previous name, or `null` |
| `new_value` | New name, or `null` |
| `changed_by_handle` | Chat Handle that made the change, or `null` |
| `updated_at` | When the name changed |
