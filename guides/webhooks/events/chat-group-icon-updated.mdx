`chat.group_icon_updated` reports when a group Chat icon changes.

## Payload

The `data` object uses `ChatGroupIconUpdatedEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat_id": "01a05fa7-f256-7786-a816-0096a5c653c5",
  "old_value": null,
  "new_value": "https://cdn.staging.relayapp.im/chats/01a05fa7-f257-7578-b54c-2c4c42e2ae9d.png",
  "changed_by_handle": {
    "id": "01a05fa7-f258-76a2-af7e-99d751b2038a",
    "handle": "advait",
    "joined_at": "2026-08-31T06:00:00.000Z",
    "kind": "user",
    "display_name": "Advait",
    "image_url": null,
    "about": null,
    "verified": false
  },
  "updated_at": "2026-08-31T06:10:00.000Z"
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat_id` | Group Chat ID |
| `old_value` | Previous icon URL, or `null` |
| `new_value` | New icon URL, or `null` when removed |
| `changed_by_handle` | Chat Handle that made the change, or `null` |
| `updated_at` | When the icon changed |
