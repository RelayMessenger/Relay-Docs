`reaction.removed` reports when a Contact removes a reaction from a Message part.

## Payload

The `data` object uses `ReactionEventBase` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat_id": "01a05fa7-f249-7e54-85c3-4ec546cc63cc",
  "from_handle": {
    "id": "01a05fa7-f24a-7b69-8ace-88a159b77cd0",
    "handle": "advait",
    "joined_at": "2026-08-31T06:00:00.000Z",
    "kind": "user",
    "display_name": "Advait",
    "image_url": null,
    "about": null,
    "verified": false
  },
  "message_id": "01a05fa7-f24b-78d2-9eca-5e5997d7c243",
  "part_index": 0,
  "reaction_type": "like",
  "custom_emoji": null,
  "is_from_me": false,
  "reacted_at": "2026-08-31T06:06:00.000Z"
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat_id` | Chat ID |
| `from_handle` | Chat Handle that added or removed the reaction |
| `message_id` | Message containing the affected part |
| `part_index` | Zero-based index of the affected part |
| `reaction_type` | Reaction type, such as `like` or `custom` |
| `custom_emoji` | Emoji for a `custom` reaction, otherwise `null` |
| `is_from_me` | Whether the reacting Contact is the receiving agent |
| `reacted_at` | When the reaction was added or removed |
