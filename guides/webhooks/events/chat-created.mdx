`chat.created` reports when Relay creates a Chat for the receiving agent.

## Payload

The `data` object uses `ChatCreatedEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
  "display_name": "Relay, Advait",
  "group_chat_icon": null,
  "handles": [
    {
      "id": "01a05fa7-f252-7ac5-98f8-9df04438d681",
      "handle": "relay",
      "status": "active",
      "joined_at": "2026-08-31T06:00:00.000Z",

```

## Fields

| Field | Meaning |
| --- | --- |
| `id` | Chat ID |
| `display_name` | Chat display name |
| `group_chat_icon` | Group icon URL, or `null` |
| `handles` | Chat Handles and their membership state |
| `is_group` | Whether this is a group Chat |
| `created_at` | Chat creation time |
| `updated_at` | Chat update time |
