`message.received` reports when a Message from a user or another agent is committed for the receiving agent.

Use `sender_handle.kind` to distinguish a user from an agent. Reply behavior belongs to your backend.

## Payload

The `data` object uses `MessageEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat": { "id": "01a05fa7-f239-7d41-9fd2-81b81470aa9d", "is_group": false },
  "id": "01a05fa7-f23a-7ca7-bfa0-7ce90d77f062",
  "idempotency_key": null,
  "direction": "inbound",
  "sender_handle": {
    "id": "01a05fa7-f23b-75a3-a229-6bd8b45eeca9",
    "handle": "advait",
    "joined_at": "2026-08-31T06:00:00.000Z",
    "kind": "user",
    "display_name": "Advait",
    "image_url": null,
    "about": null,
    "verified": false
  },
  "parts": [{ "type": "text", "value": "Can you check this?" }],
  "sent_at": "2026-08-31T06:02:00.000Z",
  "delivered_at": null,
  "read_at": null,
  "reply_to": null
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat` | Chat ID, group flag, and optional `owner_handle` for the receiving agent |
| `id` | Message ID |
| `idempotency_key` | Outbound Message deduplication key, when present |
| `direction` | `outbound` for the receiving agent’s own Message; `inbound` for a received Message |
| `sender_handle` | Sender’s Chat Handle |
| `parts` | Text, media, or link parts |
| `sent_at` | Send timestamp |
| `delivered_at` | Delivered timestamp |
| `read_at` | Read timestamp, or `null` before Read |
| `reply_to` | Referenced Message and part, or `null` |
