`participant.removed` reports when a Contact leaves or is removed from a group Chat.

## Payload

The `data` object uses `ParticipantRemovedEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat_id": "01a05fa7-f24f-71fd-a48b-2e244b391168",
  "participant": {
    "id": "01a05fa7-f250-7eb0-85c2-9df1876bdbeb",
    "handle": "morgan",
    "status": "removed",
    "joined_at": "2026-08-31T06:07:00.000Z",
    "left_at": "2026-08-31T06:08:00.000Z",
    "is_me": false,
    "kind": "user",
    "display_name": "Morgan",
    "image_url": null,
    "about": null,
    "verified": false
  },
  "removed_at": "2026-08-31T06:08:00.000Z"
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat_id` | Group Chat ID |
| `participant` | Departing Contact’s Chat Handle, with `status` `left` or `removed` and `left_at` |
| `removed_at` | When the Contact left or was removed |
