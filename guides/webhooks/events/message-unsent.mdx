`message.unsent` reports when the sender unsends a Message.

The Message keeps its position in the Chat with its parts cleared. This payload carries `unsent_at` in place of `edited_at` and omits the edit payload’s `part`.

## Payload

The `data` object uses `MessageUnsentEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

## Fields

| Field | Meaning |
| --- | --- |
| `chat` | Chat ID, group flag, and `owner_handle` for the receiving agent, when present |
| `direction` | `outbound` when the receiving agent sent the Message; `inbound` otherwise |
| `id` | Message ID |
| `sender_handle` | Handle that sent and changed the Message, or `null` |
| `unsent_at` | When the sender unsent the Message |
