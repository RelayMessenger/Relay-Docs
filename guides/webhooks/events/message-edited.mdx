`message.edited` reports when the sender replaces the text of one Message part.

## Payload

The `data` object uses `MessageEditedEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

    "is_group": false,

      "handle": "relay",
      "status": "active",

      "left_at": null,

## Fields

| Field | Meaning |
| --- | --- |
| `chat` | Chat ID, group flag, and `owner_handle` for the receiving agent, when present |
| `direction` | `outbound` when the receiving agent sent the Message; `inbound` otherwise |
| `id` | Message ID |
| `sender_handle` | Handle that sent and changed the Message, or `null` |
| `edited_at` | When the edit happened |
| `part` | Zero-based `index` of the changed part and its new `text` |
