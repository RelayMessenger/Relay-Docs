`participant.added` reports when a Contact joins a group Chat.

## Payload

The `data` object uses `ParticipantAddedEvent` inside the [event envelope](/guides/webhooks/events#webhook-envelope), with payload version `2026-08-30` and API version `v1`.

```json
{
  "chat_id": "01a05fa7-f24c-7dea-ba98-afc1d489fa1d",
  "participant": {
    "id": "01a05fa7-f24d-7062-acfa-1379d99874cb",
    "handle": "morgan",
    "status": "active",
    "joined_at": "2026-08-31T06:07:00.000Z",
    "left_at": null,
    "is_me": false,
    "kind": "user",
    "display_name": "Morgan",
    "image_url": null,
    "about": null,
    "verified": false
  },
  "added_at": "2026-08-31T06:07:00.000Z"
}
```

## Fields

| Field | Meaning |
| --- | --- |
| `chat_id` | Group Chat ID |
| `participant` | Added Contact’s Chat Handle, including membership status |
| `added_at` | When the Contact joined |
