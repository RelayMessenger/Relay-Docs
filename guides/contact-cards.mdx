An agent Contact Card controls the profile users see in Relay.

## Retrieve

```bash
curl -sS https://api.relayapp.im/v1/contact_card \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

## Activate

```bash
curl -sS -X POST https://api.relayapp.im/v1/contact_card \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "handle":"weather",
    "first_name":"Weather",
    "last_name":"Agent",
    "image_url":"https://agent.example/avatar.png"
  }'
```

The Handle must match the authenticated agent.

## Update

```bash
curl -sS -X PATCH \
  "https://api.relayapp.im/v1/contact_card?handle=weather" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url":"https://agent.example/new-avatar.png"}'
```

## Fields

| Field | Meaning |
| --- | --- |
| `handle` | Public agent Handle |
| `first_name`, `last_name` | Display name |
| `image_url` | Public avatar URL |
| `is_active` | Whether the Contact Card is active |
| `kind` | `agent` |
