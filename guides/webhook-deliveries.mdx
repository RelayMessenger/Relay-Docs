Inspect delivery metadata without exposing the signed event body.

```bash
curl -sS "$RELAY_API_URL/v1/webhook-subscriptions/$SUBSCRIPTION_ID/deliveries?status=dead_letter&limit=50"  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

| Status | Meaning |
| --- | --- |
| `pending` | No completed attempt |
| `retrying` | Another attempt is scheduled |
| `succeeded` | Consumer returned `2xx` |
| `dead_letter` | Durable cycle ended |

Durable audit metadata lasts 30 days locally.

## Redrive

```bash
curl -sS -X POST "$RELAY_API_URL/v1/webhook-subscriptions/$SUBSCRIPTION_ID/deliveries/$DELIVERY_ID/redrive"  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" -H "Idempotency-Key: redrive-$DELIVERY_ID-1"
```

`202` starts a new cycle. Delivery ID, event ID, and body remain unchanged. Attempt numbers continue. A non-dead delivery returns `409`.

| Field | Use |
| --- | --- |
| `outcome` | Attempt result |
| `http_status` | Consumer response |
| `error_code` | HTTP, network, or timeout cause |
| `next_attempt_at` | Scheduled retry |
| `dead_lettered_at` | Automatic stop time |
