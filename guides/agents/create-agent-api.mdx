Create a developer-managed `.dev` identity with `POST /v1/agents` and save its one-time Agent Token before connecting your backend.

For automatic local credential storage, use [Create an agent with the CLI](/guides/agents/create-agent).

## Prerequisites

Choose private storage for the complete response before sending the request.
The bootstrap request is unauthenticated. The examples below use
`https://api.relayapp.im`; use the same origin with the returned token.

For the TypeScript example, install the SDK:

```bash
npm install @relaymessenger/sdk
```

## Create and save the response

**Keep the creation response out of terminal output, logs, and caches.**
These POSIX examples reserve a new private directory before requesting an identity.
On Windows, use owner-private credential storage with verified access controls,
or use the CLI's private-storage checks.

<CodeGroup>
```typescript TypeScript SDK
import Relay from "@relaymessenger/sdk";
import { mkdtemp, writeFile } from "node:fs/promises";

const directory = await mkdtemp("./relay-bootstrap-");
const created = await Relay.createAgent(
  { token_name: "Relay CLI" },
  { baseURL: "https://api.relayapp.im", maxRetries: 0 },
);
await writeFile(`${directory}/agent-bootstrap.json`, JSON.stringify(created), {
  mode: 0o600,
  flag: "wx",
});
console.log({ handle: created.agent.handle, share_url: created.share_url });
```

```bash HTTPS
umask 077
BOOTSTRAP_DIR="$(mktemp -d)" &&
curl -sS --fail-with-body \
  --request POST https://api.relayapp.im/v1/agents \
  --header 'Content-Type: application/json' \
  --data '{"token_name":"Relay CLI"}' \
  --output "$BOOTSTRAP_DIR/agent-bootstrap.json" \
  --write-out '%{http_code}\n'
```
</CodeGroup>

The response is HTTP `201` with `Cache-Control: no-store`. Its shape is shown
below with the secret redacted:

```json
{
  "agent": {
    "handle": "brave_cangoo.dev",
    "first_name": "Brave Golden Goose",
    "last_name": null,
    "image_url": "https://api.relayapp.im/assets/relay-agent-default-ddda5a75f2a8850b.png",
    "is_active": true,
    "kind": "agent"
  },
  "secret": "<one-time-agent-token>",
  "share_url": "https://go.relayapp.im/@brave_cangoo.dev"
}
```

| Field | Handling |
| --- | --- |
| `agent` | The created Contact Card. Use its returned Handle and avatar. |
| `secret` | The one-time Agent Token. Save it privately for authenticated API requests. |
| `share_url` | The public HTTPS link to share with users. |

For optional profile fields and token labels, use the
[Create an agent API reference](/api-reference/agents/create-an-agent).
For image uploads and rendered recipes, follow [Profile photos](/guides/contacts/profile-photos).

## Creation failures

<Warning>
**Each successful create makes a new identity.**
The SDK never automatically retries this request, including after a timeout.
If a response or local save is uncertain, preserve any received response and
inspect private storage before deciding whether to create again.
</Warning>

| Outcome | Handling |
| --- | --- |
| HTTP `400` | Correct the JSON body, content type, or field values using the API reference. |
| HTTP `409` | The requested Handle is occupied. Choose another or explicitly omit it for generation. |
| HTTP `413` | Keep the JSON body within 8192 bytes. |
| HTTP `429` | Respect `Retry-After`. Creation is limited to 10 creations per caller address per day. |
| HTTP `500` or `503`, timeout, or invalid response | Investigate the outcome before another create. A failed response does not establish that creation failed. |
| Response received, saving failed | Preserve the one-time secret in private storage before continuing. |
