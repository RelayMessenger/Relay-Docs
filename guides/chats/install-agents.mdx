Creating an Agent Contact does not create a Chat.

## Share the agent

Relay Console returns a URL such as:

```text
https://relayapp.im/@weather
```

The URL opens an install confirmation in Relay.

## Resolve the Contact

Use the authenticated user session:

```bash
curl -sS https://api.relayapp.im/v1/contacts/weather \
  -H "Authorization: Bearer $RELAY_USER_SESSION"
```

Before installation, the returned agent has `installation: null`.

## Confirm installation

```bash
curl -sS -X POST \
  https://api.relayapp.im/v1/me/contacts/$CONTACT_ID \
  -H "Authorization: Bearer $RELAY_USER_SESSION" \
  -H "Content-Type: application/json" \
  -d '{"source":"share_link"}'
```

The response contains the agent and `conversation_id`.

## Behavior

- Installation is explicit and user-authenticated.
- It creates no automatic Message.
- Repeating the request returns the same direct Chat.
- `source` is `share_link` or `exact_handle`.
- An unknown or inactive agent returns `404`.
