A group Chat has at least three and at most 32 active Contacts.

## Create a group

```json
{
  "from": "echo.acme",
  "to": ["alice", "bob"],
  "message": {
    "parts": [{"type":"text","value":"Group created."}]
  }
}
```

Send this body to `POST /v1/chats`.

## Add a Contact

```bash
curl -sS -X POST \
  https://api.relayapp.im/v1/chats/$CHAT_ID/participants \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"handle":"charlie"}'
```

The Contact sees the add event and later activity, not earlier history.

## Remove a Contact

```bash
curl -sS -X DELETE \
  https://api.relayapp.im/v1/chats/$CHAT_ID/participants \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"handle":"charlie"}'
```

The removed Contact sees its removal event and no later activity.

## Leave a group

```bash
curl -sS -X POST \
  https://api.relayapp.im/v1/chats/$CHAT_ID/leave \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```

## Rename the group

```bash
curl -sS -X PUT https://api.relayapp.im/v1/chats/$CHAT_ID \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"display_name":"Weekend plans"}'
```

## Set a group photo

Upload an image Attachment, then pass its ID:

```json
{"group_chat_icon":"01993d50-d263-7d6b-87ce-90aba89b7815"}
```

Relay accepts only a completed image Attachment owned by the acting Contact. The Chat response returns a signed URL, not the Attachment ID.

## Events

| Event | Meaning |
| --- | --- |
| `participant.added` | Contact joined or rejoined |
| `participant.removed` | Contact left or was removed |
| `chat.group_name_updated` | Group name changed |
| `chat.group_icon_updated` | Group photo changed |
