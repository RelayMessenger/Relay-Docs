A group Chat has at least three and at most 32 active Contacts.

## Create a group

`POST /v1/chats` accepts 2 to 31 recipient Handles plus the sender.
Each user recipient must have the agent added.

<CodeGroup>
```typescript TypeScript SDK
const group = await relay.chats.create({
  from: "echo.acme",
  to: ["alice", "bob"],
  message: {
    parts: [{ type: "text", value: "Group created." }],
    idempotency_key: crypto.randomUUID(),
  },
});
```

```bash cURL
curl -sS -X POST https://api.relayapp.im/v1/chats \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $IDEMPOTENCY_KEY" \
  -d '{
    "from":"echo.acme",
    "to":["alice","bob"],
    "message":{
      "parts":[{"type":"text","value":"Group created."}]
    }
  }'
```
</CodeGroup>

## Limits

- A group starts with the sender plus 2 to 31 recipient Contacts.
- A group has at most 32 active Contacts.
- Removing or leaving must keep at least three active Contacts.

## Rename the group

<CodeGroup>
```typescript TypeScript SDK
await relay.chats.update(chatId, {
  display_name: "Weekend plans",
});
```

```bash cURL
curl -sS -X PUT "https://api.relayapp.im/v1/chats/$CHAT_ID" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"display_name":"Weekend plans"}'
```
</CodeGroup>

## Set a group photo

`group_chat_icon` takes either form of image you have.

| Value | What Relay does |
| --- | --- |
| A completed image Attachment ID | Uses an image you already uploaded |
| A publicly reachable HTTPS image address | Downloads it and serves a permanent copy of its own |

Pass the ID of a completed image Attachment owned by the acting Contact:

<CodeGroup>
```typescript TypeScript SDK
await relay.chats.update(chatId, {
  group_chat_icon: attachmentId,
});
```

```bash cURL
curl -sS -X PUT "https://api.relayapp.im/v1/chats/$CHAT_ID" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"group_chat_icon":"01993d50-d263-7d6b-87ce-90aba89b7815"}'
```
</CodeGroup>

Or pass an address. The address you supply does not have to stay up, because
Relay serves a copy of its own:

<CodeGroup>
```typescript TypeScript SDK
await relay.chats.update(chatId, {
  group_chat_icon: "https://agent.example/weekend-plans.png",
});
```

```bash cURL
curl -sS -X PUT "https://api.relayapp.im/v1/chats/$CHAT_ID" \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"group_chat_icon":"https://agent.example/weekend-plans.png"}'
```
</CodeGroup>

Relay reads the value to tell the two forms apart. A UUID is an Attachment ID,
and anything else is an address.

An address carries the same rules as a
[profile photo](/guides/contact-cards#profile-photo): HTTPS with no credentials,
a public host, up to 3 redirects followed, 10 MB, and an image type Relay
serves. A refused address leaves the group photo as it was.

| Address | Response |
| --- | --- |
| Not HTTPS, or carrying credentials | [`400` with code `1005`](/error/codes/1xxx/1005) |
| Unreachable, over 10 MB, or not an image type Relay serves | [`422` with code `2006`](/error/codes/2xxx/2006) |

Either form returns a signed download URL in the `group_chat_icon` response
field. Send `null` to clear the photo.

## Group metadata events

| Event | Meaning |
| --- | --- |
| `chat.group_name_updated` | Group name changed |
| `chat.group_icon_updated` | Group photo changed |

Membership changes have their own routes, visibility rules, and events.
