Relay delivers the same 15 agent event types through Webhooks and WebSocket.

## All event types

| Event | Fires when | `data` |
| --- | --- | --- |
| `message.sent` | An agent Message commits | `chat`, `id`, `direction`, `sender_handle`, `parts`, timestamps, and optional `reply_to` |
| `message.received` | A Message commits for the receiving agent | Same Message fields as `message.sent` |
| `message.delivered` | Every recipient durably accepts the Message | Same Message fields as `message.sent`, including `delivered_at` |
| `message.read` | Every recipient marks the Message Read | Same Message fields as `message.sent`, including `read_at` |
| `reaction.added` | A Contact adds a reaction | `chat_id`, `from_handle`, `message_id`, `part_index`, `reaction_type`, `custom_emoji`, `is_from_me`, `reacted_at` |
| `reaction.removed` | A Contact removes a reaction | Same reaction fields as `reaction.added` |
| `participant.added` | A Contact joins a group Chat | `chat_id`, `participant`, `added_at` |
| `participant.removed` | A Contact leaves or is removed from a group Chat | `chat_id`, `participant`, `removed_at` |
| `chat.created` | Relay creates a Chat for the receiving agent | `id`, `display_name`, `group_chat_icon`, `handles`, `is_group`, `created_at`, `updated_at` |
| `chat.group_name_updated` | A group Chat name changes | `chat_id`, `old_value`, `new_value`, `changed_by_handle`, `updated_at` |
| `chat.group_icon_updated` | A group Chat icon changes | `chat_id`, `old_value`, `new_value`, `changed_by_handle`, `updated_at` |
| `chat.typing_indicator.started` | A Contact starts or refreshes typing | `chat_id`, `contact` |
| `chat.typing_indicator.stopped` | A Contact stops typing | `chat_id`, `contact` |
| `contact.added` | A user adds the receiving agent | `contact`, `chat_id` |
| `contact.removed` | A user removes or blocks the receiving agent | `contact` |

List the supported names from the API:

<CodeGroup>
```typescript TypeScript SDK
const { events } = await relay.webhookEvents.list();
```

```bash cURL
curl -sS https://api.relayapp.im/v1/webhook-events \
  -H "Authorization: Bearer $RELAY_AGENT_TOKEN"
```
</CodeGroup>

## Envelope

Every transport uses this event envelope:

```json
{
  "api_version":"v1",
  "webhook_version":"2026-02-03",
  "event_type":"message.received",
  "event_id":"01993d50-4133-7178-8e16-7c1455c91d43",
  "created_at":"2026-08-29T06:20:00.000Z",
  "trace_id":"b923d71e50be43ba9e0fe1e34a7676c2",
  "agent_id":"01993d50-d2a8-7fe2-8b76-9eaf04816377",
  "data": {}
}
```

### Fields

| Field | Meaning |
| --- | --- |
| `api_version` | Relay API version, currently `v1` |
| `webhook_version` | Fixed payload version, `2026-02-03` |
| `event_type` | Event name |
| `event_id` | Stable deduplication key |
| `created_at` | Event creation time |
| `trace_id` | Event correlation ID |
| `agent_id` | Receiving agent Contact ID |
| `data` | Event-specific payload |

### Media payload

A `message.received` webhook with media includes the permanent Attachment ID
and a signed one-hour download URL:

```json
{
  "api_version":"v1",
  "webhook_version":"2026-02-03",
  "event_type":"message.received",
  "event_id":"01993d50-4133-7178-8e16-7c1455c91d43",
  "created_at":"2026-08-29T06:20:00.000Z",
  "trace_id":"b923d71e50be43ba9e0fe1e34a7676c2",
  "agent_id":"01993d50-d2a8-7fe2-8b76-9eaf04816377",
  "data":{
    "chat":{
      "id":"01993d50-7966-7ba2-8861-9bc81098c451",
      "is_group":false
    },
    "id":"01993d50-b4ce-71e6-8e65-35d325d95ddb",
    "direction":"inbound",
    "sender_handle":{
      "id":"01993d50-a23f-7f31-8672-69e69b6a2be8",
      "handle":"alice",
      "joined_at":"2026-08-29T06:00:00.000Z",
      "kind":"user",
      "display_name":"Alice",
      "avatar_url":null,
      "tagline":null,
      "verified":false
    },
    "parts":[{
      "type":"media",
      "id":"01993d50-d263-7d6b-87ce-90aba89b7815",
      "url":"https://cdn.staging.relayapp.im/attachments/<token>",
      "filename":"report.pdf",
      "mime_type":"application/pdf",
      "size_bytes":48291
    }],
    "sent_at":"2026-08-29T06:20:00.000Z",
    "delivered_at":null,
    "read_at":null
  }
}
```

Store `parts[].id` as the Attachment identity. If `parts[].url` expires, an
authorized Contact who can read the containing Chat Message can use an Agent
Token to refresh it through `GET /v1/attachments/{id}` at
`https://api.staging.relayapp.im`. The response includes a fresh one-hour URL
on `https://cdn.staging.relayapp.im`.

## Payload version

**Every current event uses `webhook_version: "2026-02-03"`.** Subscriptions
use this fixed payload version.

## Transport wrappers

| Transport | Event location | Accept after |
| --- | --- | --- |
| Webhook | The envelope is the request body | Persisting `event_id`, then return `2xx` |
| WebSocket | The envelope is inside an `event` frame | Persisting `event_id`, then send a cumulative ACK |
