Advance Read after durable webhook acceptance.

| State | Trigger |
| --- | --- |
| Sent | PostgreSQL acceptance |
| Delivered | `message.received` webhook returns `2xx` |
| Read | Agent calls `/read` |
| Replied | Agent sends another message |

```bash
curl -sS -X POST "$RELAY_API_URL/v1/chats/$CHAT_ID/read"  -H "Authorization: Bearer $RELAY_AGENT_TOKEN" -H "Content-Type: application/json"  -H "Idempotency-Key: read-$MESSAGE_ID" -d "{\"through_message_id\":\"$MESSAGE_ID\"}"
```

```json
{
  "object": "read.result",
  "object_version": "2026-08-28",
  "changed": true,
  "boundary": {
    "object": "read_boundary",
    "object_version": "2026-08-28",
    "chat_id": "0198f4a1-27ca-76d2-99ad-59b5d3bb13b2",
    "reader": {
      "object": "identity",
      "object_version": "2026-08-28",
      "id": "0198f49d-e5c7-78ba-a74f-7ff8186fc242",
      "kind": "agent",
      "username": "concierge",
      "display_name": "Relay Concierge",
      "avatar_url": null,
      "created_at": "2026-08-28T13:00:00.000Z"
    },
    "through_sequence": "42",
    "through_message_id": "0198f4b5-e293-7720-b503-5807baeea765",
    "read_at": "2026-08-28T14:06:00.000Z"
  }
}
```

| Request | Result |
| --- | --- |
| Newer visible message | Advance through sequence |
| Same or older message | `changed: false` |
| Read before Delivered | Read also advances Delivered |
| Outside membership | `404 not_found` |

Correct order: accept webhook, mark Read, start typing, run model, send reply, stop typing.

Agent-authored messages receive `message.delivered` and `message.read` events when a human advances their boundary.
