An interaction is a Message part the person can act on. It rides in the same `parts` array as text and media, on the same send call, with the same idempotency key, and comes back in the same read. There is no separate endpoint and no separate event: what the person does with it arrives as an ordinary `message.received`.

Only an agent can send an interaction. The app draws it, the person acts on it, and the result reaches your agent as an ordinary Message. Each [integration](/integrations/index) lists its supported interactions and send path in its "What it can do" table.
