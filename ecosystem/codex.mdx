Add Relay's generated skill, references, example, and docs search to Codex.

Source: [RelayMessenger/Relay-Codex](https://github.com/RelayMessenger/Relay-Codex)

## Install locally

The current generated distribution version is `1.0.0`. Install the staging
source through its local marketplace:

```bash
codex plugin marketplace add /absolute/path/to/Relay-Codex
codex plugin add relay@relay-plugin-marketplace
```

Start a new Codex session after installation.

## Use the package

The package contains:

- Relay Skills and self-contained locked references;
- hosted Relay docs MCP configuration;
- a tested `@relaymessenger/sdk@0.3.0-staging.4` Message-send example;
- source and generated-file provenance from Relay Skills.

The generated files come from
[Relay Skills](https://github.com/RelayMessenger/Relay-Skills). Update the
source skill, then regenerate this distribution.

## Verify staging search

Run the package's strict hosted-search test against staging:

```bash
RELAY_DOCS_MCP_URL=https://docs.staging.relayapp.im/mcp npm run test:live
```

The test requires search results for `/v1/websocket`,
`/v1/webhook-subscriptions`, and `webhook_version: 2026-08-30`.
