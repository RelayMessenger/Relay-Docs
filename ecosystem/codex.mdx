## Install locally

The current generated distribution version is `1.0.0`. Use Codex CLI
`0.152.0` for this staging candidate, then install the staging source through
its local marketplace:

```bash
npm install --global @openai/codex@0.152.0
git clone --branch staging \
  https://github.com/RelayMessenger/Relay-Codex.git
codex plugin marketplace add /absolute/path/to/Relay-Codex
codex plugin add relay@relay-plugin-marketplace
```

Start a new Codex session after installation.

## Use the package

The package contains:

- the Relay Skill and self-contained locked references;
- hosted Relay docs MCP configuration;
- a tested `@relaymessenger/sdk@0.3.0-staging.4` Message-send example;
- source and generated-file provenance from the Relay Skill.

The generated files come from the canonical Relay Skill and
[distribution tooling](https://github.com/RelayMessenger/Relay-SDK/tree/staging/tooling/skills-distributions).
Update the source Skill, then regenerate this mirror.

## Prepare hosted proof

Run the package's strict hosted-search test only after this docs candidate is
pushed and the hosted staging index refreshes:

```bash
RELAY_DOCS_MCP_URL=https://docs.staging.relayapp.im/mcp npm run test:live
```

The test requires search results for `/v1/websocket`,
`/v1/webhook-subscriptions`, and `webhook_version: 2026-08-30`.
Local Docs validation does not claim that hosted result.
