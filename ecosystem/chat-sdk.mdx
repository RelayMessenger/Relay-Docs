Add Relay to Vercel Chat SDK with the official Relay adapter.

**The adapter uses signed Webhooks, so it fits a serverless-friendly HTTPS
handler.**

Source:
[Relay-SDK `packages/chat-sdk-adapter`](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/chat-sdk-adapter)

## Use the adapter

Relay Chats map to stable Chat SDK thread IDs in the form
`relay:<Chat UUID>`. Mount `chat.webhooks.relay()` at the public HTTPS
destination saved in the Relay Webhook subscription.

```typescript
const relay = createRelayAdapter({
  token: process.env.RELAY_AGENT_TOKEN,
  webhookSecret: process.env.RELAY_WEBHOOK_SECRET,
});
```

The adapter verifies the exact raw Webhook body. A
`message.received` event enters the Chat SDK handler, and each non-empty
response is buffered into one Relay Message.

## Media boundary

**Post a stable public HTTPS media URL through the adapter.**

For local bytes or files:

1. Allocate and upload the bytes with
   `@relaymessenger/sdk@0.3.0-staging.8`.
2. Retain the prepared Attachment identity for recovery.
3. Pass its stable public HTTPS URL to the adapter.

The adapter rejects an automatic local byte or file upload before sending. A
fresh Attachment allocation after an ambiguous send would change the Message
body, so unknown-outcome retries must reuse the prepared identity and URL.

## Delivery behavior

| Send source | Idempotency behavior |
| --- | --- |
| Inbound Webhook turn | `relay-chat-sdk:<event_id>:<send ordinal>` |
| Think Action or another recovered task | Supply `idempotencyKeyResolver` with the stable Action or delivery identity |
| Empty response | Local no-op, with no Relay Message |

Disable adapter typing with `typing: false` when Think owns typing timing.
