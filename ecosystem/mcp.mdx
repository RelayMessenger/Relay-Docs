Give a trusted local MCP client explicit Relay messaging tools.

Source:
[Relay-SDK `packages/mcp`](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/mcp)

## Staging package

The current package is `@relaymessenger/mcp@0.1.0-staging.4` and requires
Node.js `22.22.3` or newer. Both the `latest` and `staging` npm tags select
this version. Install the published staging tag:

```bash
npm install --global @relaymessenger/mcp@staging
relay-mcp --version
```

## Configure a local client

The server uses local process-spawned stdio. Resolve the Agent Token from the
environment or the profile shared with Relay CLI:

```json
{
  "mcpServers": {
    "relay": {
      "command": "relay-mcp",
      "env": {
        "RELAY_PROFILE": "staging"
      }
    }
  }
}
```

The server exposes named tools for reading and sending Messages, reactions,
typing and Read state, Contact Cards, and Add requests. Message-send tools
require a caller-supplied idempotency key.

## Choose the MCP surface

| MCP surface | Transport | Credential | Purpose |
| --- | --- | --- | --- |
| Local Relay MCP | Process-spawned stdio | Relay Agent Token | Call Relay API operations |
| Relay docs MCP | Hosted HTTP | None | Search current Relay documentation |

The local server opens no listening port. The MCP host is its security
boundary, so configure it only in a trusted local client.
