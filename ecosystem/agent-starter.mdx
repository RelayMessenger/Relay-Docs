Fork a minimal Cloudflare Think messenger for a Relay agent.

**The starter receives signed Webhooks in a Worker. Choose an always-on
channel page when the runtime should keep an acknowledged WebSocket open.**

Source: [RelayMessenger/Relay-Agent-Starter](https://github.com/RelayMessenger/Relay-Agent-Starter)

## Current source

The private starter package is `relay-agent-starter@0.1.0` and pins:

| Dependency | Version |
| --- | --- |
| `@cloudflare/think` | `0.17.0` |
| `@relaymessenger/chat-sdk-adapter` | `0.3.0-staging.0` |
| `@relaymessenger/sdk` | `0.3.0-staging.4` |
| `chat` | `4.39.0` |
| `agents` | `0.22.0` |

The Chat SDK adapter prerelease is currently source-only. Build its tarball
first, then install it into the starter checkout without saving a registry
reference:

```bash
cd /absolute/path/to/Relay-Chat-SDK
npm ci
npm pack --pack-destination /tmp/relay-chat-sdk-pack

cd /absolute/path/to/Relay-Agent-Starter
npm install --no-save \
  /tmp/relay-chat-sdk-pack/relaymessenger-chat-sdk-adapter-0.3.0-staging.0.tgz
```

## Configure staging

Set the staging Agent Token and one-time Webhook signing secret in
`.dev.vars`. Keep these non-secret values in `wrangler.jsonc`:

```text
RELAY_API_ORIGIN=https://api.staging.relayapp.im
RELAY_AGENT_HANDLE=your_agent_handle
MODEL_ID=@cf/openai/gpt-oss-120b
```

Run `npm run dev`, expose the Worker's exact `/webhooks/relay` path through
HTTPS, and save that URL through
`POST /v1/webhook-subscriptions`.

## Delivery behavior

Relay's Chat SDK adapter verifies the raw signed body. Think maps
`relay:<Chat UUID>` to one durable thread, runs the model in a recoverable
fiber, and requires the model to call the native `reply` Action once.

The Action commits one complete Relay Message with a stable idempotency key
derived from the inbound Relay Message ID. Think owns durable turn recovery
and its Action ledger.
