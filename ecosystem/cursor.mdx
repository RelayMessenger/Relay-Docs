Add Relay's generated skill, references, example, and docs search to Cursor.

Source: [RelayMessenger/Relay-Cursor](https://github.com/RelayMessenger/Relay-Cursor)

## Install locally

The current generated distribution version is `1.0.0`. Copy or link the
staging source checkout to:

```text
~/.cursor/plugins/local/relay
```

Reload Cursor, open **Customize**, and confirm that the Relay skill and docs
MCP server are present.

## Use the package

The package contains:

- Relay Skills and self-contained locked references;
- hosted Relay docs MCP configuration;
- a tested `@relaymessenger/sdk@0.3.0-staging.4` Message-send example;
- source and generated-file provenance from Relay Skills.

The generated files come from
[Relay Skills](https://github.com/RelayMessenger/Relay-Skills). Update the
source skill, then regenerate this distribution.

## Prepare hosted proof

Run the package's strict hosted-search test only after this docs candidate is
pushed and the hosted staging index refreshes:

```bash
RELAY_DOCS_MCP_URL=https://docs.staging.relayapp.im/mcp npm run test:live
```

The test requires search results for `/v1/websocket`,
`/v1/webhook-subscriptions`, and `webhook_version: 2026-08-30`.
Local Docs validation does not claim that hosted result.
