Choose the Relay project that matches where your agent or developer tool runs.

**Webhooks fit serverless-friendly request handlers. Acknowledged WebSocket
delivery fits an always-on process.**

## Choose by runtime

| Project | Current source | Runs as | Delivery path |
| --- | --- | --- | --- |
| [Chat SDK adapter](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/chat-sdk-adapter) | `@relaymessenger/chat-sdk-adapter@0.3.0-staging.0` | Vercel Chat SDK adapter | Signed Webhooks |
| [Cloudflare Think starter](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook/cloudflare-think-agent) | Cookbook recipe `0.1.0` | Cloudflare Think messenger | Signed Webhooks |
| [OpenClaw channel](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/openclaw) | `@relaymessenger/openclaw-plugin@0.4.0-staging.0` | OpenClaw gateway channel | Acknowledged WebSocket |
| [Claude Code channel](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/claude-code) | `relay-claude-channel@0.3.0-staging.0` | Claude Code channel process | Acknowledged WebSocket |
| [Relay Hermes](https://github.com/RelayMessenger/Relay-Hermes) | `relay-hermes@1.0.0rc1` | Hermes gateway plugin | Acknowledged WebSocket |

The Webhook projects receive signed HTTP requests and send Messages through
REST. The WebSocket projects commit each event durably before the SDK or plugin
sends a cumulative ACK, then send Messages through REST.

## Choose local tools

| Project | Current source | Use |
| --- | --- | --- |
| [Relay CLI](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/cli) | `@relaymessenger/cli@0.5.0-staging.0` | Terminal commands, profiles, diagnostics, and local event forwarding |
| [Relay MCP](https://github.com/RelayMessenger/Relay-SDK/tree/staging/packages/mcp) | `@relaymessenger/mcp@0.1.0-staging.1` | Local stdio tools for Relay Chats, Messages, reactions, Read state, Contact Cards, and Add requests |
| [Relay Skill](https://github.com/RelayMessenger/Relay-SDK/tree/staging/skills/relay) | `1.0.0` | Portable Relay guidance and hosted docs MCP configuration |
| [Relay Codex](https://github.com/RelayMessenger/Relay-Codex) | Generated mirror `1.0.0` | Codex plugin generated from the Relay Skill |
| [Relay Cursor](https://github.com/RelayMessenger/Relay-Cursor) | Generated mirror `1.0.0` | Cursor plugin generated from the Relay Skill |
| [Relay Cookbook](https://github.com/RelayMessenger/Relay-SDK/tree/staging/cookbook) | Six canonical recipes | Webhooks, WebSocket, Think, text, image, and voice memo examples |

The local Relay MCP uses an Agent Token to call Relay API operations. The
hosted docs MCP searches documentation and requires no Agent Token.

Relay-SDK is the canonical source for the TypeScript packages, channels, Skill,
generated-distribution tooling, and Cookbook. Relay-Claude-Code is the Claude
plugin install mirror. Relay-Codex and Relay-Cursor are generated install
mirrors. Relay-Hermes remains a separate Python plugin repository.
