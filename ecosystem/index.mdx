Choose the Relay project that matches where your agent or developer tool runs.

**Webhooks fit serverless-friendly request handlers. Acknowledged WebSocket
delivery fits an always-on process.**

## Choose by runtime

| Project | Current source | Runs as | Agent event path |
| --- | --- | --- | --- |
| [Relay Chat SDK](https://github.com/RelayMessenger/Relay-Chat-SDK) | `@relaymessenger/chat-sdk-adapter@0.3.0-staging.0` | Vercel Chat SDK adapter | Signed Webhooks |
| [Relay Agent Starter](https://github.com/RelayMessenger/Relay-Agent-Starter) | `relay-agent-starter@0.1.0` | Cloudflare Think messenger | Signed Webhooks |
| [Relay OpenClaw](https://github.com/RelayMessenger/Relay-OpenClaw) | `@relaymessenger/openclaw-plugin@0.4.0-staging.0` | OpenClaw gateway channel | Acknowledged WebSocket |
| [Relay Claude Code](https://github.com/RelayMessenger/Relay-Claude-Code) | `relay-claude-channel@0.3.0-staging.0` | Claude Code channel process | Acknowledged WebSocket |
| [Relay Hermes](https://github.com/RelayMessenger/Relay-Hermes) | `relay-hermes@1.0.0rc1` | Hermes gateway plugin | Acknowledged WebSocket |

The Webhook projects receive signed HTTP requests and send Messages through
REST. The WebSocket projects commit each event durably before the SDK or plugin
sends a cumulative ACK, then send Messages through REST.

## Choose local tools

| Project | Current source | Use |
| --- | --- | --- |
| [Relay CLI](https://github.com/RelayMessenger/Relay-CLI) | `@relaymessenger/cli@0.5.0-staging.0` | Terminal commands, profiles, diagnostics, and local event forwarding |
| [Relay MCP](https://github.com/RelayMessenger/Relay-MCP) | `@relaymessenger/mcp@0.1.0-staging.0` | Local stdio tools for Relay Chats, Messages, reactions, Read state, Contact Cards, and Add requests |
| [Relay Skills](https://github.com/RelayMessenger/Relay-Skills) | `1.0.0` | Portable Relay guidance and hosted docs MCP configuration |
| [Relay Codex](https://github.com/RelayMessenger/Relay-Codex) | `1.0.0` | Generated Codex plugin from Relay Skills |
| [Relay Cursor](https://github.com/RelayMessenger/Relay-Cursor) | `1.0.0` | Generated Cursor plugin from Relay Skills |
| [Relay Examples](https://github.com/RelayMessenger/Relay-Examples) | `1.0.0` | Four source examples for Webhooks, WebSocket, Think, and Attachments |

The local Relay MCP uses an Agent Token to call Relay API operations. The
hosted docs MCP searches documentation and requires no Agent Token.
