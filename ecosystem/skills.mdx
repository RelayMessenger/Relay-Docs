Install portable Relay guidance for coding agents and connect them to current
Relay docs search.

Source: [RelayMessenger/Relay-Skills](https://github.com/RelayMessenger/Relay-Skills)

## Install

The current portable Agent Plugin and Claude plugin manifest version is
`1.0.0`:

```bash
npx skills add https://github.com/RelayMessenger/Relay-Skills --skill relay
```

Relay Skills is the editable source for the generated Codex and Cursor
packages. Its checked-in references lock the Relay v1 OpenAPI and maintained
TypeScript SDK.

## Choose the docs MCP

The skill configures a hosted, read-only docs MCP. It searches documentation
and requires no Relay Agent Token.

| Docs source | MCP URL |
| --- | --- |
| Published docs | `https://docs.relayapp.im/mcp` |
| Staging verification | `https://docs.staging.relayapp.im/mcp` |

Use [Relay MCP](/ecosystem/mcp) instead when the local coding agent should call
Relay messaging tools with an Agent Token.

## Verify staging search

Staging search must return the current event paths and payload version for
these queries:

```text
Relay v1 /v1/websocket /v1/webhook-subscriptions full_sync
message.received webhook_version 2026-08-30 api_version v1
```

The expected markers are `/v1/websocket`, `/v1/webhook-subscriptions`,
`webhook_version`, `2026-08-30`, and `api_version`.

From a Relay Skills, Codex, or Cursor source checkout, target staging during
the strict hosted-search test:

```bash
RELAY_DOCS_MCP_URL=https://docs.staging.relayapp.im/mcp npm run test:live
```
